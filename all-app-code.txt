# Workspace Mgr

Middleware between the **Orion** dashboard and **Red Hat OpenShift Dev Spaces**. On demand of a user it
creates, lists, starts, stops and deletes DevWorkspaces, creates the user's project (namespace) when it does not
exist, manages per-user Git credentials, and records every action to Postgres for the Dev Spaces dashboard.

Node 20+, TypeScript (strict, ESM), Express 4, `@kubernetes/client-node`, `pg`, `zod`.
Project rules: [docs/PROJECT_RULES.md](docs/PROJECT_RULES.md) · Checklist: [docs/CHECKLIST.md](docs/CHECKLIST.md)

## Quick start

```bash
npm install
cp .env.example .env        # edit; SECRET_KEY, ADMIN_*, DEVREG_URL are required
npm run dev                 # tsx watch (loads env from your shell; use `node --env-file=.env` if you prefer)
npm run build && npm start  # production
```

| Script                                                | What it does                               |
| ----------------------------------------------------- | ------------------------------------------ |
| `npm run typecheck` / `lint` / `format`               | tsc, eslint (0 warnings allowed), prettier |
| `npm test`                                            | unit + integration + e2e                   |
| `npm run test:unit` / `test:integration` / `test:e2e` | one layer                                  |
| `npm run test:coverage`                               | all layers with a coverage gate            |

## Postgres: the existing database

Metrics go into the **existing** Orion database. workspace-mgr creates nothing (no tables, schemas or migrations);
it only inserts rows into the table named by `POSTGRES_DATABASE_TABLENAME`.

Same variables as the original service:

```bash
export POSTGRES_DATABASE=orion_dev_metadata
export POSTGRES_HOSTNAME=NAORI01DPS_INSTANCE1.pgaas.dyn.nsroot.net
export POSTGRES_PASSWORD=...
export POSTGRES_PORT='1524'
export POSTGRES_USER=app_orion_pgsql_dev
export POSTGRES_DATABASE_TABLENAME='metrics."devspaces-metrics-dev"'
export NODE_ENV=development
```

- **TLS** is always on and the server certificate is verified, as before. `NODE_ENV` picks the CA file:
  `development` → `./certs/dev.pem` (hostname check relaxed), `uat` → `/app/backend/cert/uat.pem`,
  `production` → `/app/backend/cert/prod.pem`. Override with `POSTGRES_CERT_DIR` or `POSTGRES_CA_FILE`.
  The app refuses to start, naming the missing file, if the CA cannot be read.
- **Columns:** the service reads the table's column list once and writes only the columns that exist (it knows
  `timestamp, csiid, soeid, eventtype, resourcename, resourcetype, status, limitcpu, limitmemory, requestcpu,
requestmemory, duration, storage, useraction, errordetail, workspaceversion, editorname`). A table without
  `workspaceversion` / `editorname` still works; a warning names what is not stored.
- **Timestamps** are written as UTC wall-clock text, as the original did.
- A database problem never blocks a workspace action: it is logged and the action continues.

## Hand-over to another computer (`recreate-app.sh`, `all-app-code.txt`)

The app moves between computers as **one text file**, `all-app-code.txt`, and one script, `recreate-app.sh`.
The text file is made for you (by Claude, with `tools/build-all-code.sh`); you only run the script:

```bash
bash recreate-app.sh -f             # inside the app folder: writes the files of ./all-app-code.txt, overwriting
bash recreate-app.sh -f --prune     # also delete files that were removed from the app
bash recreate-app.sh -n             # dry run: show what would happen
bash recreate-app.sh p.txt ./out    # another input file / another folder (existing files are kept without -f)
```

- **First hand-over:** the entire application. **Every later one:** only the new and changed files, plus a list of
  files that were removed (`/_REMOVED.txt`). It ends with what to run next (`npm install`, `npm run build`, ...) when
  something relevant changed.
- **New empty folder:** put `recreate-app.sh` and `all-app-code.txt` in it and run `bash recreate-app.sh -f`, then
  `npm ci && npm test && npm run build && npm start`.
- **Format:** `/path/to/file`, the file's content, a blank line, next file. Files that cannot be shown as exact plain
  text (CRLF line endings, no final newline, odd names) are stored as base64 after `@@BINARY-SECTION`; the plain files
  are LF, so an editor, e-mail or git changing line endings cannot damage anything.
- **Safe:** the text file ends with a SHA-256 for every file; they are all checked in a temp folder before your files are
  touched. Existing files that differ are kept unless you pass `-f`. Paths that could escape the folder are rejected.
  `recreate-app.sh` never replaces itself while running; a newer version is saved as `recreate-app.sh.new`.
- **Never in a hand-over:** `node_modules`, `dist`, `coverage`, `.git`, `legacy`, `tools`, `.env*` (secrets), private keys.
- **For the maintainer:** `bash tools/build-all-code.sh` builds the next hand-over (entire app the first time, then
  only changes; `--full`, `--list`, `--redo` and `--keep-state` exist). What the other computer has is remembered in
  `.handover-state` (not committed). Before saving, the file is recreated in a temp folder and compared byte for byte.

# Workspace Mgr — Project Rules

Workspace Mgr is the backend/middleware between the Orion dashboard and OpenShift
Dev Spaces. It creates, lists, starts, stops and deletes DevWorkspaces for a user,
creates the user's project (namespace) when it does not exist, and records every
action to Postgres for the Dev Spaces dashboard.

These rules are binding for every change. If a rule must be broken, say why in the PR.

## 1. Architecture

1. **Layers, strictly top-down:** `http` → `services` → `infra`/`factories` → `domain`/`utils`.
   A lower layer never imports from a higher one.
2. **`http`** only parses/validates input, calls one service method, and maps the result or
   error to a response. No Kubernetes, SQL or business rules in routes.
3. **`services`** own business rules (limits, ordering of steps, naming, metrics events).
   They depend on **ports** (interfaces), never on concrete clients.
4. **`infra`** holds the concrete adapters (Kubernetes, Postgres, devfile registry, email).
   Every adapter implements a port declared in `src/infra/ports.ts`.
5. **`factories`** are pure functions (devfile → DevWorkspace, log records). No I/O.
6. **One composition root** (`src/container.ts`) wires adapters into services. Nothing else
   calls `new` on an adapter. Tests build the container with fakes.
7. No module-level side effects (no connecting to a DB, reading files, or reading `process.env`
   at import time). Config is read once in `src/config/env.ts` and passed in.

## 2. Language and style

1. TypeScript `strict: true`, ESM (`"module": "NodeNext"`). Local imports end in `.js`.
2. No `any` except at a third-party boundary, and then it is narrowed immediately.
   **No `// @ts-ignore`.** Use `// @ts-expect-error` with a reason if truly unavoidable.
3. Prefer `async/await`. No `.then().catch()` chains.
4. Functions are small and single-purpose. A service method that needs a comment block to
   explain its steps should be split.
5. Names: `camelCase` values, `PascalCase` types/classes, `kebab-case.ts` filenames for modules
   that export functions, `PascalCase.ts` for files whose main export is a class.
6. Comments explain _why_, not _what_. No commented-out code, no TODO without an issue id.
7. `eslint` and `prettier` must pass with zero warnings.

## 3. Errors

1. Throw typed errors from `src/utils/errors.ts` (`AppError` subclasses). Each carries an HTTP
   status and a stable `code`.
2. Never swallow an error silently. Either handle it, record it, or rethrow it.
   The only intentional swallow is the metrics recorder (rule 6.2), and it logs.
3. Kubernetes/axios errors are translated to `AppError` at the adapter boundary
   (`src/utils/k8s-errors.ts`). Callers never inspect `err.body.code`.
4. Error responses always have the shape `{ "error": string, "message": string, "code": string }`.
   Never return a stack trace or upstream response body to the client.

## 4. Security

1. `SECRET_KEY` is **required**; the process refuses to start without it. No fallback secret.
2. Tokens: `Authorization: Bearer <jwt>` only. Verify with the explicit algorithm `HS256`.
3. Admin credential comparison is constant-time (`crypto.timingSafeEqual`).
4. Every `:soeid` and `:id` path parameter is validated against an allow-list pattern before it
   is used in a namespace name, label selector or Kubernetes path.
5. A caller may only act on their own `:soeid` unless the token has the `admin` role.
6. Never log tokens, passwords, PAT values, or full request bodies. PAT values are masked
   (`ghp_ab…xyz`) everywhere except the Secret itself.
7. Secrets for Kubernetes and Postgres come from the environment / mounted files, never from
   source or from git.
8. All SQL is parameterised. No string-built queries.
9. Kubernetes access uses the pod's service account with the minimum RBAC in
   `kustomize.server/base/sa.yaml`; do not widen it without review.

## 5. Kubernetes behaviour

1. Operations are idempotent: "create or replace" for quotas, roles, bindings, ConfigMaps.
2. Workspace namespaces are found by **label + annotation**, not by listing the whole cluster.
   Deployment namespaces are created through OpenShift's `ProjectRequest`, which may not apply our labels, so
   they are found by their deterministic name (`<soeid>-devspaces-deploy-<csiid>`).
3. A workspace id is `metadata.name`; it is unique inside a user's namespaces.
4. Poll loops have a hard timeout and an interval, are injectable (clock/sleep) for tests, and
   fail with a typed error. They never silently "fix" state by restarting workspaces.
5. Deleting something that is already gone is a success.

## 6. Metrics (Postgres)

1. Every user-visible action (create/delete/start/stop of workspace; create/delete of project;
   PAT/gitconfig changes) records one row to `metrics."devspaces-metrics"`, success **or** failure.
2. Recording is best-effort: a database failure is logged and must never fail or delay the
   user's action beyond a short timeout.
3. The row shape is defined once (`MetricsRecord`). The metrics table **already exists** and is owned by the
   database team: the service never issues DDL (no `CREATE`, `ALTER`, `DROP`) and ships no migrations. It only
   `INSERT`s, plus read-only `SELECT`s of the table's column list so it can write into an older table that lacks
   some of our columns. A test asserts this. The table SQL under `tests/helpers/` is a test fixture only.
4. Postgres is configured only through the existing variables (`POSTGRES_DATABASE`, `_HOSTNAME`, `_PASSWORD`,
   `_PORT`, `_USER`, `_DATABASE_TABLENAME`) and `NODE_ENV`, which picks the CA file (dev/uat/prod) as before.
5. Timestamps are written as UTC wall-clock text (`2026-01-02 03:04:05.678`), as the original service did. The
   CST format is for logs and emails only.

## 7. Testing

1. Three layers, all required for a feature:
   - **Unit** (`tests/unit`): one module, all collaborators faked, no network, no timers
     (use fake clock). Fast (< 5 s total).
   - **Integration** (`tests/integration`): real HTTP routes + real services + real SQL
     (`pg-mem`) + in-memory Kubernetes + a local fake devfile registry. Verifies wiring.
   - **End to end** (`tests/e2e`): a real listening server, driven only over HTTP
     (`fetch`) through whole user journeys (login → create → start → stop → delete), then
     asserting the Kubernetes state and metrics rows.
2. A bug fix starts with a failing test.
3. Tests do not depend on order, wall-clock time, or real cluster/DB access.
4. Coverage gate: ≥ 85 % lines and ≥ 80 % branches on `src/` (excluding `src/index.ts`).
5. No `.only`, no `.skip` committed.

## 8. API contract

1. **URI versioning, industry standard:** every API route is served under `/api/v1`
   (`/api/v1/login`, `/api/v1/catalog`, `/api/v1/:soeid/workspaces[/:id[/start|/stop]]`, ...).
   Path structure after the prefix is identical to the pre-versioning layout.
   Operational probes `/healthz` and `/readyz` are unversioned.
2. Within a major version changes are additive only (new routes, new optional fields).
   A breaking change ships as `/api/v2` alongside `v1`; `v1` is then deprecated, never edited in place.
3. The pre-versioning paths (`/login`, `/:soeid/...`) exist only as deprecated aliases of `v1`
   (`Deprecation: true` and a `Link: rel="successor-version"` header) controlled by
   `LEGACY_UNVERSIONED_ROUTES`. Remove them once Orion has migrated.
4. Request bodies are validated with `zod`; unknown properties are rejected.
5. `409` for limit/conflict, `404` unknown resource, `400` invalid input, `401/403` auth,
   `502` upstream (cluster/registry) failure, `500` everything else.

## 9. Operations

1. `/healthz` (liveness) never touches dependencies. `/readyz` checks Kubernetes API and
   Postgres reachability.
2. Logs are one entry per event with `requestId`, `soeid`, `event`. Terminal format (`LOG_FORMAT=pretty`, the default) is readable and coloured: errors red, warnings orange, successes green, everything else white; `LOG_FORMAT=json` gives structured JSON lines. Use `logger.success` for something that worked, `warn` for a problem the caller or the setup caused, `error` for a failure on our side.
3. Graceful shutdown on `SIGTERM`: stop accepting, drain, close the DB pool.
4. Config via environment variables only; every variable is documented in `.env.example`.
5. Container runs as non-root, read-only root filesystem compatible.

## 10. Git and review

1. Small, focused commits; imperative subject line.
2. CI order: `typecheck` → `lint` → `test:unit` → `test:integration` → `test:e2e` → `build`.
3. A PR is mergeable only when the [CHECKLIST](./CHECKLIST.md) items for its scope are ticked.

/** `'1524'` → `1524`, `"a b"` → `a b`; anything not wrapped in one matching pair of quotes is untouched. */
export function unquote(value: string): string {
  const match = /^(['"])(.*)\1$/s.exec(value);
  return match?.[2] ?? value;
}

/** `che-code` → `che-incubator/che-code/latest`; `che-incubator/che-code/latest` is kept as it is. */
export function normalizeEditorId(value: string): string {
  const v = value.trim();
  return v.includes('/') ? v : `che-incubator/${v}/latest`;
}

/** `https://api.namctigtd001d.ecs.dyn.example.net:6443` → `namctigtd001d`. */
export function clusterNameOf(apiUrl: string): string | undefined {
  try {
    const host = new URL(apiUrl).hostname;
    return host.startsWith('api.') ? host.split('.')[1] : undefined;
  } catch {
    return undefined;
  }
}

/** `https://api.<rest>:6443` → `https://devspaces.apps.<rest>` (the usual Dev Spaces dashboard host). */
export function deriveDevSpacesFqdn(apiUrl: string): string {
  try {
    const host = new URL(apiUrl).hostname;
    return host.startsWith('api.') ? `https://devspaces.apps.${host.slice('api.'.length)}` : '';
  } catch {
    return '';
  }
}

export interface FoundToken {
  /** The environment variable the token came from (never the token itself). */
  name: string;
  value: string;
}

/**
 * Finds the bearer token for a cluster by variable name: `<prefix><id>`, e.g. devSpacesClusterToken001d for the cluster
 * `namctigtd001d` (the id must be the end of the cluster name). A variable without an id (`<prefix>`) fits any cluster.
 * Tokens that belong to another cluster are ignored, so a leftover `devOpsToken004d` is never sent to cluster 001d.
 */
export function findClusterToken(
  env: Record<string, string | undefined>,
  prefix: string,
  apiUrl: string,
): FoundToken | undefined {
  const cluster = (clusterNameOf(apiUrl) ?? '').toLowerCase();
  const fits = Object.keys(env)
    .filter((k) => k.toLowerCase().startsWith(prefix.toLowerCase()) && env[k])
    .filter((k) => {
      const id = k.slice(prefix.length).toLowerCase();
      return id === '' || (cluster !== '' && cluster.endsWith(id));
    });
  if (fits.length > 1) {
    throw new Error(
      `Invalid configuration:\n  - several variables fit one cluster token: ${fits.join(', ')}`,
    );
  }
  const name = fits[0];
  return name ? { name, value: env[name] as string } : undefined;
}

/** What the service understood from its environment, for the startup log. Contains no secret values. */
export function startupSummary(c: AppConfig): Record<string, unknown> {
  const auth = (tokenVar: string | undefined, kubeconfig: string | undefined): string =>
    tokenVar
      ? `bearer token from ${tokenVar}`
      : kubeconfig
        ? 'kubeconfig file'
        : 'default kubeconfig / pod service account';
  return {
    port: c.port,
    nodeEnv: c.nodeEnv,
    cluster: c.cluster.apiUrl,
    clusterAuth: auth(c.cluster.tokenVar, c.cluster.kubeconfigPath),
    deployCluster: c.cluster.deployApiUrl,
    deployClusterAuth:
      c.cluster.deployApiUrl === c.cluster.apiUrl
        ? 'same cluster'
        : auth(c.cluster.deployTokenVar, c.cluster.kubeconfigPath),
    devSpacesFqdn: c.cluster.devSpacesServiceFqdn,
    devfileRegistry: c.devreg.url,
    editors: c.devreg.editors,
    clusterTls: c.cluster.tlsRejectUnauthorized
      ? 'certificates verified'
      : 'NOT verified (NODE_TLS_REJECT_UNAUTHORIZED=0)',
    postgres: c.postgres.enabled
      ? {
          host: c.postgres.host,
          port: c.postgres.port,
          database: c.postgres.database,
          table: c.postgres.table,
        }
      : 'disabled',
  };
}

/** Parse and validate the environment once, at startup. Throws a readable error listing every problem. */
export function loadConfig(env: NodeJS.ProcessEnv = process.env): AppConfig {
  // An exported-but-empty variable (`FOO=`) is treated as unset. Values that still carry their shell quotes
  // (`'1524'`, `'metrics."devspaces-metrics-dev"'` from a .env file or a pasted export line) are unwrapped.
  const cleaned = Object.fromEntries(
    Object.entries(env)
      .filter(([, v]) => v !== undefined && v !== '')
      .map(([k, v]) => [k, unquote(v as string)]),
  );
  const parsed = schema.safeParse(cleaned);
  if (!parsed.success) {
    const problems = parsed.error.issues.map((i) => `${i.path.join('.') || '(root)'}: ${i.message}`);
    throw new Error(`Invalid configuration:\n  - ${problems.join('\n  - ')}`);
  }
  const e = parsed.data;
  if (e.POSTGRES_ENABLED && (!e.POSTGRES_DATABASE || !e.POSTGRES_USER)) {
    throw new Error(
      'Invalid configuration:\n  - POSTGRES_DATABASE and POSTGRES_USER are required when POSTGRES_ENABLED=true',
    );
  }

  const deployApiUrl = e.DEPLOY_CLUSTER_API_URL ?? e.CLUSTER_API_URL;
  const separateDeployCluster = deployApiUrl !== e.CLUSTER_API_URL;
  const main = e.CLUSTER_TOKEN
    ? { name: 'CLUSTER_TOKEN', value: e.CLUSTER_TOKEN }
    : findClusterToken(cleaned, 'devSpacesClusterToken', e.CLUSTER_API_URL);
  const deploy = !separateDeployCluster
    ? undefined
    : e.DEPLOY_CLUSTER_TOKEN
      ? { name: 'DEPLOY_CLUSTER_TOKEN', value: e.DEPLOY_CLUSTER_TOKEN }
      : findClusterToken(cleaned, 'devOpsToken', deployApiUrl);
  if (separateDeployCluster && !deploy && !e.KUBECONFIG_PATH) {
    throw new Error(
      `Invalid configuration:\n  - DEPLOY_CLUSTER_API_URL is set to a different cluster but no token was found for it ` +
        `(set DEPLOY_CLUSTER_TOKEN, or devOpsToken<id> where <id> ends the cluster name)`,
    );
  }

  return {
    port: e.PORT,
    nodeEnv: e.NODE_ENV,
    logLevel: e.LOG_LEVEL,
    logFormat: e.LOG_FORMAT,
    logColor: e.LOG_COLOR && !cleaned.NO_COLOR,
    legacyRoutes: e.LEGACY_UNVERSIONED_ROUTES,
    auth: {
      secretKey: e.SECRET_KEY,
      adminUsername: e.ADMIN_USERNAME,
      adminPassword: e.ADMIN_PASSWORD,
      expiresIn: e.JWT_EXPIRES_IN,
    },
    cluster: {
      apiUrl: e.CLUSTER_API_URL,
      token: main?.value,
      tokenVar: main?.name,
      deployApiUrl,
      deployToken: deploy?.value,
      deployTokenVar: deploy?.name,
      tlsRejectUnauthorized: cleaned.NODE_TLS_REJECT_UNAUTHORIZED !== '0',
      kubeconfigPath: e.KUBECONFIG_PATH,
      deployProjectRequester: e.DEPLOY_PROJECT_REQUESTER,
      devSpacesServiceFqdn: e.DEV_SPACES_SERVICE_FQDN ?? deriveDevSpacesFqdn(e.CLUSTER_API_URL),
    },
    devreg: {
      url: e.DEVREG_URL,
      editors: {
        vscode: normalizeEditorId(e.EDITOR_VSCODE),
        intellij: normalizeEditorId(e.EDITOR_INTELLIJ),
        goland: normalizeEditorId(e.EDITOR_GOLAND),
      },
      workspaceProxyUrl: e.WORKSPACE_PROXY_URL,
    },
    limits: { maxRunning: e.MAX_RUNNING_WORKSPACES, maxTotal: e.MAX_TOTAL_WORKSPACES },
    postgres: {
      enabled: e.POSTGRES_ENABLED,
      host: e.POSTGRES_HOSTNAME,
      port: e.POSTGRES_PORT,
      database: e.POSTGRES_DATABASE,
      user: e.POSTGRES_USER,
      password: e.POSTGRES_PASSWORD,
      ssl: e.POSTGRES_SSL,
      caFile: e.POSTGRES_CA_FILE,
      certDir: e.POSTGRES_CERT_DIR,
      env: e.NODE_ENV,
      table: e.POSTGRES_DATABASE_TABLENAME,
    },
    notification: {
      url: e.NOTIFICATION_MAIL_URL,
      username: e.NOTIFICATION_EMAIL_USERNAME,
      password: e.NOTIFICATION_EMAIL_PASSWORD,
      sender: e.NOTIFICATION_SENDER,
      cc: e.NOTIFICATION_CC,
      emailDomain: e.EMAIL_DOMAIN,
      userDirectoryUrl: e.USER_DIRECTORY_GRAPHQL_URL,
    },
    github: { url: e.GITHUB_URL.replace(/\/$/, ''), userSuffix: e.GITHUB_USER_SUFFIX },
  };
}

import { randomUUID } from 'node:crypto';
import express, { Router, type Express, type Request, type RequestHandler, type Response } from 'express';
import type { Container } from '../container.js';
import { parseCsiid, parseTokenName } from '../utils/names.js';
import { UnauthorizedError } from '../utils/errors.js';
import { authenticate, authorizeSoeid, checkAdminCredentials, getSoeid, signToken } from './auth.js';
import { asyncHandler, createErrorHandler, errorBody, notFoundHandler } from './errors.js';
import {
  createWorkspaceSchema,
  csiidBodySchema,
  csiidQuerySchema,
  gitConfigBodySchema,
  loginSchema,
  parse,
  patBodySchema,
} from './schemas.js';

export const API_PREFIX = '/api/v1';

const param = (req: Request, name: string): string => req.params[name] ?? '';

/** RFC 8594-style signalling that an unversioned path is going away. */
const deprecatedAlias: RequestHandler = (req, res, next) => {
  res.setHeader('Deprecation', 'true');
  res.setHeader('Link', `<${API_PREFIX}${req.path}>; rel="successor-version"`);
  next();
};

export function createApp(c: Container): Express {
  const app = express();
  app.disable('x-powered-by');
  app.use(express.json({ limit: '256kb' }));

  app.use((req, res, next) => {
    const incoming = req.header('x-request-id');
    const requestId = incoming && /^[A-Za-z0-9-]{8,64}$/.test(incoming) ? incoming : randomUUID();
    res.locals.requestId = requestId;
    res.setHeader('x-request-id', requestId);
    const started = Date.now();
    res.on('finish', () => {
      // 5xx = we failed (red), 4xx = the caller's problem (orange), everything else = a successful call (green)
      const outcome = res.statusCode >= 500 ? 'error' : res.statusCode >= 400 ? 'warn' : 'success';
      c.logger[outcome]('request', {
        method: req.method,
        // originalUrl, not req.path: inside nested routers req.path is only the part after the mount point
        path: req.originalUrl.split('?')[0],
        status: res.statusCode,
        ms: Date.now() - started,
        requestId,
        soeid: res.locals.soeid as string | undefined,
      });
    });
    next();
  });

  // ---- operations ---------------------------------------------------------------------------
  app.get('/healthz', (_req, res) => {
    res.send('OK');
  });

  app.get(
    '/readyz',
    asyncHandler(async (_req, res) => {
      const checks: Record<string, string> = {};
      await Promise.all([
        c.kube.ping().then(
          () => (checks.kubernetes = 'ok'),
          () => (checks.kubernetes = 'unavailable'),
        ),
        c.metrics.ping().then(
          () => (checks.postgres = 'ok'),
          () => (checks.postgres = 'unavailable'),
        ),
        // only when build/deploy projects live on a different cluster
        ...(c.deployKube !== c.kube
          ? [
              c.deployKube.ping().then(
                () => (checks.deployCluster = 'ok'),
                () => (checks.deployCluster = 'unavailable'),
              ),
            ]
          : []),
      ]);
      const ready = Object.values(checks).every((v) => v === 'ok');
      res.status(ready ? 200 : 503).json({ status: ready ? 'ready' : 'not-ready', checks });
    }),
  );

  // ---- versioned API (mounted at /api/v1, and optionally at / as a deprecated alias) --------
  const api = Router();

  api.post('/login', (req, res, next) => {
    try {
      const { username, password } = parse(loginSchema, req.body);
      if (!checkAdminCredentials(c.config.auth, username, password)) {
        throw new UnauthorizedError('Username or password is incorrect');
      }
      res.json({ token: signToken(c.config.auth, { soeid: username, role: 'admin' }) });
    } catch (error) {
      next(error);
    }
  });

  const auth = authenticate(c.config.auth);

  api.get(
    '/catalog',
    auth,
    asyncHandler(async (_req, res) => {
      res.json(await c.registry.getCatalog());
    }),
  );

  // ---- per-user routes ----------------------------------------------------------------------
  const user = Router({ mergeParams: true });

  user.get(
    '/projects',
    asyncHandler(async (_req, res) => {
      res.json(await c.namespaces.listProjects(getSoeid(res)));
    }),
  );

  user.get(
    '/workspaces',
    asyncHandler(async (_req, res) => {
      res.json(await c.workspaces.list(getSoeid(res)));
    }),
  );

  user.get(
    '/workspaces/:id',
    asyncHandler(async (req, res) => {
      res.json(await c.workspaces.get(getSoeid(res), param(req, 'id')));
    }),
  );

  user.post(
    '/workspaces',
    asyncHandler(async (req, res) => {
      const body = parse(createWorkspaceSchema, req.body);
      const workspace = await c.workspaces.create({
        soeid: getSoeid(res),
        csiid: parseCsiid(body.csiid),
        devworkspaceValue: body.devworkspaceValue,
        editor: body.editor,
        stackVersion: body.stackVersion,
        repositoryUrl: body.repositoryUrl,
        repositoryBranch: body.repositoryBranch,
      });
      res.status(200).json(workspace);
    }),
  );

  user.delete(
    '/workspaces/:id',
    asyncHandler(async (req, res) => {
      const id = param(req, 'id');
      await c.workspaces.delete(getSoeid(res), id);
      res.json({ message: `Workspace with id ${id} is terminating.` });
    }),
  );

  user.post(
    '/workspaces/:id/start',
    asyncHandler(async (req, res) => {
      const id = param(req, 'id');
      await c.workspaces.start(getSoeid(res), id);
      res.json({ message: `Workspace with id ${id} is starting.` });
    }),
  );

  user.post(
    '/workspaces/:id/stop',
    asyncHandler(async (req, res) => {
      const id = param(req, 'id');
      await c.workspaces.stop(getSoeid(res), id);
      res.json({ message: `Workspace with id ${id} is stopping.` });
    }),
  );

  // Personal access tokens
  user.get(
    '/pats',
    asyncHandler(async (_req, res) => {
      res.json(await c.pats.list(getSoeid(res)));
    }),
  );
  user.get(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      res.json(await c.pats.view(getSoeid(res), parseCsiid(csiid), parseTokenName(param(req, 'tokenName'))));
    }),
  );
  user.post(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const body = parse(patBodySchema, req.body);
      const created = await c.pats.create(
        getSoeid(res),
        parseCsiid(body.csiid),
        parseTokenName(param(req, 'tokenName')),
        body.token,
      );
      res.status(201).json(created);
    }),
  );
  user.put(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const body = parse(patBodySchema, req.body);
      res.json(
        await c.pats.update(
          getSoeid(res),
          parseCsiid(body.csiid),
          parseTokenName(param(req, 'tokenName')),
          body.token,
        ),
      );
    }),
  );
  user.delete(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      const tokenName = parseTokenName(param(req, 'tokenName'));
      const removed = await c.pats.delete(getSoeid(res), parseCsiid(csiid), tokenName);
      res.json({
        message: removed ? `PAT '${tokenName}' deleted.` : `PAT '${tokenName}' not found; nothing to delete.`,
      });
    }),
  );

  // Git config
  user.get(
    '/gitconfig',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      res.json(await c.gitConfig.view(getSoeid(res), parseCsiid(csiid)));
    }),
  );
  user.put(
    '/gitconfig',
    asyncHandler(async (req, res) => {
      const body = parse(gitConfigBodySchema, req.body);
      res.json(await c.gitConfig.upsert(getSoeid(res), parseCsiid(body.csiid), body.content));
    }),
  );
  user.delete(
    '/gitconfig',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      const removed = await c.gitConfig.delete(getSoeid(res), parseCsiid(csiid));
      res.json({ message: removed ? 'Git config deleted.' : 'Git config not found; nothing to delete.' });
    }),
  );

  // Deployment (build/deploy) projects
  user.get(
    '/deployment-projects',
    asyncHandler(async (_req, res) => {
      res.json(await c.deployments.list(getSoeid(res)));
    }),
  );
  user.post(
    '/deployment-projects',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidBodySchema, req.body);
      const result = await c.deployments.ensure(getSoeid(res), parseCsiid(csiid));
      res.status(result.exists ? 200 : 201).json(result);
    }),
  );
  user.delete(
    '/deployment-projects',
    asyncHandler(async (_req: Request, res: Response) => {
      res.json(await c.deployments.delete(getSoeid(res)));
    }),
  );

  api.use('/:soeid', auth, authorizeSoeid(), user);

  app.use(API_PREFIX, api);
  if (c.config.legacyRoutes) {
    // Pre-versioning paths kept so existing Orion builds keep working while they migrate to /api/v1.
    const legacy = Router();
    // Unknown /api/... paths (e.g. a future /api/v2) must 404, not be read as `/:soeid` = "api".
    legacy.use((req, _res, next) =>
      req.path === '/api' || req.path.startsWith('/api/') ? next('router') : next(),
    );
    legacy.use(deprecatedAlias, api);
    app.use('/', legacy);
  }

  app.use(notFoundHandler);
  app.use(createErrorHandler(c.logger));
  return app;
}

async function main(): Promise<void> {

  const config = loadConfig(
    process.argv[2] ? { ...process.env, KUBECONFIG_PATH: process.argv[2] } : process.env,
  );
  const logger = createLogger(
    config.logLevel,
    undefined,
    {},
    { format: config.logFormat, color: config.logColor },
  );
  if (!config.cluster.tlsRejectUnauthorized) {
    logger.warn('cluster.tls_verification_disabled', {
      reason: 'NODE_TLS_REJECT_UNAUTHORIZED=0',
      risk: 'the clusters, the devfile registry and other HTTPS peers are not verified',
    });
  }
  const container = buildContainer(config, logger, createProductionDependencies(config, logger));
  const server: Server = createApp(container).listen(config.port, () =>
    logger.success('server.listening', startupSummary(config)),
  );

  let shuttingDown = false;
  const shutdown = (signal: string): void => {
    if (shuttingDown) return;
    shuttingDown = true;
    logger.info('server.shutdown', { signal });
    server.close(() => {
      container.metrics.close().finally(() => process.exit(0));
    });
    setTimeout(() => process.exit(1), 10_000).unref();
  };
  process.on('SIGTERM', () => shutdown('SIGTERM'));
  process.on('SIGINT', () => shutdown('SIGINT'));
}

    );
  }

  private async send(
    soeid: string,
    subject: string,
    body: (firstName: string | undefined, recipient: string) => string,
  ): Promise<void> {
    const { url, username, password, sender, cc, emailDomain } = this.config;
    if (!url) {
      this.logger.debug('email.skipped', { reason: 'NOTIFICATION_MAIL_URL not set', subject });
      return;
    }
    const recipient = `${soeid}@${emailDomain}`;
    try {
      const firstName = await this.directory.firstName(soeid);
      const response = await this.fetchFn(`${url.replace(/\/$/, '')}/send-mail/v2`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Basic ${Buffer.from(`${username}:${password}`).toString('base64')}`,
        },
        body: JSON.stringify({
          sender,
          receiver: recipient,
          receiverName: soeid.toUpperCase(),
          cc: cc ?? '',
          bcc: '',
          subject,
          emailMessage: body(firstName, recipient),
          isHtml: true,
        }),
        signal: AbortSignal.timeout(10_000),
      });
      if (!response.ok) throw new Error(`mail service answered ${response.status}`);
      this.logger.success('email.sent', { soeid, subject });
    } catch (error) {
      this.logger.error('email.failed', { soeid, subject, error: errorMessage(error) });
    }
  }

import {
  ANNOTATION_CHE_USERNAME,
  BUILDER_ROLE_CONFIG,
  DEPLOYER_ROLE_CONFIG,
  DEPLOYMENT_LIMIT_RANGE_DEFAULT_CONFIG,
  DEPLOYMENT_RESOURCE_QUOTA_COMPUTE_CONFIG,
  DEPLOYMENT_RESOURCE_QUOTA_STORAGE_CONFIG,
  LABEL_COMPONENT,
  LABEL_CSIID,
  LABEL_DEPLOYMENT_NAMESPACE,
} from '../constants/kubernetes-configs.js';
import type { KubeObject } from '../domain/types.js';
import type { KubeGateway, Notifier } from '../infra/ports.js';
import { errorMessage } from '../utils/errors.js';
import { silentLogger, type Logger } from '../utils/logger.js';
import { csiidFromDeploymentNamespace, deploymentNamespace } from '../utils/names.js';
import type { MetricsRecorder } from './MetricsRecorder.js';

export interface DeploymentEnsureResult {
  exists: boolean;
  name: string;
}

export interface DeploymentDeleteResult {
  exists: boolean;
  deleted: string[];
  failed: string[];
  message: string;
}

export class DeploymentNamespaceService {
  constructor(
    private readonly kube: KubeGateway,
    private readonly recorder: MetricsRecorder,
    private readonly notifier: Notifier,
    private readonly requester: string,
    private readonly logger: Logger = silentLogger,
  ) {}

  async list(soeid: string): Promise<string[]> {
    const pattern = new RegExp(`^${soeid}-devspaces-deploy-\\d+$`);
    const all = await this.kube.listNamespaces();
    return all.map((ns) => ns.metadata?.name ?? '').filter((name) => pattern.test(name));
  }

  /** Returns the existing deployment project for this CSI id, or creates and provisions a new one. */
  async ensure(soeid: string, csiid: string): Promise<DeploymentEnsureResult> {
    const desired = deploymentNamespace(soeid, csiid);
    if (await this.kube.getNamespace(desired)) {
      await this.notifier.namespaceAlreadyExists({
        soeid,
        newNamespace: desired,
        existingNamespace: desired,
      });
      return { exists: true, name: desired };
    }

    const actual = await this.recorder.track(
      { soeid, csiid, eventtype: 'create', resourcetype: 'deployment_namespace', resourcename: desired },
      () => this.createAndProvision(soeid, csiid, desired),
    );
    await this.notifier.namespaceCreated({ soeid, namespace: actual });
    return { exists: false, name: actual };
  }

  private async createAndProvision(soeid: string, csiid: string, desired: string): Promise<string> {
    const project = await this.kube.createProject({
      metadata: {
        name: desired,
        labels: {
          [LABEL_COMPONENT]: LABEL_DEPLOYMENT_NAMESPACE,
          'app.kubernetes.io/managed-by': 'devspaces-support-team',
          'devspaces.citi.com/purpose': 'deployment-resource-management',
          [LABEL_CSIID]: csiid,
        },
        annotations: {
          [ANNOTATION_CHE_USERNAME]: soeid,
          'devspaces.citi.com/creator': 'workspace-manager-automation',
          'openshift.io/requester': this.requester,
          'openshift.io/display-name': `DevSpaces Deployment Project for User ${soeid} [CSIID: ${csiid}]`,
          'openshift.io/description': `Temporary deployment testing project for user ${soeid} [CSIID: ${csiid}], removable by DevSpaces support`,
        },
      },
    });
    const name = project.metadata?.name ?? desired;

    await this.kube.apply('ResourceQuota', name, DEPLOYMENT_RESOURCE_QUOTA_COMPUTE_CONFIG);
    await this.kube.apply('LimitRange', name, DEPLOYMENT_LIMIT_RANGE_DEFAULT_CONFIG);
    await this.kube.apply('ResourceQuota', name, DEPLOYMENT_RESOURCE_QUOTA_STORAGE_CONFIG);
    await this.grantAccess(soeid, name);
    this.logger.success('deployment_namespace.created', { soeid, namespace: name });
    return name;
  }

  private async grantAccess(soeid: string, namespace: string): Promise<void> {
    for (const role of [BUILDER_ROLE_CONFIG, DEPLOYER_ROLE_CONFIG]) {
      const roleName = role.metadata?.name ?? '';
      await this.kube.apply('Role', namespace, role);
      await this.kube.apply('RoleBinding', namespace, this.binding(soeid, namespace, roleName));
    }
  }

  private binding(soeid: string, namespace: string, roleName: string): KubeObject {
    return {
      apiVersion: 'rbac.authorization.k8s.io/v1',
      kind: 'RoleBinding',
      metadata: { name: `${roleName}-${soeid}-binding` },
      subjects: [
        { kind: 'User', name: soeid, apiGroup: 'rbac.authorization.k8s.io' },
        { kind: 'ServiceAccount', name: 'default', namespace },
      ],
      roleRef: { apiGroup: 'rbac.authorization.k8s.io', kind: 'Role', name: roleName },
    };
  }

  async delete(soeid: string): Promise<DeploymentDeleteResult> {
    const names = await this.list(soeid);
    if (names.length === 0) {
      return { exists: false, deleted: [], failed: [], message: 'No deployment namespaces found for user.' };
    }

    const deleted: string[] = [];
    const failed: string[] = [];
    for (const name of names) {
      try {
        await this.recorder.track(
          {
            soeid,
            csiid: csiidFromDeploymentNamespace(name) ?? '',
            eventtype: 'delete',
            resourcetype: 'deployment_namespace',
            resourcename: name,
          },
          () => this.kube.deleteNamespace(name),
        );
        deleted.push(name);
      } catch (error) {
        this.logger.error('deployment_namespace.delete_failed', {
          soeid,
          namespace: name,
          error: errorMessage(error),
        });
        failed.push(name);
      }
    }

    if (deleted.length > 0) await this.notifier.namespacesDeleted({ soeid, namespaces: deleted });

    const parts: string[] = [];
    if (deleted.length > 0)
      parts.push(`Deleted ${deleted.length} deployment namespace(s): ${deleted.join(', ')}`);
    if (failed.length > 0) parts.push(`Failed to delete ${failed.length}: ${failed.join(', ')}`);
    return { exists: deleted.length > 0, deleted, failed, message: parts.join('. ') };
  }
}

import type { AppConfig } from '../config/env.js';
import type { CreateWorkspaceInput, DevWorkspaceResource, EditorKey, Workspace } from '../domain/types.js';
import { applyEditorProfile, parseDevfile } from '../factories/devfile-updater.js';
import { buildDevWorkspaceObject, WORKSPACE_LABELS } from '../factories/workspace-factory.js';

import {

} from '../utils/errors.js';

  editors: AppConfig['devreg']['editors'];

const ACTIVE_PHASES = new Set(['Running', 'Starting', 'Stopping']);

/** Running, starting, stopping — or not yet reporting a phase — all still hold cluster resources. */
export const isActive = (dw: DevWorkspaceResource): boolean =>
  !dw.status?.phase || ACTIVE_PHASES.has(dw.status.phase);

export function toWorkspace(dw: DevWorkspaceResource): Workspace {
  const meta = dw.metadata ?? {};
  const annotations = meta.annotations ?? {};
  const namespace = meta.namespace ?? '';
  const resources = summarizeComponents(dw.spec?.template?.components);
  return {
    id: meta.name ?? '',
    name: meta.name ?? '',
    displayName: annotations.workspaceDisplayName ?? meta.name ?? '',
    description: annotations.workspaceDescription ?? '',
    namespace,
    csiid: meta.labels?.[WORKSPACE_LABELS.csiid] ?? csiidFromWorkspaceNamespace(namespace) ?? '',
    phase: dw.status?.phase ?? 'Starting',
    mainUrl: dw.status?.mainUrl ?? '',
    editor: annotations.editorDisplayName ?? '',
    version: annotations.workspaceVersion ?? '',
    stack: meta.labels?.[WORKSPACE_LABELS.stack] ?? '',
    created: meta.creationTimestamp ? new Date(meta.creationTimestamp).toISOString() : '',
    limitcpu: resources.limitcpu,
    limitmemory: resources.limitmemory,
    storage: resources.storage,
  };
}

/** When the workspace last became ready; falls back to creation time. */
function runningSince(dw: DevWorkspaceResource): Date | string | undefined {
  const ready = dw.status?.conditions?.find(
    (c) => (c.type === 'Started' || c.type === 'Ready') && c.status === 'True',
  );
  return ready?.lastTransitionTime ?? dw.metadata?.creationTimestamp;
}

export class WorkspaceService {
  constructor(
    private readonly kube: KubeGateway,
    private readonly namespaces: NamespaceService,
    private readonly registry: DevfileRegistry,
    private readonly recorder: MetricsRecorder,
    private readonly options: WorkspaceServiceOptions,
    private readonly clock: Clock = systemClock,
    private readonly logger: Logger = silentLogger,
  ) {}

  private async listResources(soeid: string): Promise<DevWorkspaceResource[]> {
    const namespaces = await this.namespaces.listForUser(soeid);
    const lists = await Promise.all(
      namespaces.map((ns) => this.kube.list<DevWorkspaceResource>('DevWorkspace', ns.metadata?.name ?? '')),
    );
    return lists.flat();
  }

  async list(soeid: string): Promise<Workspace[]> {
    return (await this.listResources(soeid)).map(toWorkspace);
  }

  private async find(soeid: string, id: string): Promise<DevWorkspaceResource> {
    const found = (await this.listResources(soeid)).find((dw) => dw.metadata?.name === id);
    if (!found) throw new NotFoundError(`Workspace '${id}' not found`, 'WORKSPACE_NOT_FOUND');
    return found;
  }

  async get(soeid: string, id: string): Promise<Workspace> {
    return toWorkspace(await this.find(soeid, id));
  }

  private assertCanRunAnother(all: DevWorkspaceResource[]): void {
    const active = all.filter(isActive).length;
    if (active >= this.options.limits.maxRunning) {
      throw new WorkspaceRunCountExceededError(
        `You already have ${active} running workspace(s); the limit is ${this.options.limits.maxRunning}. Stop one first.`,
      );
    }
  }

  private assertCanCreateAnother(all: DevWorkspaceResource[]): void {
    if (all.length >= this.options.limits.maxTotal) {
      throw new WorkspaceCountExceededError(
        `You already have ${all.length} workspace(s); the limit is ${this.options.limits.maxTotal}. Delete one first.`,
      );
    }
    this.assertCanRunAnother(all);
  }

  async create(input: CreateWorkspaceInput): Promise<Workspace> {
    const { soeid, csiid } = input;
    this.assertCanCreateAnother(await this.listResources(soeid));

    const { name: namespace } = await this.namespaces.ensure(soeid, csiid);
    const { yaml, version } = await this.registry.getDevfile(input.devworkspaceValue, input.stackVersion);
    const devfile = applyEditorProfile(parseDevfile(yaml), input.editor);
    const body = buildDevWorkspaceObject({
      name: cleanWorkspaceName(input.devworkspaceValue),
      namespace,
      csiid,
      stack: input.devworkspaceValue,
      stackVersion: version,
      devfile,
      editor: input.editor,
      editorId: this.editorId(input.editor),
      devSpacesServiceFqdn: this.options.devSpacesServiceFqdn,
      repositoryUrl: input.repositoryUrl,
      repositoryBranch: input.repositoryBranch,
    });

    const created = await this.recorder.track(
      {
        soeid,
        csiid,
        eventtype: 'create',
        resourcetype: 'workspace',
        resourcename: body.metadata?.name ?? '',
        workspaceversion: version,
        editorname: input.editor,
        ...summarizeComponents(devfile.components),
      },
      () => this.kube.create<DevWorkspaceResource>('DevWorkspace', namespace, body),
    );
    this.logger.success('workspace.created', { soeid, namespace, workspace: created.metadata?.name });
    return toWorkspace(created);
  }

  async start(soeid: string, id: string): Promise<Workspace> {
    const dw = await this.find(soeid, id);
    if (dw.status?.phase === 'Running' || dw.status?.phase === 'Starting') return toWorkspace(dw);
    this.assertCanRunAnother(await this.listResources(soeid));
    return this.setStarted(soeid, dw, true);
  }

  async stop(soeid: string, id: string): Promise<Workspace> {
    const dw = await this.find(soeid, id);
    return this.setStarted(soeid, dw, false);
  }

  private async setStarted(soeid: string, dw: DevWorkspaceResource, started: boolean): Promise<Workspace> {
    const namespace = dw.metadata?.namespace ?? '';
    const name = dw.metadata?.name ?? '';
    const resources = summarizeComponents(dw.spec?.template?.components);
    const patched = await this.recorder.track(
      {
        soeid,
        csiid: toWorkspace(dw).csiid,
        eventtype: started ? 'start' : 'stop',
        resourcetype: 'workspace',
        resourcename: name,
        workspaceversion: dw.metadata?.annotations?.workspaceVersion ?? '',
        editorname: dw.metadata?.annotations?.editorDisplayName ?? '',
        duration: started ? '0 seconds' : durationSince(runningSince(dw), this.clock.now()),
        ...resources,
      },
      () => this.kube.setWorkspaceStarted(namespace, name, started),
    );
    this.logger.success(started ? 'workspace.started' : 'workspace.stopped', {
      soeid,
      namespace,
      workspace: name,
    });
    return toWorkspace({ ...dw, ...patched, metadata: { ...dw.metadata, ...patched.metadata } });
  }

  async delete(soeid: string, id: string): Promise<void> {
    const dw = await this.find(soeid, id);
    const namespace = dw.metadata?.namespace ?? '';
    const name = dw.metadata?.name ?? '';
    const resources = summarizeComponents(dw.spec?.template?.components);

    await this.recorder.track(
      {
        soeid,
        csiid: toWorkspace(dw).csiid,
        eventtype: 'delete',
        resourcetype: 'workspace',
        resourcename: name,
        workspaceversion: dw.metadata?.annotations?.workspaceVersion ?? '',
        editorname: dw.metadata?.annotations?.editorDisplayName ?? '',
        duration: durationSince(dw.metadata?.creationTimestamp, this.clock.now()),
        ...resources,
      },
      async () => {
        await this.kube.delete('DevWorkspace', namespace, name);
        // Workspaces created by the legacy flow reference a separate DevWorkspaceTemplate.
        for (const contribution of dw.spec?.contributions ?? []) {
          if (contribution.kubernetes?.name) {
            await this.kube.delete('DevWorkspaceTemplate', namespace, contribution.kubernetes.name);
          }
        }
      },
    );
    this.logger.success('workspace.deleted', { soeid, namespace, workspace: name });
  }

  private editorId(editor: EditorKey): string {
    return this.options.editors[editor];
  }
}

const pad2 = (n: number): string => String(n).padStart(2, '0');

/** Local time `2026-10-24 03:12:45.123`. */
export function formatLocalTime(d: Date): string {
  return (
    `${d.getFullYear()}-${pad2(d.getMonth() + 1)}-${pad2(d.getDate())} ` +
    `${pad2(d.getHours())}:${pad2(d.getMinutes())}:${pad2(d.getSeconds())}.${String(d.getMilliseconds()).padStart(3, '0')}`
  );
}

type Primitive = string | number | boolean | null | undefined;
const isPrimitive = (v: unknown): v is Primitive => v === null || v === undefined || typeof v !== 'object';
const isPlainObject = (v: unknown): v is Record<string, unknown> =>
  typeof v === 'object' && v !== null && !Array.isArray(v);

const oneLine = (s: string): string => s.replace(/\r?\n/g, '\\n');

/** Inline value: bare when simple, quoted when it contains spaces or `=`. */
function inlineValue(v: Primitive): string {
  if (typeof v !== 'string') return String(v);
  const s = oneLine(v);
  return /^[^\s"=]+$/.test(s) ? s : JSON.stringify(s);
}

/** Value on its own line: strings as they are, arrays as compact JSON. */
function blockValue(v: unknown): string {
  if (typeof v === 'string') return oneLine(v);
  if (Array.isArray(v)) return JSON.stringify(v);
  return String(v);
}

function renderBlock(obj: Record<string, unknown>, indent: string): string[] {
  const entries = Object.entries(obj).filter(([, v]) => v !== undefined);
  const width = Math.max(
    0,
    ...entries.filter(([, v]) => !isPlainObject(v) || Object.keys(v).length === 0).map(([k]) => k.length),
  );
  const lines: string[] = [];
  for (const [key, value] of entries) {
    if (isPlainObject(value) && Object.keys(value).length > 0) {
      lines.push(`${indent}${key}:`);
      lines.push(...renderBlock(value, `${indent}  `));
    } else {
      const text = isPlainObject(value) ? '{}' : blockValue(value);
      lines.push(`${indent}${key.padEnd(width)} : ${text}`);
    }
  }
  return lines;
}

function canInline(fields: [string, unknown][]): boolean {
  if (fields.length > MAX_INLINE_FIELDS) return false;
  let total = 0;
  for (const [k, v] of fields) {
    if (!isPrimitive(v)) return false;
    const text = inlineValue(v);
    if (text.length > MAX_INLINE_VALUE) return false;
    total += k.length + text.length + 3;
  }
  return total <= MAX_INLINE_TOTAL;
}

/** `GET    /api/v1/x -> 200 (12 ms)` for the per-request log line, plus the fields that are not part of it. */
function requestMessage(
  fields: Record<string, unknown>,
): { message: string; rest: Record<string, unknown> } | undefined {
  const { method, path, status, ms, ...rest } = fields;
  if (typeof method !== 'string' || typeof path !== 'string' || typeof status !== 'number') return undefined;
  const took = typeof ms === 'number' ? ` (${ms} ms)` : '';
  return { message: `${method.padEnd(6)} ${path} -> ${status}${took}`, rest };
}

/** One log entry as text. Multi-line entries end with a blank line so that entries stay visually separate. */
export function formatPretty(entry: LogEntry, color: boolean): string {
  const head = `${formatLocalTime(entry.time)} | ${BADGE[entry.kind]} | `;
  const request = entry.event === 'request' ? requestMessage(entry.fields) : undefined;
  const fields = Object.entries(request ? request.rest : entry.fields).filter(([, v]) => v !== undefined);
  const lines: string[] = [];

  if (fields.length === 0 && !request) {
    lines.push(`${head}${entry.event}`);
  } else if (canInline(fields)) {
    const inline = fields.map(([k, v]) => `${k}=${inlineValue(v as Primitive)}`).join('  ');
    const text = [request?.message, inline].filter(Boolean).join('  ');
    lines.push(`${head}${entry.event.padEnd(EVENT_WIDTH)} | ${text}`);
  } else {
    lines.push(
      request ? `${head}${entry.event.padEnd(EVENT_WIDTH)} | ${request.message}` : `${head}${entry.event}`,
    );
    lines.push(...renderBlock(Object.fromEntries(fields), BLOCK_INDENT));
    lines.push(''); // blank line after a multi-line entry
  }

  const paint = (line: string): string =>
    color && line !== '' ? `${COLORS[entry.kind]}${line}${RESET}` : line;
  return lines.map(paint).join('\n');
}

/src/utils/logger.ts
import { formatPretty, type LogKind } from './log-format.js';

export type LogLevel = 'debug' | 'info' | 'warn' | 'error' | 'silent';
export type LogFormat = 'json' | 'pretty';

const ORDER: Record<LogLevel, number> = { debug: 10, info: 20, warn: 30, error: 40, silent: 100 };
const SENSITIVE = /token|password|authorization|secret|pat$|credential|cookie/i;

export type LogFields = Record<string, unknown>;

export interface Logger {
  debug(event: string, fields?: LogFields): void;
  info(event: string, fields?: LogFields): void;
  /** Something finished successfully (a call, a created resource): shown green in the terminal. */
  success(event: string, fields?: LogFields): void;
  warn(event: string, fields?: LogFields): void;
  error(event: string, fields?: LogFields): void;
  child(bindings: LogFields): Logger;
}

export type LogSink = (line: string) => void;

export interface LoggerOptions {
  /** `json` (one JSON object per line, for log collectors; the default here) or `pretty` (terminal). */
  format?: LogFormat;
  /** ANSI colours for the pretty format: error red, warn orange, success green, everything else white. */
  color?: boolean;
  /** Clock, replaceable in tests. */
  now?: () => Date;
}

export function redact(value: unknown, depth = 0): unknown {
  if (depth > 5 || value === null || typeof value !== 'object') return value;
  if (value instanceof Error) return { name: value.name, message: value.message };
  if (Array.isArray(value)) return value.map((v) => redact(v, depth + 1));
  return Object.fromEntries(
    Object.entries(value as Record<string, unknown>).map(([k, v]) => [
      k,
      SENSITIVE.test(k) ? '[redacted]' : redact(v, depth + 1),
    ]),
  );
}

export function createLogger(
  level: LogLevel = 'info',
  sink: LogSink = (line) => process.stdout.write(`${line}\n`),
  bindings: LogFields = {},
  options: LoggerOptions = {},
): Logger {
  const format = options.format ?? 'json';
  const now = options.now ?? (() => new Date());

  const write = (kind: LogKind, event: string, fields?: LogFields): void => {
    // `success` is an info-level message that is shown in green
    const severity: Exclude<LogLevel, 'silent'> = kind === 'success' ? 'info' : kind;
    if (ORDER[severity] < ORDER[level]) return;
    const merged = {
      ...(redact(bindings) as LogFields),
      ...(redact(fields ?? {}) as LogFields),
    };
    const time = now();
    if (format === 'pretty') {
      sink(formatPretty({ time, kind, event, fields: merged }, options.color === true));
      return;
    }
    sink(
      JSON.stringify({
        time: time.toISOString(),
        level: severity,
        ...(kind === 'success' ? { outcome: 'success' } : {}),
        event,
        ...merged,
      }),
    );
  };

  return {
    debug: (e, f) => write('debug', e, f),
    info: (e, f) => write('info', e, f),
    success: (e, f) => write('success', e, f),
    warn: (e, f) => write('warn', e, f),
    error: (e, f) => write('error', e, f),
    child: (b) => createLogger(level, sink, { ...bindings, ...b }, options),
  };
}

export const silentLogger: Logger = createLogger('silent');

/**

export async function startIntegration(
  env: Record<string, string> = {},
  options: { deployKube?: InMemoryKube; logger?: Logger } = {},

import { describe, expect, it } from 'vitest';
import {
  COLORS,
  RESET,
  formatLocalTime,
  formatPretty,
  type LogEntry,
  type LogKind,
} from '../../../src/utils/log-format.js';

const time = new Date(2026, 0, 2, 3, 4, 5, 678); // local time, as the formatter prints it
const T = '2026-01-02 03:04:05.678';
const entry = (kind: LogKind, event: string, fields: Record<string, unknown> = {}): LogEntry => ({
  time,
  kind,
  event,
  fields,
});
const plain = (e: LogEntry) => formatPretty(e, false);

describe('colours: errors red, warnings orange, successes green, everything else white', () => {
  it('uses exactly these ANSI codes', () => {
    expect(COLORS.error).toBe('\u001b[31m'); // red
    expect(COLORS.warn).toBe('\u001b[38;5;208m'); // orange
    expect(COLORS.success).toBe('\u001b[32m'); // green
    expect(COLORS.info).toBe('\u001b[97m'); // bright white
    expect(COLORS.debug).toBe(COLORS.info); // white as well
  });

  it.each(['error', 'warn', 'success', 'info', 'debug'] as const)(
    '%s line is painted in its colour',
    (kind) => {
      const out = formatPretty(entry(kind, 'some.event', { a: 1 }), true);
      expect(out.startsWith(COLORS[kind])).toBe(true);
      expect(out.endsWith(RESET)).toBe(true);
    },
  );

  it('every line of a multi-line entry is painted on its own, the separating blank line is not', () => {
    const out = formatPretty(entry('error', 'boom', { a: { b: 1 }, c: 2 }), true);
    const lines = out.split('\n');
    expect(lines.length).toBeGreaterThan(3);
    expect(lines.at(-1)).toBe('');
    for (const line of lines.slice(0, -1)) {
      expect(line.startsWith(COLORS.error), line).toBe(true);
      expect(line.endsWith(RESET), line).toBe(true);
      expect(line.slice(COLORS.error.length, -RESET.length)).not.toContain('\u001b');
    }
  });

  it('prints no escape codes at all when colour is off', () => {
    for (const kind of ['error', 'warn', 'success', 'info', 'debug'] as const) {
      expect(plain(entry(kind, 'e', { a: { b: 1 } }))).not.toContain('\u001b');
    }
  });
});

describe('layout', () => {
  it('formats local time as YYYY-MM-DD HH:mm:ss.SSS', () => {
    expect(formatLocalTime(time)).toBe(T);
    expect(formatLocalTime(new Date(2026, 10, 9, 23, 59, 1, 5))).toBe('2026-11-09 23:59:01.005');
  });

  it('a bare event is one line: time | LEVEL | event', () => {
    expect(plain(entry('info', 'server.shutdown'))).toBe(`${T} | INFO  | server.shutdown`);
  });

  it('level badges all have the same width so the columns line up', () => {
    const widths = (['error', 'warn', 'success', 'info', 'debug'] as const).map((k) =>
      plain(entry(k, 'e')).indexOf(' | e'),
    );
    expect(new Set(widths).size).toBe(1);
    expect(plain(entry('error', 'e'))).toContain('| ERROR |');
    expect(plain(entry('warn', 'e'))).toContain('| WARN  |');
    expect(plain(entry('success', 'e'))).toContain('| OK    |');
    expect(plain(entry('debug', 'e'))).toContain('| DEBUG |');
  });

  it('a few short fields stay on the same line, as key=value separated by two spaces', () => {
    expect(plain(entry('warn', 'metrics.columns_missing', { table: 't1', missing: 'a,b' }))).toBe(
      `${T} | WARN  | ${'metrics.columns_missing'.padEnd(30)} | table=t1  missing=a,b`,
    );
  });

  it('quotes inline values that contain spaces or =, and escapes newlines', () => {
    const out = plain(
      entry('error', 'x', { error: 'cluster is down', eq: 'a=b', multi: 'l1\nl2', bare: 'ok-1' }),
    );
    expect(out).toContain('error="cluster is down"');
    expect(out).toContain('eq="a=b"');
    expect(out).toContain('multi=l1\\nl2'); // the newline becomes a visible \n, so the entry stays on one line
    expect(out).toContain('bare=ok-1');
    expect(out.split('\n')).toHaveLength(1);
  });

  it('shows the per-request line as: METHOD path -> status (ms) plus the ids', () => {
    const out = plain(
      entry('success', 'request', {
        method: 'GET',
        path: '/api/v1/pp1/workspaces',
        status: 200,
        ms: 12,
        requestId: 'r-1',
        soeid: 'pp1',
      }),
    );
    expect(out).toBe(
      `${T} | OK    | ${'request'.padEnd(30)} | GET    /api/v1/pp1/workspaces -> 200 (12 ms)  requestId=r-1  soeid=pp1`,
    );
  });

  it('leaves out fields that have no value (a request without a user)', () => {
    const out = plain(
      entry('success', 'request', { method: 'GET', path: '/healthz', status: 200, ms: 1, soeid: undefined }),
    );
    expect(out).not.toContain('soeid');
    expect(out).not.toContain('undefined');
  });

  it('puts nested and long data on indented lines with aligned colons, and ends with a blank line', () => {
    const out = plain(
      entry('success', 'server.listening', {
        port: 8080,
        cluster: 'https://x',
        editors: { vscode: 'a', intellij: 'b' },
        postgres: 'disabled',
        empty: {},
        list: [1, 2],
        gone: undefined,
      }),
    );
    expect(out).toBe(
      [
        `${T} | OK    | server.listening`,
        '    port     : 8080',
        '    cluster  : https://x',
        '    editors:',
        '      vscode   : a',
        '      intellij : b',
        '    postgres : disabled',
        '    empty    : {}',
        '    list     : [1,2]',
        '',
      ].join('\n'),
    );
  });

  it('switches to the indented layout for many fields, or a long value', () => {
    const many = plain(entry('info', 'e', { a: 1, b: 2, c: 3, d: 4, e: 5, f: 6, g: 7 }));
    expect(many.split('\n')[0]).toBe(`${T} | INFO  | e`);
    expect(many).toContain('    g : 7');

    const long = plain(entry('error', 'e', { error: 'x'.repeat(100) }));
    expect(long.split('\n')[0]).toBe(`${T} | ERROR | e`);
    expect(long).toContain(`    error : ${'x'.repeat(100)}`);
  });

  it('an error with a request id and a message gets its own block, easy to read', () => {
    const out = plain(
      entry('error', 'request.failed', {
        requestId: '7989eb27-2d84-4d15-aa0b-95003ff51f85',
        code: 'UPSTREAM_ERROR',
        error: 'Devfile registry catalog: No response received from server',
      }),
    );
    expect(out).toBe(
      [
        `${T} | ERROR | request.failed`,
        '    requestId : 7989eb27-2d84-4d15-aa0b-95003ff51f85',
        '    code      : UPSTREAM_ERROR',
        '    error     : Devfile registry catalog: No response received from server',
        '',
      ].join('\n'),
    );
  });

  it('treats a "request" event without method/path/status as an ordinary entry', () => {
    expect(plain(entry('info', 'request', { note: 'hi' }))).toBe(
      `${T} | INFO  | ${'request'.padEnd(30)} | note=hi`,
    );
  });
});

import { describe, expect, it } from 'vitest';
import { createLogger, redact } from '../../../src/utils/logger.js';

function capture(level: Parameters<typeof createLogger>[0] = 'info') {
  const lines: Record<string, unknown>[] = [];
  return { lines, logger: createLogger(level, (l) => lines.push(JSON.parse(l))) };
}

describe('logger', () => {
  it('writes one JSON line with level, event and fields', () => {
    const { lines, logger } = capture();
    logger.info('hello', { a: 1 });
    expect(lines).toHaveLength(1);
    expect(lines[0]).toMatchObject({ level: 'info', event: 'hello', a: 1 });
    expect(typeof lines[0]?.time).toBe('string');
  });

  it('filters below the configured level', () => {
    const { lines, logger } = capture('warn');
    logger.debug('d');
    logger.info('i');
    logger.warn('w');
    logger.error('e');
    expect(lines.map((l) => l.event)).toEqual(['w', 'e']);
  });

  it('is silent when asked', () => {
    const { lines, logger } = capture('silent');
    logger.error('e');
    expect(lines).toHaveLength(0);
  });

  it('child loggers carry bindings', () => {
    const { lines, logger } = capture();
    logger.child({ requestId: 'r1' }).info('x', { b: 2 });
    expect(lines[0]).toMatchObject({ requestId: 'r1', b: 2 });
  });

  it('redacts sensitive keys, nested and in arrays', () => {
    const { lines, logger } = capture();
    logger.info('x', {
      token: 'ghp_secret',
      nested: { password: 'p', ok: 1 },
      list: [{ authorization: 'Bearer x' }],
    });
    expect(lines[0]).toMatchObject({
      token: '[redacted]',
      nested: { password: '[redacted]', ok: 1 },
      list: [{ authorization: '[redacted]' }],
    });
    expect(JSON.stringify(lines[0])).not.toContain('ghp_secret');
  });

  it('success is an info-level line marked as a success, and hidden when only warnings are wanted', () => {
    const { lines, logger } = capture();
    logger.success('workspace.created', { workspace: 'w1' });
    expect(lines[0]).toMatchObject({
      level: 'info',
      outcome: 'success',
      event: 'workspace.created',
      workspace: 'w1',
    });
    const quiet = capture('warn');
    quiet.logger.success('workspace.created');
    expect(quiet.lines).toHaveLength(0);
  });

  it('plain info lines carry no outcome', () => {
    const { lines, logger } = capture();
    logger.info('x');
    expect(lines[0]).not.toHaveProperty('outcome');
  });

  describe('pretty format (terminal)', () => {
    const now = () => new Date(2026, 0, 2, 3, 4, 5, 678);
    const pretty = (level: Parameters<typeof createLogger>[0] = 'info', color = true) => {
      const out: string[] = [];
      return { out, logger: createLogger(level, (l) => out.push(l), {}, { format: 'pretty', color, now }) };
    };

    it('paints each kind in its colour: error red, warn orange, success green, info and debug white', () => {
      const { out, logger } = pretty('debug');
      logger.error('e');
      logger.warn('w');
      logger.success('s');
      logger.info('i');
      logger.debug('d');
      expect(out).toEqual([
        '\u001b[31m2026-01-02 03:04:05.678 | ERROR | e\u001b[0m',
        '\u001b[38;5;208m2026-01-02 03:04:05.678 | WARN  | w\u001b[0m',
        '\u001b[32m2026-01-02 03:04:05.678 | OK    | s\u001b[0m',
        '\u001b[97m2026-01-02 03:04:05.678 | INFO  | i\u001b[0m',
        '\u001b[97m2026-01-02 03:04:05.678 | DEBUG | d\u001b[0m',
      ]);
    });

    it('writes one sink call per entry, plain when colour is off', () => {
      const { out, logger } = pretty('info', false);
      logger.info('a', { n: 1 });
      logger.warn('b');
      expect(out).toEqual([
        `2026-01-02 03:04:05.678 | INFO  | ${'a'.padEnd(30)} | n=1`,
        '2026-01-02 03:04:05.678 | WARN  | b',
      ]);
    });

    it('applies the level filter, bindings of child loggers, and redaction', () => {
      const { out, logger } = pretty('info', false);
      logger.debug('hidden');
      logger.child({ requestId: 'r1' }).info('x', { token: 'ghp_secret', ok: 1 });
      expect(out).toHaveLength(1);
      expect(out[0]).toContain('requestId=r1');
      expect(out[0]).toContain('token=[redacted]');
      expect(out[0]).not.toContain('ghp_secret');
    });

    it('child loggers keep the format and colour of their parent', () => {
      const { out, logger } = pretty('info', true);
      logger.child({ a: 1 }).error('boom');
      expect(out[0]?.startsWith('\u001b[31m')).toBe(true);
    });

    it('the default is still JSON, so existing log collectors keep working', () => {
      const lines: string[] = [];
      createLogger('info', (l) => lines.push(l)).info('x');
      expect(JSON.parse(lines[0] as string)).toMatchObject({ event: 'x', level: 'info' });
    });
  });

  it('serialises errors as name and message only', () => {
    expect(redact(new Error('bad'))).toEqual({ name: 'Error', message: 'bad' });
  });

  it('stops redacting past a sane depth', () => {
    const deep = { a: { b: { c: { d: { e: { f: { g: 1 } } } } } } };
    expect(redact(deep)).toEqual(deep);
  });
});
