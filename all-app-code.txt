# Workspace Manager API and code map

Every endpoint starts with `/api/v1`. Unversioned URLs return 404. There is no legacy
router, compatibility switch, or archived implementation to maintain.


Source files are TypeScript; the build emits ESM `.js` files in `dist/`.
`npm start` runs `dist/index.js`, which calls the application factory in `dist/app.js`.
To debug a route, follow its router to the matching controller and service.

## Endpoints

Paths below include the version prefix. Use `Authorization: Bearer <jwt>` for all
routes except login and probes. The existing login issues an administrator token;
regular user tokens can access only their own `:soeid` resources.

| Method                 | Path                                  | Purpose                                               |
| ---------------------- | ------------------------------------- | ----------------------------------------------------- |
| GET                    | `/api/v1/healthz`                     | Liveness; does not contact dependencies               |
| GET                    | `/api/v1/readyz`                      | Kubernetes, deployment cluster and database readiness |
| POST                   | `/api/v1/login`                       | Existing username/password login                      |
| GET                    | `/api/v1/catalog`                     | Stack catalog                                         |
| GET, POST              | `/api/v1/:soeid/projects`             | List or provision workspace projects                  |
| GET, POST              | `/api/v1/:soeid/workspaces`           | List or create workspaces                             |
| GET, DELETE            | `/api/v1/:soeid/workspaces/:id`       | Read or terminate a workspace                         |
| POST                   | `/api/v1/:soeid/workspaces/:id/start` | Start a workspace                                     |
| POST                   | `/api/v1/:soeid/workspaces/:id/stop`  | Stop a workspace                                      |
| GET                    | `/api/v1/:soeid/pats`                 | List PATs                                             |
| GET, POST, PUT, DELETE | `/api/v1/:soeid/pats/:tokenName`      | View, create, update or delete a PAT                  |
| GET, POST, PUT, DELETE | `/api/v1/:soeid/gitconfig`            | View, upsert or delete Git configuration              |
| GET, POST, DELETE      | `/api/v1/:soeid/deployment-projects`  | List, provision or delete deployment projects         |
| PUT                    | `/api/v1/support/resources`           | Administrator resource reconciliation                 |
| GET, PATCH             | `/api/v1/configuration`               | Administrator runtime settings                        |
| GET                    | `/api/v1/logs`                        | Administrator log search and formatted output         |

Project/workspace/deployment-project lists accept an optional `?csiid=177398`
filter. Identifiers use the application's existing names: **SOEID** and **CSIID**.
Stacks come from the configured registry and are shared across projects.

`POST /api/v1/:soeid/projects` and `POST /api/v1/:soeid/deployment-projects` accept
`{ "csiid": "177398" }`. They reuse the existing provisioning services, including
roles, bindings, quotas, limit ranges, workspace network policies and proxy configuration.
Creation returns 201; an existing project returns 200. Deployment projects use the
configured deployment cluster. Deleting deployment projects retains the existing
behavior: delete all matching deployment projects for that user.

PAT writes accept `{ "csiid": "177398", "token": "..." }`. PAT reads and deletes use
`?csiid=177398`. Git configuration writes accept `{ "csiid": "177398", "content": "..." }`;
reads and deletes use the same query parameter. POST and PUT Git configuration both upsert.

## Creating a workspace

`POST /api/v1/:soeid/workspaces` accepts the existing dashboard payload:

```json
{
  "devworkspaceValue": "citi-optimus",
  "csiid": "177398",
  "editorType": "che-code",
  "stackVersion": "8.1.1",
  "repositoryUrl": "https://github.com/acme/project.git",
  "repositoryCheckoutBranch": "optimus"
}
```

The first four fields are required. `editorType` accepts `che-code`, `che-idea`, or
`che-goland`. The previously documented `editor` and `repositoryBranch` names also
remain accepted; conflicting aliases are rejected. Invalid nonempty values produce
400 with a `details` array naming the offending fields.

Repository URL and checkout branch are optional. Omitted, empty or null values do
not prevent workspace creation. Without a URL, no request-supplied project is added
and Git setup is skipped. Stack-provided projects remain intact. With a URL, the
request-supplied project is named `default-project`, cloned by Dev Spaces under
`/projects/default-project`. Branch selection happens in a post-start command so
an unavailable branch does not fail that command. It tries the requested branch,
then its remote tracking branch, then creates a local branch if no remote exists.
With no branch supplied, it tries `main`, then `master`, retaining the current
checkout if neither is available. Git failures are logged and the setup script
returns success. Actual project cloning still depends on Dev Spaces and repository
access; the API response confirms resource creation, not completed cloning.

The post-start setup runs in the stack's `tools` container, or its first container
when `tools` is absent. Existing commands and lifecycle events are preserved. For
`citi-optimus`, it also makes `/home/user/mta-analyzer-rpc-linux-amd64/mta-analyzer-rpc`
executable and updates `mta-core.analyzerPath` in
`/checode/remote/data/Machine/settings.json` using `jq`. Missing files, missing `jq`,
or configuration errors are logged without stopping setup. Other stacks skip MTA
configuration. Request values are safely passed as environment variables to the
workspace command; the API server needs no repository environment variables.

Inspect `/tmp/workspace-setup-debug.log` inside the workspace for Git and MTA setup
details. These operations execute in the workspace pod, so their runtime output is
separate from the API server's logs.

Failed API requests have a `request.failed` log containing the error's source and
message. Their `request` summary uses that same source, rather than the response
listener in `app.ts`. Successful request summaries identify the access-log function.

## Editor definition access

The DevWorkspace operator fetches the IDE contribution independently of the API
server. It needs a reachable editor devfile URL, not a browser-authenticated
dashboard API URL. New workspaces use:

```text
<DEV_SPACES_SERVICE_FQDN>/plugin-registry/v3/plugins/<editor-id>/devfile.yaml
```

Set `EDITOR_REGISTRY_URL` to your actual internal plugin registry base, including
`/v3`, when it differs from this default. The startup summary prints the selected
registry. This is separate from `DEVREG_URL`, which supplies workspace stacks.
The selected registry must be reachable from the DevWorkspace operator's cluster;
Workspace Manager's token is not attached to the stored URL.

An HTTP 403 while resolving `ide` means the editor request was denied. Updating
the app fixes URLs for newly created workspaces; existing failed DevWorkspace
resources retain their stored contribution until updated or recreated. The API's
creation response confirms the resource exists, not that the operator has fetched
the editor or started the workspace successfully.

The registry URI form follows the DevWorkspace example in the
[Red Hat Dev Spaces user guide](https://docs.redhat.com/en/documentation/red_hat_openshift_dev_spaces/3.8/pdf/user_guide/Red_Hat_OpenShift_Dev_Spaces-3.8-User_guide-en-US.pdf).

## Repairing or updating Kubernetes resources

Restore existing defaults on a user's workspace project:

```http
PUT /api/v1/support/resources
Authorization: Bearer <admin-jwt>
Content-Type: application/json

{ "soeid": "pp58386", "csiid": "177398", "target": "workspace" }
```

Use `"target": "deployment"` for the deployment cluster/project. The project must
exist and its owner annotation must match the requested SOEID. Omitting `resources`
reapplies the existing provisioning defaults, including network/proxy resources for
workspace projects. This repairs missing resources without recreating a project.

To create or replace selected resources, supply their manifests:

```json
{
  "soeid": "pp58386",
  "csiid": "177398",
  "target": "workspace",
  "resources": [
    {
      "kind": "ResourceQuota",
      "metadata": { "name": "custom-compute-quota" },
      "spec": { "hard": { "requests.cpu": "4", "requests.memory": "8Gi" } }
    }
  ]
}
```

Allowed kinds: `Role`, `RoleBinding`, `ResourceQuota`, `LimitRange`, `ClusterRole`,
`ClusterRoleBinding`. `metadata` accepts only `name`: the server sets namespace and
API version. Cluster roles/bindings are cluster-scoped and apply to the selected
workspace or deployment cluster. Kubernetes has no cluster-scoped LimitRange or
ResourceQuota; those apply to the selected user's namespace on that cluster.
Kubernetes validates manifest rules, subjects, role references and specs.

Operations run sequentially. If one fails, earlier successful updates remain;
correct the error and retry. Existing Kubernetes permissions still apply. The
service account needs explicit cluster-RBAC write privileges for cluster-scoped
operations; this change does not automatically expand deployment privileges.

## Runtime settings

`GET /api/v1/configuration` returns settings with passwords and tokens redacted.
`PATCH /api/v1/configuration` accepts any nonempty subset of:

```json
{
  "DEVREG_URL": "https://registry.example.com",
  "NOTIFICATION_MAIL_URL": "https://mail.example.com",
  "NOTIFICATION_EMAIL_USERNAME": "workspace-mailer",
  "NOTIFICATION_EMAIL_PASSWORD": "replacement-password",
  "MAX_RUNNING_WORKSPACES": 3,
  "MAX_TOTAL_WORKSPACES": 5,
  "CLUSTER_API_URL": "https://api.cluster.example.com:6443",
  "CLUSTER_TOKEN": "replacement-token",
  "DEPLOY_CLUSTER_API_URL": "https://api.deploy.example.com:6443",
  "DEPLOY_CLUSTER_TOKEN": "replacement-deployment-token"
}
```

Changes take effect for subsequent requests in this process. Production adapters
are rebuilt so updated URLs and credentials are used; the database pool remains
open. In-flight operations can finish using their original services. Updates are
validated before replacement. Running limits cannot exceed total limits; changing
a cluster URL requires its token in the same request.

**Persistence is process-lifetime:** this API does not rewrite deployment environment
variables, Kubernetes Secrets or `.env` files. Set the same values in deployment
configuration to retain them after restart and across replicas. Responses explicitly
report `"persistence": "process-lifetime"`. No arbitrary environment-variable writes
are supported. Stored secret values are never returned by this API.

## Troubleshooting with daily logs

Production writes one redacted JSON entry per line to `logs/app-YYYY-MM-DD.log`.
Each entry includes `timestamp` (`YYYY-MM-DD HH:MM:SS` in the process's local timezone),
`file`, and `function`. The ISO `time` field remains available for precise filtering.
Successful and informational console/log-search output uses
`[timestamp] [Workspace] Created workspace resource ...` and similar category-based
sentences. Source locations are omitted from routine messages. Warnings and errors
use `[timestamp] [filename:line] [functionName]` with the error message, status and
correlation details. Continuation lines carry the same prefix. Structured JSON files
retain event names, fields and source metadata for every severity. Source details
come from the log call, or the original error stack when
an Error object is provided. Application callbacks have descriptive function names;
top-level execution without a named function is identified as `module`.
Client failures (400/401/403/404/409) are logged as warnings with status, error code,
message, request ID, and source location. Server failures are logged as errors.
JWT errors distinguish expired, not-yet-valid, invalid-signature, and malformed tokens.
Use the Workspace Manager token from `/api/v1/login` for these APIs; cluster tokens
authenticate the server's Kubernetes requests and are separate credentials.
Dates are UTC and files switch automatically at midnight. Console formatting is
independent. `LOG_DIRECTORY` selects the directory. Mount a writable volume there
when using a read-only filesystem, and persistent storage if logs must survive pod
replacement. Log files are not committed. Retention is managed by the deployment.

```http
GET /api/v1/logs?days=2&level=error&search=namespace&limit=100&format=text
Authorization: Bearer <admin-jwt>
```

Supported query parameters:

| Parameter   | Meaning                                           |
| ----------- | ------------------------------------------------- |
| `days`      | Rolling last 1–31 days; default 1                 |
| `limit`     | Maximum 1–1000 results; default 200               |
| `level`     | `debug`, `info`, `warn`, or `error`               |
| `search`    | Case-insensitive text match, up to 200 characters |
| `requestId` | Exact request correlation ID                      |
| `soeid`     | Exact user match                                  |
| `format`    | `json` (default) or readable `text`               |

Results are newest first and include the queried range and a `truncated` indicator.
Search scans at most 100,000 lines per request. Missing files and malformed lines are
ignored. Search uses literal text filtering. The API searches this
instance's files; aggregate logs externally when running multiple replicas.

/** `'1524'` → `1524`, `"a b"` → `a b`; anything not wrapped in one matching pair of quotes is untouched. */
export function unquote(value: string): string {
  const match = /^(['"])(.*)\1$/s.exec(value);
  return match?.[2] ?? value;
}

/** `che-code` → `che-incubator/che-code/latest`; `che-incubator/che-code/latest` is kept as it is. */
export function normalizeEditorId(value: string): string {
  const v = value.trim();
  return v.includes('/') ? v : `che-incubator/${v}/latest`;
}

/** `https://api.namctigtd001d.ecs.dyn.example.net:6443` → `namctigtd001d`. */
export function clusterNameOf(apiUrl: string): string | undefined {
  try {
    const host = new URL(apiUrl).hostname;
    return host.startsWith('api.') ? host.split('.')[1] : undefined;
  } catch {
    return undefined;
  }
}

/** `https://api.<rest>:6443` → `https://devspaces.apps.<rest>` (the usual Dev Spaces dashboard host). */
export function deriveDevSpacesFqdn(apiUrl: string): string {
  try {
    const host = new URL(apiUrl).hostname;
    return host.startsWith('api.') ? `https://devspaces.apps.${host.slice('api.'.length)}` : '';
  } catch {
    return '';
  }
}

export interface FoundToken {
  /** The environment variable the token came from (never the token itself). */
  name: string;
  value: string;
}

/**
 * Finds the bearer token for a cluster by variable name: `<prefix><id>`, e.g. devSpacesClusterToken001d for the cluster
 * `namctigtd001d` (the id must be the end of the cluster name). A variable without an id (`<prefix>`) fits any cluster.
 * Tokens that belong to another cluster are ignored, so a leftover `devOpsToken004d` is never sent to cluster 001d.
 */
export function findClusterToken(
  env: Record<string, string | undefined>,
  prefix: string,
  apiUrl: string,
): FoundToken | undefined {
  const cluster = (clusterNameOf(apiUrl) ?? '').toLowerCase();
  const fits = Object.keys(env)
    .filter((k) => k.toLowerCase().startsWith(prefix.toLowerCase()) && env[k])
    .filter((k) => {
      const id = k.slice(prefix.length).toLowerCase();
      return id === '' || (cluster !== '' && cluster.endsWith(id));
    });
  if (fits.length > 1) {
    throw new Error(
      `Invalid configuration:\n  - several variables fit one cluster token: ${fits.join(', ')}`,
    );
  }
  const name = fits[0];
  return name ? { name, value: env[name] as string } : undefined;
}

/** What the service understood from its environment, for the startup log. Contains no secret values. */
export function startupSummary(c: AppConfig): Record<string, unknown> {
  const auth = (tokenVar: string | undefined, kubeconfig: string | undefined): string =>
    tokenVar
      ? `bearer token from ${tokenVar}`
      : kubeconfig
        ? 'kubeconfig file'
        : 'default kubeconfig / pod service account';
  return {
    port: c.port,
    nodeEnv: c.nodeEnv,
    cluster: c.cluster.apiUrl,
    clusterAuth: auth(c.cluster.tokenVar, c.cluster.kubeconfigPath),
    deployCluster: c.cluster.deployApiUrl,
    deployClusterAuth:
      c.cluster.deployApiUrl === c.cluster.apiUrl
        ? 'same cluster'
        : auth(c.cluster.deployTokenVar, c.cluster.kubeconfigPath),
    devSpacesFqdn: c.cluster.devSpacesServiceFqdn,
    devfileRegistry: c.devreg.url,
    editorRegistry:
      c.devreg.editorRegistryUrl ?? `${c.cluster.devSpacesServiceFqdn.replace(/\/$/, '')}/plugin-registry/v3`,
    editors: c.devreg.editors,
    clusterTls: c.cluster.tlsRejectUnauthorized
      ? 'certificates verified'
      : 'NOT verified (NODE_TLS_REJECT_UNAUTHORIZED=0)',
    postgres: c.postgres.enabled
      ? {
          host: c.postgres.host,
          port: c.postgres.port,
          database: c.postgres.database,
          table: c.postgres.table,
        }
      : 'disabled',
  };
}

/** Parse and validate the environment once, at startup. Throws a readable error listing every problem. */
export function loadConfig(env: NodeJS.ProcessEnv = process.env): AppConfig {
  // An exported-but-empty variable (`FOO=`) is treated as unset. Values that still carry their shell quotes
  // (`'1524'`, `'metrics."devspaces-metrics-dev"'` from a .env file or a pasted export line) are unwrapped.
  const cleaned = Object.fromEntries(
    Object.entries(env)
      .filter(([, v]) => v !== undefined && v !== '')
      .map(([k, v]) => [k, unquote(v as string)]),
  );
  const parsed = schema.safeParse(cleaned);
  if (!parsed.success) {
    const problems = parsed.error.issues.map((i) => `${i.path.join('.') || '(root)'}: ${i.message}`);
    throw new Error(`Invalid configuration:\n  - ${problems.join('\n  - ')}`);
  }
  const e = parsed.data;
  if (e.POSTGRES_ENABLED && (!e.POSTGRES_DATABASE || !e.POSTGRES_USER)) {
    throw new Error(
      'Invalid configuration:\n  - POSTGRES_DATABASE and POSTGRES_USER are required when POSTGRES_ENABLED=true',
    );
  }

  const deployApiUrl = e.DEPLOY_CLUSTER_API_URL ?? e.CLUSTER_API_URL;
  const separateDeployCluster = deployApiUrl !== e.CLUSTER_API_URL;
  const main = e.CLUSTER_TOKEN
    ? { name: 'CLUSTER_TOKEN', value: e.CLUSTER_TOKEN }
    : findClusterToken(cleaned, 'devSpacesClusterToken', e.CLUSTER_API_URL);
  const deploy = !separateDeployCluster
    ? undefined
    : e.DEPLOY_CLUSTER_TOKEN
      ? { name: 'DEPLOY_CLUSTER_TOKEN', value: e.DEPLOY_CLUSTER_TOKEN }
      : findClusterToken(cleaned, 'devOpsToken', deployApiUrl);
  if (separateDeployCluster && !deploy && !e.KUBECONFIG_PATH) {
    throw new Error(
      `Invalid configuration:\n  - DEPLOY_CLUSTER_API_URL is set to a different cluster but no token was found for it ` +
        `(set DEPLOY_CLUSTER_TOKEN, or devOpsToken<id> where <id> ends the cluster name)`,
    );
  }

  return {
    port: e.PORT,
    nodeEnv: e.NODE_ENV,

/** Wire services to production adapters or test doubles. */
export function buildContainer(
  config: AppConfig,
  logger: Logger,
  deps: Dependencies,
  refresh?: (config: AppConfig) => Dependencies,
): Container {
  const clock = deps.clock ?? systemClock;
  const recorder = new MetricsRecorder(deps.metrics, clock, logger);
  const namespaces = new NamespaceService(
    deps.kube,
    recorder,
    { workspaceProxyUrl: config.devreg.workspaceProxyUrl, emailDomain: config.notification.emailDomain },
    logger,
  );
  const deployments = new DeploymentNamespaceService(
    deps.deployKube ?? deps.kube,
    recorder,
    deps.notifier,
    config.cluster.deployProjectRequester,
    logger,
  );
  const container: Container = {
    reconfigure(next) {
      const nextDependencies = refresh ? refresh(next) : deps;
      const reconfigure = container.reconfigure;
      Object.assign(container, buildContainer(next, logger, nextDependencies, refresh), { reconfigure });
    },
    config,
    logger,
    kube: deps.kube,
    deployKube: deps.deployKube ?? deps.kube,
    metrics: deps.metrics,
    registry: deps.registry,
    recorder,
    namespaces,
    workspaces: new WorkspaceService(
      deps.kube,
      namespaces,
      deps.registry,
      recorder,
      {
        limits: config.limits,
        editors: config.devreg.editors,
        editorRegistryUrl: config.devreg.editorRegistryUrl,
        devSpacesServiceFqdn: config.cluster.devSpacesServiceFqdn,
      },
      clock,
      logger,
    ),
    pats: new PatService(deps.kube, namespaces, recorder, config.github),
    gitConfig: new GitConfigService(deps.kube, namespaces, recorder),
    deployments,
    support: new SupportService({
      kube: deps.kube,
      deployKube: deps.deployKube ?? deps.kube,
      namespaces,
      deployments,
      logger,
    }),
  };
  return container;
}

/** Real adapters for a running pod. */
export function createProductionDependencies(config: AppConfig, logger: Logger): Dependencies {
  const directory = config.notification.userDirectoryUrl
    ? new GraphqlUserDirectory(config.notification.userDirectoryUrl, logger)
    : new NullUserDirectory();
  const { cluster } = config;
  const skipTlsVerify = !cluster.tlsRejectUnauthorized;
  const separateDeploy = cluster.deployApiUrl !== cluster.apiUrl;
  return {
    kube: new KubeClient(
      createKubeConfig({
        apiUrl: cluster.apiUrl,
        token: cluster.token,
        kubeconfigPath: cluster.kubeconfigPath,
        skipTlsVerify,
      }),
    ),
    deployKube: separateDeploy
      ? new KubeClient(
          createKubeConfig({
            apiUrl: cluster.deployApiUrl,
            token: cluster.deployToken,
            kubeconfigPath: cluster.kubeconfigPath,
            skipTlsVerify,
          }),
        )
      : undefined,
    metrics: config.postgres.enabled
      ? new MetricsRepository(createPgPool(config.postgres, logger), config.postgres.table, logger)
      : new NoopMetricsStore(),
    registry: new DevfileRegistryClient(createRegistryHttp(config.devreg.url)),
    notifier: config.notification.url
      ? new EmailNotifier(config.notification, config.cluster.deployApiUrl, directory, logger)
      : new NoopNotifier(),
  };
}

const EDITOR_DISPLAY: Record<EditorKey, string> = {

  intellij: 'IntelliJ IDEA',
  goland: 'GoLand',

export function buildDevWorkspaceObject(a: BuildWorkspaceArgs): DevWorkspaceResource {
  const projects = [...((a.devfile.projects as unknown[] | undefined) ?? [])];
  if (a.repositoryUrl) {
    const requestedProject = {
      name: 'default-project',
      git: {
        remotes: { origin: a.repositoryUrl },
      },
    };
    const existing = projects.findIndex(
      (project) => (project as { name?: string })?.name === 'default-project',
    );
    if (existing >= 0) projects[existing] = requestedProject;
    else projects.push(requestedProject);
  }

  const template: NonNullable<NonNullable<DevWorkspaceResource['spec']>['template']> = {
    attributes: {
      'controller.devfile.io/devworkspace-config': {
        name: 'devworkspace-config',
        namespace: 'openshift-devspaces',
      },
      'controller.devfile.io/scc': 'container-build',
      'controller.devfile.io/storage-type': 'per-workspace',
    },
    components: a.devfile.components ?? [],
  };
  if (projects.length > 0) template.projects = projects;
  if (Array.isArray(a.devfile.commands)) template.commands = a.devfile.commands;
  if (a.devfile.events) template.events = a.devfile.events;
  const tools = a.devfile.components?.find((component) => component.name === 'tools' && component.container);
  const container = tools ?? a.devfile.components?.find((component) => component.container);
  if (container) {
    const commands = [...(a.devfile.commands ?? [])];
    let setupId = 'workspace-manager-setup';
    while (commands.some((command) => (command as { id?: string })?.id === setupId)) setupId += '-post-start';
    commands.push({
      id: setupId,
      exec: {
        component: container.name,
        commandLine: buildWorkspaceSetupCommand({
          stack: a.stack,
          repositoryUrl: a.repositoryUrl,
          repositoryBranch: a.repositoryBranch,
        }),
        workingDir: '/projects',
      },
    });
    const events = (
      a.devfile.events && typeof a.devfile.events === 'object' ? a.devfile.events : {}
    ) as Record<string, unknown>;
    template.commands = commands;
    template.events = {
      ...events,
      postStart: [...(Array.isArray(events.postStart) ? events.postStart : []), setupId],
    };
  }

  return {
    apiVersion: 'workspace.devfile.io/v1alpha2',
    kind: 'DevWorkspace',
    metadata: {
      name: a.name,
      namespace: a.namespace,
      annotations: {
        dw: a.name,
        workspaceVersion: a.stackVersion,
        workspaceDisplayName: a.devfile.metadata?.displayName ?? a.devfile.metadata?.name ?? a.stack,
        workspaceDescription: a.devfile.metadata?.description ?? '',
        editorDisplayName: EDITOR_DISPLAY[a.editor],
      },
      labels: {
        [WORKSPACE_LABELS.csiid]: a.csiid,
        [WORKSPACE_LABELS.stack]: a.stack,
        [WORKSPACE_LABELS.managedBy]: 'workspace-mgr',
      },
    },
    spec: {
      started: true,
      routingClass: 'che',
      template,
      contributions: [
        {
          name: 'ide',
          uri: `${(a.editorRegistryUrl ?? `${a.devSpacesServiceFqdn.replace(/\/$/, '')}/plugin-registry/v3`).replace(/\/$/, '')}/plugins/${a.editorId}/devfile.yaml`,
        },
      ],
    },
  };
}

import type { AppConfig } from '../config/env.js';
import type { CreateWorkspaceInput, DevWorkspaceResource, EditorKey, Workspace } from '../types.js';
import { applyEditorProfile, parseDevfile } from '../factories/devfile-updater.js';
import { buildDevWorkspaceObject, WORKSPACE_LABELS } from '../factories/workspace-factory.js';
import { systemClock, type Clock, type DevfileRegistry, type KubeGateway } from '../infra/ports.js';
import {
  NotFoundError,
  WorkspaceCountExceededError,
  WorkspaceRunCountExceededError,
} from '../utils/errors.js';
import { silentLogger, type Logger } from '../utils/logger.js';
import { cleanWorkspaceName, csiidFromWorkspaceNamespace } from '../utils/names.js';
import { summarizeComponents } from '../utils/resources.js';
import { durationSince } from '../utils/timestamp.js';
import type { MetricsRecorder } from './MetricsRecorder.js';
import type { NamespaceService } from './NamespaceService.js';

export interface WorkspaceServiceOptions {
  limits: AppConfig['limits'];
  editors: AppConfig['devreg']['editors'];
  editorRegistryUrl?: string;
  devSpacesServiceFqdn: string;
}

const ACTIVE_PHASES = new Set(['Running', 'Starting', 'Stopping']);

/** Running, starting, stopping — or not yet reporting a phase — all still hold cluster resources. */
export const isActive = (dw: DevWorkspaceResource): boolean =>
  !dw.status?.phase || ACTIVE_PHASES.has(dw.status.phase);

export function toWorkspace(dw: DevWorkspaceResource): Workspace {
  const meta = dw.metadata ?? {};
  const annotations = meta.annotations ?? {};
  const namespace = meta.namespace ?? '';
  const resources = summarizeComponents(dw.spec?.template?.components);
  return {
    id: meta.name ?? '',
    name: meta.name ?? '',
    displayName: annotations.workspaceDisplayName ?? meta.name ?? '',
    description: annotations.workspaceDescription ?? '',
    namespace,
    csiid: meta.labels?.[WORKSPACE_LABELS.csiid] ?? csiidFromWorkspaceNamespace(namespace) ?? '',
    phase: dw.status?.phase ?? 'Starting',
    mainUrl: dw.status?.mainUrl ?? '',
    editor: annotations.editorDisplayName ?? '',
    version: annotations.workspaceVersion ?? '',
    stack: meta.labels?.[WORKSPACE_LABELS.stack] ?? '',
    created: meta.creationTimestamp ? new Date(meta.creationTimestamp).toISOString() : '',
    limitcpu: resources.limitcpu,
    limitmemory: resources.limitmemory,
    storage: resources.storage,
  };
}

/** When the workspace last became ready; falls back to creation time. */
function runningSince(dw: DevWorkspaceResource): Date | string | undefined {
  const ready = dw.status?.conditions?.find(
    (c) => (c.type === 'Started' || c.type === 'Ready') && c.status === 'True',
  );
  return ready?.lastTransitionTime ?? dw.metadata?.creationTimestamp;
}

export class WorkspaceService {
  constructor(
    private readonly kube: KubeGateway,
    private readonly namespaces: NamespaceService,
    private readonly registry: DevfileRegistry,
    private readonly recorder: MetricsRecorder,
    private readonly options: WorkspaceServiceOptions,
    private readonly clock: Clock = systemClock,
    private readonly logger: Logger = silentLogger,
  ) {}

  private async listResources(soeid: string): Promise<DevWorkspaceResource[]> {
    const namespaces = await this.namespaces.listForUser(soeid);
    const lists = await Promise.all(
      namespaces.map((ns) => this.kube.list<DevWorkspaceResource>('DevWorkspace', ns.metadata?.name ?? '')),
    );
    return lists.flat();
  }

  async list(soeid: string): Promise<Workspace[]> {
    return (await this.listResources(soeid)).map(toWorkspace);
  }

  private async find(soeid: string, id: string): Promise<DevWorkspaceResource> {
    const found = (await this.listResources(soeid)).find((dw) => dw.metadata?.name === id);
    if (!found) throw new NotFoundError(`Workspace '${id}' not found`, 'WORKSPACE_NOT_FOUND');
    return found;
  }

  async get(soeid: string, id: string): Promise<Workspace> {
    return toWorkspace(await this.find(soeid, id));
  }

  private assertCanRunAnother(all: DevWorkspaceResource[]): void {
    const active = all.filter(isActive).length;
    if (active >= this.options.limits.maxRunning) {
      throw new WorkspaceRunCountExceededError(
        `You already have ${active} running workspace(s); the limit is ${this.options.limits.maxRunning}. Stop one first.`,
      );
    }
  }

  private assertCanCreateAnother(all: DevWorkspaceResource[]): void {
    if (all.length >= this.options.limits.maxTotal) {
      throw new WorkspaceCountExceededError(
        `You already have ${all.length} workspace(s); the limit is ${this.options.limits.maxTotal}. Delete one first.`,
      );
    }
    this.assertCanRunAnother(all);
  }

  async create(input: CreateWorkspaceInput): Promise<Workspace> {
    const { soeid, csiid } = input;
    if (!input.repositoryUrl)
      this.logger.info('workspace.repository_skipped', {
        soeid,
        csiid,
        reason:
          'No repositoryUrl supplied; creating the workspace from the stack without adding a repository.',
      });
    else if (!input.repositoryBranch)
      this.logger.info('workspace.repository_default_branch', {
        soeid,
        csiid,
        reason: 'No repositoryCheckoutBranch supplied; using the repository default branch.',
      });
    this.assertCanCreateAnother(await this.listResources(soeid));

    const { name: namespace } = await this.namespaces.ensure(soeid, csiid);
    this.logger.info('workspace.creating', { soeid, namespace, stack: input.devworkspaceValue });
    const { yaml, version } = await this.registry.getDevfile(input.devworkspaceValue, input.stackVersion);
    const devfile = applyEditorProfile(parseDevfile(yaml), input.editor);
    const body = buildDevWorkspaceObject({
      name: cleanWorkspaceName(input.devworkspaceValue),
      namespace,
      csiid,
      stack: input.devworkspaceValue,
      stackVersion: version,
      devfile,
      editor: input.editor,
      editorId: this.editorId(input.editor),
      editorRegistryUrl: this.options.editorRegistryUrl,
      devSpacesServiceFqdn: this.options.devSpacesServiceFqdn,
      repositoryUrl: input.repositoryUrl,
      repositoryBranch: input.repositoryBranch,
    });

    const created = await this.recorder.track(
      {
        soeid,
        csiid,
        eventtype: 'create',
        resourcetype: 'workspace',
        resourcename: body.metadata?.name ?? '',
        workspaceversion: version,
        editorname: input.editor,
        ...summarizeComponents(devfile.components),
      },
      () => this.kube.create<DevWorkspaceResource>('DevWorkspace', namespace, body),
    );
    this.logger.success('workspace.created', {
      soeid,
      namespace,
      workspace: created.metadata?.name,
      version,
      editor: input.editor,
    });
    return toWorkspace(created);
  }

  async start(soeid: string, id: string): Promise<Workspace> {
    const dw = await this.find(soeid, id);
    if (dw.status?.phase === 'Running' || dw.status?.phase === 'Starting') return toWorkspace(dw);
    this.assertCanRunAnother(await this.listResources(soeid));
    return this.setStarted(soeid, dw, true);
  }

  async stop(soeid: string, id: string): Promise<Workspace> {
    const dw = await this.find(soeid, id);
    return this.setStarted(soeid, dw, false);
  }

  private async setStarted(soeid: string, dw: DevWorkspaceResource, started: boolean): Promise<Workspace> {
    const namespace = dw.metadata?.namespace ?? '';
    const name = dw.metadata?.name ?? '';
    this.logger.info(started ? 'workspace.starting' : 'workspace.stopping', {
      soeid,
      namespace,
      workspace: name,
    });
    const resources = summarizeComponents(dw.spec?.template?.components);
    const patched = await this.recorder.track(
      {
        soeid,
        csiid: toWorkspace(dw).csiid,
        eventtype: started ? 'start' : 'stop',
        resourcetype: 'workspace',
        resourcename: name,
        workspaceversion: dw.metadata?.annotations?.workspaceVersion ?? '',
        editorname: dw.metadata?.annotations?.editorDisplayName ?? '',
        duration: started ? '0 seconds' : durationSince(runningSince(dw), this.clock.now()),
        ...resources,
      },
      () => this.kube.setWorkspaceStarted(namespace, name, started),
    );
    this.logger.success(started ? 'workspace.started' : 'workspace.stopped', {
      soeid,
      namespace,
      workspace: name,
    });
    if (!started)
      this.logger.info('workspace.duration', {
        soeid,
        workspace: name,
        duration: durationSince(runningSince(dw), this.clock.now()),
      });
    return toWorkspace({ ...dw, ...patched, metadata: { ...dw.metadata, ...patched.metadata } });
  }

  async delete(soeid: string, id: string): Promise<void> {
    const dw = await this.find(soeid, id);
    const namespace = dw.metadata?.namespace ?? '';
    const name = dw.metadata?.name ?? '';
    this.logger.info('workspace.deleting', { soeid, namespace, workspace: name });
    const resources = summarizeComponents(dw.spec?.template?.components);

    await this.recorder.track(
      {
        soeid,
        csiid: toWorkspace(dw).csiid,
        eventtype: 'delete',
        resourcetype: 'workspace',
        resourcename: name,
        workspaceversion: dw.metadata?.annotations?.workspaceVersion ?? '',
        editorname: dw.metadata?.annotations?.editorDisplayName ?? '',
        duration: durationSince(dw.metadata?.creationTimestamp, this.clock.now()),
        ...resources,
      },
      async () => {
        await this.kube.delete('DevWorkspace', namespace, name);
        // Workspaces created by the legacy flow reference a separate DevWorkspaceTemplate.
        for (const contribution of dw.spec?.contributions ?? []) {
          if (contribution.kubernetes?.name) {
            await this.kube.delete('DevWorkspaceTemplate', namespace, contribution.kubernetes.name);
          }
        }
      },
    );
    this.logger.success('workspace.deleted', { soeid, namespace, workspace: name });
  }

  private editorId(editor: EditorKey): string {
    return this.options.editors[editor];
  }
}

const pad2 = (n: number): string => String(n).padStart(2, '0');

/** Local time `2026-10-24 03:12:45`. */
export function formatLocalTime(d: Date): string {
  return (
    `${d.getFullYear()}-${pad2(d.getMonth() + 1)}-${pad2(d.getDate())} ` +
    `${pad2(d.getHours())}:${pad2(d.getMinutes())}:${pad2(d.getSeconds())}`
  );

type Primitive = string | number | boolean | null | undefined;
const isPrimitive = (v: unknown): v is Primitive => v === null || v === undefined || typeof v !== 'object';
const isPlainObject = (v: unknown): v is Record<string, unknown> =>
  typeof v === 'object' && v !== null && !Array.isArray(v);

const oneLine = (s: string): string => s.replace(/\r?\n/g, '\\n');

/** Inline value: bare when simple, quoted when it contains spaces or `=`. */
function inlineValue(v: Primitive): string {
  if (typeof v !== 'string') return String(v);
  const s = oneLine(v);
  return /^[^\s"=]+$/.test(s) ? s : JSON.stringify(s);
}

/** Value on its own line: strings as they are, arrays as compact JSON. */
function blockValue(v: unknown): string {
  if (typeof v === 'string') return oneLine(v);
  if (Array.isArray(v)) return JSON.stringify(v);
  return String(v);
}

function renderBlock(obj: Record<string, unknown>, indent: string): string[] {
  const entries = Object.entries(obj).filter(([, v]) => v !== undefined);
  const width = Math.max(
    0,
    ...entries.filter(([, v]) => !isPlainObject(v) || Object.keys(v).length === 0).map(([k]) => k.length),
  );
  const lines: string[] = [];
  for (const [key, value] of entries) {
    if (isPlainObject(value) && Object.keys(value).length > 0) {
      lines.push(`${indent}${key}:`);
      lines.push(...renderBlock(value, `${indent}  `));
    } else {
      const text = isPlainObject(value) ? '{}' : blockValue(value);
      lines.push(`${indent}${key.padEnd(width)} : ${text}`);
    }
  }
  return lines;
}

function canInline(fields: [string, unknown][]): boolean {
  if (fields.length > MAX_INLINE_FIELDS) return false;
  let total = 0;
  for (const [k, v] of fields) {
    if (!isPrimitive(v)) return false;
    const text = inlineValue(v);
    if (text.length > MAX_INLINE_VALUE) return false;
    total += k.length + text.length + 3;
  }
  return total <= MAX_INLINE_TOTAL;
}

/** `GET    /api/v1/x -> 200 (12 ms)` for the per-request log line, plus the fields that are not part of it. */
function requestMessage(
  fields: Record<string, unknown>,
): { message: string; rest: Record<string, unknown> } | undefined {
  const { method, path, status, ms, ...rest } = fields;
  if (typeof method !== 'string' || typeof path !== 'string' || typeof status !== 'number') return undefined;
  const took = typeof ms === 'number' ? ` (${ms} ms)` : '';
  return { message: `${method.padEnd(6)} ${path} -> ${status}${took}`, rest };
}

/** One log entry as text. Multi-line entries end with a blank line so that entries stay visually separate. */
export function formatPretty(entry: LogEntry, color: boolean): string {
  const { file = 'unknown', function: functionName = 'module', line, ...data } = entry.fields;
  const location = line === undefined ? String(file) : `${String(file)}:${String(line)}`;
  const diagnostic = entry.kind === 'error' || entry.kind === 'warn';
  const prefix = diagnostic
    ? `[${formatLocalTime(entry.time)}] [${oneLine(location)}] [${oneLine(String(functionName))}]`
    : `[${formatLocalTime(entry.time)}] [${logCategory(entry.event)}]`;
  const sentence = diagnostic ? undefined : logMessage(entry.event, data);
  if (sentence) {
    const text = `${prefix} ${oneLine(sentence)}`;
    const details =
      entry.event === 'server.listening'
        ? renderBlock(data, BLOCK_INDENT).map((detail) => `${prefix} ${detail}`)
        : [];
    const lines = [text, ...details];
    return lines.map((line) => (color ? `${COLORS[entry.kind]}${line}${RESET}` : line)).join('\n');
  }
  const head = `${prefix} | ${BADGE[entry.kind]} | `;
  const request = entry.event === 'request' ? requestMessage(data) : undefined;
  const fields = Object.entries(request ? request.rest : data).filter(([, v]) => v !== undefined);
  const lines: string[] = [];

  if (fields.length === 0 && !request) {
    lines.push(`${head}${entry.event}`);
  } else if (canInline(fields)) {
    const inline = fields.map(([k, v]) => `${k}=${inlineValue(v as Primitive)}`).join('  ');
    const text = [request?.message, inline].filter(Boolean).join('  ');
    lines.push(`${head}${entry.event.padEnd(EVENT_WIDTH)} | ${text}`);
  } else {
    lines.push(
      request ? `${head}${entry.event.padEnd(EVENT_WIDTH)} | ${request.message}` : `${head}${entry.event}`,
    );
    lines.push(...renderBlock(Object.fromEntries(fields), BLOCK_INDENT).map((line) => `${prefix} ${line}`));
    lines.push(''); // blank line after a multi-line entry
  }

  const paint = (line: string): string =>
    color && line !== '' ? `${COLORS[entry.kind]}${line}${RESET}` : line;
  return lines.map(paint).join('\n');
}

type Fields = Record<string, unknown>;

export function logCategory(event: string): string {
  const category = event.split('.')[0] ?? 'application';
  return (
    (
      {
        workspace: 'Workspace',
        namespace: 'Namespace',
        deployment_namespace: 'Deployment',
        server: 'Server',
        request: 'HTTP',
        email: 'Email',
        configuration: 'Configuration',
        support: 'Support',
        metrics: 'Metrics',
      } as Record<string, string>
    )[category] ?? 'Application'
  );
}

/** Sentences for operators; structured logs retain the event names and individual fields. */
export function logMessage(event: string, fields: Fields): string | undefined {
  const user = typeof fields.soeid === 'string' ? ` for user '${fields.soeid}'` : '';
  const namespace = typeof fields.namespace === 'string' ? ` in namespace '${fields.namespace}'` : '';
  const workspace = String(fields.workspace ?? '');
  switch (event) {
    case 'workspace.creating':
      return `Creating a workspace from stack '${String(fields.stack)}'${user}${namespace}.`;
    case 'workspace.created':
      return `Created workspace resource '${workspace}'${user}${namespace}${fields.version && fields.editor ? ` (version: ${String(fields.version)}, editor: ${String(fields.editor)})` : ''}. Dev Spaces will now start it.`;
    case 'workspace.starting':
      return `Starting workspace '${workspace}'${user}${namespace}.`;
    case 'workspace.stopping':
      return `Stopping workspace '${workspace}'${user}${namespace}.`;
    case 'workspace.deleting':
      return `Deleting workspace '${workspace}'${user}${namespace}.`;
    case 'workspace.started':
      return `Requested startup of workspace '${workspace}'${user}${namespace}.`;
    case 'workspace.stopped':
      return `Requested stop of workspace '${workspace}'${user}${namespace}.`;
    case 'workspace.deleted':
      return `Successfully deleted workspace '${workspace}'${user}${namespace}.`;
    case 'workspace.duration':
      return `Workspace '${workspace}' ran for ${String(fields.duration)}${user}.`;
    case 'workspace.repository_skipped':
      return `No repository URL supplied${user}; creating the workspace from its stack without adding a repository.`;
    case 'workspace.repository_default_branch':
      return `No checkout branch supplied${user}; the repository will use its default branch.`;
    case 'namespace.creating':
      return `Creating namespace '${String(fields.namespace)}'${user}.`;
    case 'namespace.resource_applied':
      return `Applied ${String(fields.kind)} '${String(fields.name)}'${namespace}.`;
    case 'deployment_namespace.created':
      return `Successfully created deployment namespace '${String(fields.namespace)}'${user}.`;
    case 'support.resources_applied':
      return `Successfully reconciled ${String(fields.target)} resources${user}${namespace}.`;
    case 'configuration.updated':
      return `Updated runtime settings${Array.isArray(fields.keys) ? `: ${fields.keys.join(', ')}` : ''}.`;
    case 'server.listening':
      return `Workspace Manager is listening on port ${String(fields.port)}.`;
    case 'server.shutdown':
      return `Shutting down Workspace Manager${fields.signal ? ` after receiving ${String(fields.signal)}` : ''}.`;
    case 'email.sent':
      return `Successfully sent notification '${String(fields.subject)}'${user}.`;
    case 'email.skipped':
      return `Skipped notification '${String(fields.subject)}': ${String(fields.reason)}.`;
    case 'request': {
      if (
        typeof fields.method !== 'string' ||
        typeof fields.path !== 'string' ||
        typeof fields.status !== 'number'
      )
        return undefined;
      const duration = typeof fields.ms === 'number' ? `, ${fields.ms} ms` : '';
      const requestId = typeof fields.requestId === 'string' ? ` Request ID: ${fields.requestId}.` : '';
      return `${fields.method} ${fields.path} completed successfully${user} (HTTP ${fields.status}${duration}).${requestId}`;
    }
    default:
      return undefined;
  }
}

import { describe, expect, it } from 'vitest';
import { createLogger, redact } from '../../../src/utils/logger.js';

function capture(level: Parameters<typeof createLogger>[0] = 'info') {
  const lines: Record<string, unknown>[] = [];
  return { lines, logger: createLogger(level, (l) => lines.push(JSON.parse(l))) };
}

describe('logger', () => {
  it('records the calling file and function with a seconds-resolution timestamp', () => {
    const { lines, logger } = capture();
    function recordEvent() {
      logger.info('source.test');
    }
    recordEvent();
    expect(lines[0]).toMatchObject({ file: 'logger.test.ts', function: 'recordEvent' });
    expect(lines[0]?.timestamp).toMatch(/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$/);
  });
  it('uses an error stack to identify its original file and function', () => {
    const { lines, logger } = capture();
    const error = new Error('creation failed');
    error.stack =
      'Error: creation failed\n    at NamespaceService.ensure (C:\\app\\src\\services\\NamespaceService.ts:42:10)';
    logger.error('namespace.failed', { error });
    expect(lines[0]).toMatchObject({
      file: 'NamespaceService.ts',
      function: 'NamespaceService.ensure',
      error: 'creation failed',
    });
    expect(JSON.stringify(lines[0])).not.toContain('C:\\app');
  });
  it('writes one JSON line with level, event and fields', () => {
    const { lines, logger } = capture();
    logger.info('hello', { a: 1 });
    expect(lines).toHaveLength(1);
    expect(lines[0]).toMatchObject({ level: 'info', event: 'hello', a: 1 });
    expect(typeof lines[0]?.time).toBe('string');
  });

  it('filters below the configured level', () => {
    const { lines, logger } = capture('warn');
    logger.debug('d');
    logger.info('i');
    logger.warn('w');
    logger.error('e');
    expect(lines.map((l) => l.event)).toEqual(['w', 'e']);
  });

  it('is silent when asked', () => {
    const { lines, logger } = capture('silent');
    logger.error('e');
    expect(lines).toHaveLength(0);
  });

  it('child loggers carry bindings', () => {
    const { lines, logger } = capture();
    logger.child({ requestId: 'r1' }).info('x', { b: 2 });
    expect(lines[0]).toMatchObject({ requestId: 'r1', b: 2 });
  });

  it('redacts sensitive keys, nested and in arrays', () => {
    const { lines, logger } = capture();
    logger.info('x', {
      token: 'ghp_secret',
      nested: { password: 'p', ok: 1 },
      list: [{ authorization: 'Bearer x' }],
    });
    expect(lines[0]).toMatchObject({
      token: '[redacted]',
      nested: { password: '[redacted]', ok: 1 },
      list: [{ authorization: '[redacted]' }],
    });
    expect(JSON.stringify(lines[0])).not.toContain('ghp_secret');
  });

  it('success is an info-level line marked as a success, and hidden when only warnings are wanted', () => {
    const { lines, logger } = capture();
    logger.success('workspace.created', { workspace: 'w1' });
    expect(lines[0]).toMatchObject({
      level: 'info',
      outcome: 'success',
      event: 'workspace.created',
      workspace: 'w1',
    });
    const quiet = capture('warn');
    quiet.logger.success('workspace.created');
    expect(quiet.lines).toHaveLength(0);
  });

  it('plain info lines carry no outcome', () => {
    const { lines, logger } = capture();
    logger.info('x');
    expect(lines[0]).not.toHaveProperty('outcome');
  });

  describe('pretty format (terminal)', () => {
    const now = () => new Date(2026, 0, 2, 3, 4, 5, 678);
    const pretty = (level: Parameters<typeof createLogger>[0] = 'info', color = true) => {
      const out: string[] = [];
      return {
        out,
        logger: createLogger(
          level,
          (l) => out.push(l),
          {},
          { format: 'pretty', color, now, source: { file: 'logger.test.ts', function: 'testLog' } },
        ),
      };
    };

    it('paints each kind in its colour: error red, warn orange, success green, info and debug white', () => {
      const { out, logger } = pretty('debug');
      logger.error('e');
      logger.warn('w');
      logger.success('s');
      logger.info('i');
      logger.debug('d');
      expect(out).toEqual([
        '\u001b[31m[2026-01-02 03:04:05] [logger.test.ts] [testLog] | ERROR | e\u001b[0m',
        '\u001b[38;5;208m[2026-01-02 03:04:05] [logger.test.ts] [testLog] | WARN  | w\u001b[0m',
        '\u001b[32m[2026-01-02 03:04:05] [Application] | OK    | s\u001b[0m',
        '\u001b[97m[2026-01-02 03:04:05] [Application] | INFO  | i\u001b[0m',
        '\u001b[97m[2026-01-02 03:04:05] [Application] | DEBUG | d\u001b[0m',
      ]);
    });

    it('writes one sink call per entry, plain when colour is off', () => {
      const { out, logger } = pretty('info', false);
      logger.info('a', { n: 1 });
      logger.warn('b');
      expect(out).toEqual([
        `[2026-01-02 03:04:05] [Application] | INFO  | ${'a'.padEnd(30)} | n=1`,
        '[2026-01-02 03:04:05] [logger.test.ts] [testLog] | WARN  | b',
      ]);
    });

    it('applies the level filter, bindings of child loggers, and redaction', () => {
      const { out, logger } = pretty('info', false);
      logger.debug('hidden');
      logger.child({ requestId: 'r1' }).info('x', { token: 'ghp_secret', ok: 1 });
      expect(out).toHaveLength(1);
      expect(out[0]).toContain('requestId=r1');
      expect(out[0]).toContain('token=[redacted]');
      expect(out[0]).not.toContain('ghp_secret');
    });

    it('child loggers keep the format and colour of their parent', () => {
      const { out, logger } = pretty('info', true);
      logger.child({ a: 1 }).error('boom');
      expect(out[0]?.startsWith('\u001b[31m')).toBe(true);
    });

    it('the default is still JSON, so existing log collectors keep working', () => {
      const lines: string[] = [];
      createLogger('info', (l) => lines.push(l)).info('x');
      expect(JSON.parse(lines[0] as string)).toMatchObject({ event: 'x', level: 'info' });
    });
  });

  it('serialises errors as name and message only', () => {
    expect(redact(new Error('bad'))).toEqual({ name: 'Error', message: 'bad' });
  });

  it('stops redacting past a sane depth', () => {
    const deep = { a: { b: { c: { d: { e: { f: { g: 1 } } } } } } };
    expect(redact(deep)).toEqual(deep);
  });
});
