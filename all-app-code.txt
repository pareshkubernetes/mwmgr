# Workspace Manager API and code map

Every endpoint starts with `/api/v1`. Unversioned URLs return 404. There is no legacy
router, compatibility switch, or archived implementation to maintain.

## Finding the code

```text
src/index.ts                   start server, load settings, graceful shutdown
src/app.ts                     Express setup, request logging, error handling
src/routers/index.ts           mount all feature routers and authentication
src/routers/*Router.ts         HTTP methods and paths
src/controllers/*Controller.ts parse requests and produce responses
src/services/                  provisioning and workspace business rules
src/http/helpers.ts             shared parameters and administrator authorization
src/config/                    environment validation and daily log storage
src/infra/                     Kubernetes, registry, email and database adapters
src/types.ts                   shared resource and API types
src/utils/                     shared logging, errors, names and resources
tests/unit/                    isolated behavior
tests/integration/             API, service and adapter wiring
tests/e2e/                     complete HTTP journeys
```

Source files are TypeScript; the build emits ESM `.js` files in `dist/`.
`npm start` runs `dist/index.js`, which calls the application factory in `dist/app.js`.
To debug a route, follow its router to the matching controller and service.

## Endpoints

Paths below include the version prefix. Use `Authorization: Bearer <jwt>` for all
routes except login and probes. The existing login issues an administrator token;
regular user tokens can access only their own `:soeid` resources.

| Method                 | Path                                  | Purpose                                               |
| ---------------------- | ------------------------------------- | ----------------------------------------------------- |
| GET                    | `/api/v1/healthz`                     | Liveness; does not contact dependencies               |
| GET                    | `/api/v1/readyz`                      | Kubernetes, deployment cluster and database readiness |
| POST                   | `/api/v1/login`                       | Existing username/password login                      |
| GET                    | `/api/v1/catalog`                     | Stack catalog                                         |
| GET, POST              | `/api/v1/:soeid/projects`             | List or provision workspace projects                  |
| GET, POST              | `/api/v1/:soeid/workspaces`           | List or create workspaces                             |
| GET, DELETE            | `/api/v1/:soeid/workspaces/:id`       | Read or terminate a workspace                         |
| POST                   | `/api/v1/:soeid/workspaces/:id/start` | Start a workspace                                     |
| POST                   | `/api/v1/:soeid/workspaces/:id/stop`  | Stop a workspace                                      |
| GET                    | `/api/v1/:soeid/pats`                 | List PATs                                             |
| GET, POST, PUT, DELETE | `/api/v1/:soeid/pats/:tokenName`      | View, create, update or delete a PAT                  |
| GET, POST, PUT, DELETE | `/api/v1/:soeid/gitconfig`            | View, upsert or delete Git configuration              |
| GET, POST, DELETE      | `/api/v1/:soeid/deployment-projects`  | List, provision or delete deployment projects         |
| PUT                    | `/api/v1/support/resources`           | Administrator resource reconciliation                 |
| GET, PATCH             | `/api/v1/configuration`               | Administrator runtime settings                        |
| GET                    | `/api/v1/logs`                        | Administrator log search and formatted output         |

Project/workspace/deployment-project lists accept an optional `?csiid=177398`
filter. Identifiers use the application's existing names: **SOEID** and **CSIID**.
Stacks come from the configured registry and are shared across projects.

`POST /api/v1/:soeid/projects` and `POST /api/v1/:soeid/deployment-projects` accept
`{ "csiid": "177398" }`. They reuse the existing provisioning services, including
roles, bindings, quotas, limit ranges, workspace network policies and proxy configuration.
Creation returns 201; an existing project returns 200. Deployment projects use the
configured deployment cluster. Deleting deployment projects retains the existing
behavior: delete all matching deployment projects for that user.

PAT writes accept `{ "csiid": "177398", "token": "..." }`. PAT reads and deletes use
`?csiid=177398`. Git configuration writes accept `{ "csiid": "177398", "content": "..." }`;
reads and deletes use the same query parameter. POST and PUT Git configuration both upsert.

## Repairing or updating Kubernetes resources

Restore existing defaults on a user's workspace project:

```http
PUT /api/v1/support/resources
Authorization: Bearer <admin-jwt>
Content-Type: application/json

{ "soeid": "pp58386", "csiid": "177398", "target": "workspace" }
```

Use `"target": "deployment"` for the deployment cluster/project. The project must
exist and its owner annotation must match the requested SOEID. Omitting `resources`
reapplies the existing provisioning defaults, including network/proxy resources for
workspace projects. This repairs missing resources without recreating a project.

To create or replace selected resources, supply their manifests:

```json
{
  "soeid": "pp58386",
  "csiid": "177398",
  "target": "workspace",
  "resources": [
    {
      "kind": "ResourceQuota",
      "metadata": { "name": "custom-compute-quota" },
      "spec": { "hard": { "requests.cpu": "4", "requests.memory": "8Gi" } }
    }
  ]
}
```

Allowed kinds: `Role`, `RoleBinding`, `ResourceQuota`, `LimitRange`, `ClusterRole`,
`ClusterRoleBinding`. `metadata` accepts only `name`: the server sets namespace and
API version. Cluster roles/bindings are cluster-scoped and apply to the selected
workspace or deployment cluster. Kubernetes has no cluster-scoped LimitRange or
ResourceQuota; those apply to the selected user's namespace on that cluster.
Kubernetes validates manifest rules, subjects, role references and specs.

Operations run sequentially. If one fails, earlier successful updates remain;
correct the error and retry. Existing Kubernetes permissions still apply. The
service account needs explicit cluster-RBAC write privileges for cluster-scoped
operations; this change does not automatically expand deployment privileges.

## Runtime settings

`GET /api/v1/configuration` returns settings with passwords and tokens redacted.
`PATCH /api/v1/configuration` accepts any nonempty subset of:

```json
{
  "DEVREG_URL": "https://registry.example.com",
  "NOTIFICATION_MAIL_URL": "https://mail.example.com",
  "NOTIFICATION_EMAIL_USERNAME": "workspace-mailer",
  "NOTIFICATION_EMAIL_PASSWORD": "replacement-password",
  "MAX_RUNNING_WORKSPACES": 3,
  "MAX_TOTAL_WORKSPACES": 5,
  "CLUSTER_API_URL": "https://api.cluster.example.com:6443",
  "CLUSTER_TOKEN": "replacement-token",
  "DEPLOY_CLUSTER_API_URL": "https://api.deploy.example.com:6443",
  "DEPLOY_CLUSTER_TOKEN": "replacement-deployment-token"
}
```

Changes take effect for subsequent requests in this process. Production adapters
are rebuilt so updated URLs and credentials are used; the database pool remains
open. In-flight operations can finish using their original services. Updates are
validated before replacement. Running limits cannot exceed total limits; changing
a cluster URL requires its token in the same request.

**Persistence is process-lifetime:** this API does not rewrite deployment environment
variables, Kubernetes Secrets or `.env` files. Set the same values in deployment
configuration to retain them after restart and across replicas. Responses explicitly
report `"persistence": "process-lifetime"`. No arbitrary environment-variable writes
are supported. Stored secret values are never returned by this API.

## Troubleshooting with daily logs

Production writes one redacted JSON entry per line to `logs/app-YYYY-MM-DD.log`.
Each entry includes `timestamp` (`YYYY-MM-DD HH:MM:SS` in the process's local timezone),
`file`, and `function`. The ISO `time` field remains available for precise filtering.
Readable console and log-search output uses
`[timestamp] [filename:line] [functionName]`. Continuation lines carry the
same prefix. Source details come from the log call, or the original error stack when
an Error object is provided. Application callbacks have descriptive function names;
top-level execution without a named function is identified as `module`.
Client failures (400/401/403/404/409) are logged as warnings with status, error code,
message, request ID, and source location. Server failures are logged as errors.
JWT errors distinguish expired, not-yet-valid, invalid-signature, and malformed tokens.
Use the Workspace Manager token from `/api/v1/login` for these APIs; cluster tokens
authenticate the server's Kubernetes requests and are separate credentials.
Dates are UTC and files switch automatically at midnight. Console formatting is
independent. `LOG_DIRECTORY` selects the directory. Mount a writable volume there
when using a read-only filesystem, and persistent storage if logs must survive pod
replacement. Log files are not committed. Retention is managed by the deployment.

```http
GET /api/v1/logs?days=2&level=error&search=namespace&limit=100&format=text
Authorization: Bearer <admin-jwt>
```

Supported query parameters:

| Parameter   | Meaning                                           |
| ----------- | ------------------------------------------------- |
| `days`      | Rolling last 1–31 days; default 1                 |
| `limit`     | Maximum 1–1000 results; default 200               |
| `level`     | `debug`, `info`, `warn`, or `error`               |
| `search`    | Case-insensitive text match, up to 200 characters |
| `requestId` | Exact request correlation ID                      |
| `soeid`     | Exact user match                                  |
| `format`    | `json` (default) or readable `text`               |

Results are newest first and include the queried range and a `truncated` indicator.
Search scans at most 100,000 lines per request. Missing files and malformed lines are
ignored. Search uses literal text filtering. The API searches this
instance's files; aggregate logs externally when running multiple replicas.

## Offline transfer

Copy `recreate-app.sh` and `all-app-code.txt` into the destination application folder:

```bash
bash recreate-app.sh -n -f --prune
bash recreate-app.sh -f --prune
```

The first command previews the update. The second verifies checksums, writes the
snapshot and deletes files explicitly listed as removed. The snapshot contains the
complete application source, tests, lockfile, configuration templates and documentation.
It can also be restored into an empty folder.

Node.js, installed dependencies and secrets are not included. Install dependencies
from your configured internal npm repository with `npm ci`, then run `npm run build`.
Supply environment variables or mounted secrets separately.

To prepare another full transfer on the development machine, run
`bash tools/build-all-code.sh --full`. Its verification restores every bundled file
to a temporary directory and compares it byte for byte with the source.

/src/app.ts
import express, { type Express } from 'express';
import { randomUUID } from 'node:crypto';
import type { Container } from './container.js';
import baseRouter from './routers/index.js';
import { createErrorHandler, notFoundHandler } from './http/errors.js';

export const API_PREFIX = '/api/v1';

export function createApp(c: Container): Express {
  const app = express();
  app.disable('x-powered-by');

  app.use(function requestContext(req, res, next) {
    const incoming = req.header('x-request-id');
    const requestId = incoming && /^[A-Za-z0-9-]{8,64}$/.test(incoming) ? incoming : randomUUID();
    res.locals.requestId = requestId;
    res.setHeader('x-request-id', requestId);
    const started = Date.now();
    res.on('finish', function logRequest() {
      // Match request severity to the HTTP status.
      const outcome = res.statusCode >= 500 ? 'error' : res.statusCode >= 400 ? 'warn' : 'success';
      c.logger[outcome]('request', {
        method: req.method,
        // Preserve the full path when logging requests handled by nested routers.
        path: req.originalUrl.split('?')[0],
        status: res.statusCode,
        ms: Date.now() - started,
        requestId,
        soeid: res.locals.soeid as string | undefined,
      });
    });
    next();
  });
  app.use(express.json({ limit: '256kb' }));

  const api = baseRouter(c);
  app.use(API_PREFIX, api);

  app.use(notFoundHandler);
  app.use(createErrorHandler(c.logger));
  return app;
}

/src/config/daily-logs.ts
import { appendFile, mkdir } from 'node:fs/promises';
import { createReadStream } from 'node:fs';
import { createInterface } from 'node:readline';
import { resolve, join } from 'node:path';
import { formatLocalTime } from '../utils/log-format.js';

export const logDirectory = (): string => resolve(process.env.LOG_DIRECTORY || 'logs');
let pending: Promise<void> = Promise.resolve();
export const flushDailyLogs = (): Promise<void> => pending;

/** Files always contain redacted JSON, independently of the console format. UTC date boundaries. */
export function appendDailyLog(line: string, time: Date): void {
  const directory = logDirectory();
  pending = pending
    .then(async () => {
      await mkdir(directory, { recursive: true });
      await appendFile(join(directory, `app-${time.toISOString().slice(0, 10)}.log`), `${line}\n`, {
        mode: 0o600,
      });
    })
    .catch(function reportLogWriteFailure() {
      process.stderr.write(
        `[${formatLocalTime(new Date())}] [daily-logs.ts] [reportLogWriteFailure] | ERROR | Unable to write daily application log\n`,
      );
    });
}

export async function queryLogs(
  options: {
    days: number;
    limit: number;
    level?: string;
    search?: string;
    requestId?: string;
    soeid?: string;
  },
  now = new Date(),
) {
  await pending;
  const from = new Date(now.getTime() - options.days * 86400000);
  const entries: Record<string, unknown>[] = [];
  let scanned = 0;
  let truncated = false;
  // Newest files first, and retain the newest matching entries within each file.
  for (
    let day = new Date(now);
    day.toISOString().slice(0, 10) >= from.toISOString().slice(0, 10);
    day = new Date(day.getTime() - 86400000)
  ) {
    const input = createReadStream(join(logDirectory(), `app-${day.toISOString().slice(0, 10)}.log`), {
      encoding: 'utf8',
    });
    const lines = createInterface({ input, crlfDelay: Infinity });
    try {
      for await (const line of lines) {
        if (++scanned > 100000) {
          truncated = true;
          break;
        }
        let entry: Record<string, unknown>;
        try {
          entry = JSON.parse(line) as Record<string, unknown>;
        } catch {
          continue;
        }
        const time = Date.parse(String(entry.time));
        if (!Number.isFinite(time) || time < from.getTime() || time > now.getTime()) continue;
        if (options.level && entry.level !== options.level) continue;
        if (options.requestId && entry.requestId !== options.requestId) continue;
        if (options.soeid && entry.soeid !== options.soeid) continue;
        if (options.search && !line.toLowerCase().includes(options.search.toLowerCase())) continue;
        entries.push(entry);
      }
    } catch (error) {
      if ((error as NodeJS.ErrnoException).code !== 'ENOENT') throw error;
    } finally {
      lines.close();
      input.destroy();
    }
    if (truncated) break;
  }
  entries.sort((a, b) => String(b.time).localeCompare(String(a.time)));
  return {
    from: from.toISOString(),
    to: now.toISOString(),
    truncated: truncated || entries.length > options.limit,
    entries: entries.slice(0, options.limit),
  };
}

/src/controllers/authController.ts
import type { RequestHandler } from 'express';
import type { Container } from '../container.js';
import { checkAdminCredentials, signToken } from '../http/auth.js';
import { loginSchema, parse } from '../http/schemas.js';
import { UnauthorizedError } from '../utils/errors.js';

export function authController(container: Container) {
  return {
    login: function login(req, res, next) {
      try {
        const { username, password } = parse(loginSchema, req.body);
        if (!checkAdminCredentials(container.config.auth, username, password)) {
          throw new UnauthorizedError('Username or password is incorrect');
        }
        res.json({ token: signToken(container.config.auth, { soeid: username, role: 'admin' }) });
      } catch (error) {
        next(error);
      }
    },
  } satisfies Record<string, RequestHandler>;
}

/src/controllers/healthCheckController.ts
import type { RequestHandler } from 'express';
import type { Container } from '../container.js';
import { asyncHandler } from '../http/errors.js';
import { k8sStatus } from '../utils/k8s-errors.js';

function failureDetails(error: unknown) {
  const cause = error instanceof Error && error.cause ? error.cause : error;
  const httpStatus = k8sStatus(cause);
  const message = cause instanceof Error ? cause.message : '';
  const reason =
    httpStatus === 401
      ? 'authentication_failed'
      : httpStatus === 403
        ? 'permission_denied'
        : /certificate|ssl|tls/i.test(message)
          ? 'certificate_error'
          : /timeout|timed out|abort/i.test(message)
            ? 'timeout'
            : /ENOTFOUND|ECONNREFUSED|EHOSTUNREACH|fetch failed|connect/i.test(message)
              ? 'connection_failed'
              : 'dependency_check_failed';
  return { reason, ...(httpStatus === undefined ? {} : { httpStatus }) };
}

export function healthCheckController(container: Container) {
  return {
    health: function health(_req, res) {
      res.send('OK');
    },
    ready: asyncHandler(async function healthCheckReady(_req, res) {
      const checks: Record<string, string> = {};
      const failed = (dependency: string) =>
        function reportReadinessFailure(error: unknown) {
          checks[dependency] = 'unavailable';
          container.logger.error('readiness.check_failed', {
            dependency,
            requestId: res.locals.requestId as string | undefined,
            ...failureDetails(error),
          });
        };
      await Promise.all([
        container.kube.ping().then(() => (checks.kubernetes = 'ok'), failed('kubernetes')),
        container.metrics.ping().then(() => (checks.postgres = 'ok'), failed('postgres')),
        // only when build/deploy projects live on a different cluster
        ...(container.deployKube !== container.kube
          ? [container.deployKube.ping().then(() => (checks.deployCluster = 'ok'), failed('deployCluster'))]
          : []),
      ]);
      const ready = Object.values(checks).every((v) => v === 'ok');
      res.status(ready ? 200 : 503).json({ status: ready ? 'ready' : 'not-ready', checks });
    }),
  } satisfies Record<string, RequestHandler>;
}

/src/controllers/logController.ts
import { z } from 'zod';
import { queryLogs } from '../config/daily-logs.js';
import { formatPretty } from '../utils/log-format.js';
import { asyncHandler } from '../http/errors.js';
import { parse } from '../http/schemas.js';

const query = z.strictObject({
  days: z.coerce.number().int().min(1).max(31).default(1),
  limit: z.coerce.number().int().min(1).max(1000).default(200),
  level: z.enum(['debug', 'info', 'warn', 'error']).optional(),
  search: z.string().max(200).optional(),
  requestId: z.string().max(64).optional(),
  soeid: z.string().max(64).optional(),
  format: z.enum(['json', 'text']).default('json'),
});
export function logController() {
  return {
    list: asyncHandler(async function logList(req, res) {
      const options = parse(query, req.query);
      const result = await queryLogs(options);
      if (options.format === 'text') {
        res.type('text').send(
          [
            `Application logs | ${result.from} to ${result.to} | ${result.entries.length} entries | truncated: ${result.truncated}`,
            ...result.entries.map(({ time, level, event, timestamp: _timestamp, ...fields }) =>
              formatPretty(
                {
                  time: new Date(String(time)),
                  kind: level === 'error' || level === 'warn' || level === 'debug' ? level : 'info',
                  event: String(event),
                  fields,
                },
                false,
              ),
            ),
          ].join('\n'),
        );
      } else res.json(result);
    }),
  };
}

export function patController(container: Container) {
  return {
    list: asyncHandler(async function patList(_req, res) {

    }),
    view: asyncHandler(async function patView(req, res) {
      const { csiid } = parse(csiidQuerySchema, req.query);
      res.json(
        await container.pats.view(getSoeid(res), parseCsiid(csiid), parseTokenName(param(req, 'tokenName'))),

        getSoeid(res),
        parseCsiid(body.csiid),
        parseTokenName(param(req, 'tokenName')),

      );

    }),
    update: asyncHandler(async function patUpdate(req, res) {
      const body = parse(patBodySchema, req.body);
      res.json(
        await container.pats.update(
          getSoeid(res),
          parseCsiid(body.csiid),
          parseTokenName(param(req, 'tokenName')),
          body.token,
        ),
      );

      const tokenName = parseTokenName(param(req, 'tokenName'));

import { createHash, timingSafeEqual } from 'node:crypto';
import type { NextFunction, Request, RequestHandler, Response } from 'express';
import jwt from 'jsonwebtoken';
import type { AppConfig } from '../config/env.js';
import type { Principal } from '../types.js';
import { ForbiddenError, UnauthorizedError } from '../utils/errors.js';
import { parseSoeid } from '../utils/names.js';

const sha256 = (value: string): Buffer => createHash('sha256').update(value).digest();

/** Constant-time string comparison (hashing equalises lengths). */
export function safeEqual(a: string, b: string): boolean {
  return timingSafeEqual(sha256(a), sha256(b));
}

export function checkAdminCredentials(auth: AppConfig['auth'], username: string, password: string): boolean {
  // Evaluate both so timing does not reveal which one was wrong.
  const userOk = safeEqual(username, auth.adminUsername);
  const passOk = safeEqual(password, auth.adminPassword);
  return userOk && passOk;
}

export function signToken(auth: AppConfig['auth'], principal: Principal): string {
  return jwt.sign({ role: principal.role }, auth.secretKey, {
    algorithm: 'HS256',
    subject: principal.soeid,
    expiresIn: auth.expiresIn as jwt.SignOptions['expiresIn'],
  });
}

export function getPrincipal(res: Response): Principal {
  const principal = res.locals.principal as Principal | undefined;
  if (!principal) throw new UnauthorizedError();
  return principal;
}

/** `Authorization: Bearer <jwt>` → `res.locals.principal`. */
export function authenticate(auth: AppConfig['auth']): RequestHandler {
  return function authenticateRequest(req: Request, res: Response, next: NextFunction) {
    const match = /^Bearer (\S+)$/.exec(req.headers.authorization ?? '');
    if (!match?.[1])
      return next(
        new UnauthorizedError(
          'A Workspace Manager bearer token is required. Obtain one using /api/v1/login and send Authorization: Bearer <token>.',
        ),
      );
    try {
      const decoded = jwt.verify(match[1], auth.secretKey, { algorithms: ['HS256'] });
      if (typeof decoded === 'string' || typeof decoded.sub !== 'string') throw new Error('malformed claims');
      const role = decoded.role === 'admin' ? 'admin' : 'user';
      res.locals.principal = { soeid: decoded.sub, role } satisfies Principal;
      return next();
    } catch (error) {
      const detail =
        error instanceof jwt.TokenExpiredError
          ? 'The Workspace Manager authentication token has expired.'
          : error instanceof jwt.NotBeforeError
            ? 'The Workspace Manager authentication token is not valid yet.'
            : error instanceof jwt.JsonWebTokenError && error.message === 'invalid signature'
              ? 'Workspace Manager token signature verification failed.'
              : 'The Workspace Manager authentication token is malformed or unsupported.';
      return next(
        new UnauthorizedError(
          `${detail} Obtain a new token using /api/v1/login and send it as Authorization: Bearer <token>.`,
        ),
      );
    }
  };
}

/** Validates `:soeid` and makes sure the caller may act for that user (admins may act for anyone). */
export function authorizeSoeid(): RequestHandler {
  return function authorizeUser(req: Request, res: Response, next: NextFunction) {
    try {
      const soeid = parseSoeid(req.params.soeid ?? '');
      const principal = getPrincipal(res);
      if (principal.role !== 'admin' && principal.soeid.toLowerCase() !== soeid) {
        throw new ForbiddenError('You may only access your own resources');
      }
      res.locals.soeid = soeid;
      next();
    } catch (error) {
      next(error);
    }
  };
}

export const getSoeid = (res: Response): string => res.locals.soeid as string;

/src/http/errors.ts
import type { ErrorRequestHandler, NextFunction, Request, RequestHandler, Response } from 'express';
import { AppError, NotFoundError, errorMessage } from '../utils/errors.js';
import type { Logger } from '../utils/logger.js';

export interface ErrorBody {
  error: string;
  message: string;
  code: string;
}

export const errorBody = (message: string, code: string): ErrorBody => ({ error: message, message, code });

/** Express 4 does not catch rejected promises; this forwards them to the error handler. */
export const asyncHandler =
  (fn: (req: Request, res: Response) => Promise<void>): RequestHandler =>
  (req, res, next: NextFunction) => {
    fn(req, res).catch(next);
  };

export const notFoundHandler: RequestHandler = function routeNotFound(req, _res, next) {
  next(new NotFoundError(`Route not found: ${req.method} ${req.path}`, 'ROUTE_NOT_FOUND'));
};

export function createErrorHandler(logger: Logger): ErrorRequestHandler {
  return function handleRequestError(err: unknown, req, res, next) {
    if (res.headersSent) return next(err);
    const requestId = res.locals.requestId as string | undefined;

    if (err instanceof AppError) {
      logger[err.status >= 500 ? 'error' : 'warn']('request.failed', {
        requestId,
        method: req.method,
        path: req.originalUrl?.split('?')[0] ?? req.path,
        status: err.status,
        code: err.code,
        error: err,
      });
      res.status(err.status).json(errorBody(err.message, err.code));
      return;
    }
    // body-parser errors carry a status and a type
    const parserError = err as { status?: number; type?: string };
    if (parserError.type === 'entity.parse.failed') {
      logger.warn('request.failed', {
        requestId,
        method: req.method,
        path: req.path,
        status: 400,
        code: 'INVALID_JSON',
        error: 'Request body is not valid JSON',
      });
      res.status(400).json(errorBody('Request body is not valid JSON', 'INVALID_JSON'));
      return;
    }
    if (parserError.type === 'entity.too.large') {
      logger.warn('request.failed', {
        requestId,
        method: req.method,
        path: req.path,
        status: 413,
        code: 'PAYLOAD_TOO_LARGE',
        error: 'Request body is too large',
      });
      res.status(413).json(errorBody('Request body is too large', 'PAYLOAD_TOO_LARGE'));
      return;
    }
    // Never leak internals for unexpected errors.
    logger.error('request.crashed', {
      requestId,
      path: req.path,
      error: err instanceof Error ? err : errorMessage(err),
    });
    res.status(500).json(errorBody('Internal server error', 'INTERNAL_ERROR'));
  };
}

  });

import pg from 'pg';
import type { AppConfig } from '../../config/env.js';
import type { MetricsRecord } from '../../types.js';
import { errorMessage } from '../../utils/errors.js';
import { silentLogger, type Logger } from '../../utils/logger.js';
import type { MetricsStore } from '../ports.js';
import { buildSslOptions } from './pg-ssl.js';

/** The subset of `pg.Pool` the repository needs (also satisfied by pg-mem's pool in tests). */
export interface Queryable {
  query(text: string, values?: unknown[]): Promise<unknown>;
  end(): Promise<void>;
}

const TABLE_RE = /^("[\w-]+"|[A-Za-z_]\w*)(\.("[\w-]+"|[A-Za-z_]\w*))?$/;

export function assertSafeTableName(table: string): string {
  if (!TABLE_RE.test(table)) throw new Error(`Unsafe metrics table name: ${table}`);
  return table;
}

/** `metrics."devspaces-metrics-dev"` → `{ schema: 'metrics', name: 'devspaces-metrics-dev' }`. */
export function parseTableName(table: string): { schema?: string; name: string } {
  const unq = (s: string): string => s.replace(/^"|"$/g, '');
  const parts = assertSafeTableName(table).match(/"[\w-]+"|[A-Za-z_]\w*/g) ?? [];
  const name = unq(parts[parts.length - 1] ?? '');
  return parts.length > 1 ? { schema: unq(parts[0] ?? ''), name } : { name };
}

export function createPgPool(config: AppConfig['postgres'], logger: Logger = silentLogger): pg.Pool {
  const pool = new pg.Pool({
    host: config.host,
    port: config.port,
    database: config.database,
    user: config.user,
    password: config.password,
    ssl: buildSslOptions(config),
    max: 5,
    connectionTimeoutMillis: 3000,
    idleTimeoutMillis: 30_000,
    statement_timeout: 5000,
  });
  // An idle client dropped by the server emits 'error'; unhandled, it would crash the process.
  pool.on('error', function onPoolError(error) {
    logger.error('postgres.pool_error', { error });
  });
  return pool;
}

/** Database timestamps use UTC wall-clock text: `2026-01-02 03:04:05.678`. */
export const formatUtc = (date: Date): string => date.toISOString().replace('T', ' ').replace('Z', '');

/** Every value the service can store, keyed by column name. */
export function candidateColumns(r: MetricsRecord): Record<string, unknown> {
  return {
    timestamp: formatUtc(r.timestamp),
    csiid: r.csiid,
    soeid: r.soeid,
    eventtype: r.eventtype,
    resourcename: r.resourcename,
    resourcetype: r.resourcetype,
    status: JSON.stringify(r.status),
    limitcpu: r.limitcpu,
    limitmemory: r.limitmemory,
    requestcpu: r.requestcpu,
    requestmemory: r.requestmemory,
    duration: r.duration,
    storage: r.storage,
    useraction: r.useraction,
    workspaceversion: r.workspaceversion,
    editorname: r.editorname,
    errordetail: r.status.failed ? r.status.error : null,
  };
}

/**
 * Writes metrics rows into an EXISTING table. It never issues DDL (no CREATE/ALTER/DROP): it reads the table's
 * column list once and inserts only the columns that exist, so a table that predates some of our fields still works.
 */
export class MetricsRepository implements MetricsStore {
  private readonly table: string;
  private columns?: Promise<Set<string> | undefined>;
  private warnedMissing = false;

  constructor(
    private readonly db: Queryable,
    table = 'metrics."devspaces-metrics"',
    private readonly logger: Logger = silentLogger,
  ) {
    this.table = assertSafeTableName(table);
  }

  private knownColumns(): Promise<Set<string> | undefined> {
    this.columns ??= this.discoverColumns();
    return this.columns;
  }

  /**
   * Read-only column discovery, two independent ways: the catalog (works with INSERT-only privileges),
   * then an empty SELECT whose result metadata lists the columns (works when the catalog is hidden).
   */
  private async discoverColumns(): Promise<Set<string> | undefined> {
    const errors: string[] = [];

    try {
      const { schema, name } = parseTableName(this.table);
      const result = (await this.db.query(
        schema
          ? 'SELECT column_name FROM information_schema.columns WHERE table_schema = $1 AND table_name = $2'
          : 'SELECT column_name FROM information_schema.columns WHERE table_schema = current_schema() AND table_name = $1',
        schema ? [schema, name] : [name],
      )) as { rows?: { column_name: string }[] };
      const names = (result.rows ?? []).map((row) => row.column_name.toLowerCase());
      if (names.length > 0) return new Set(names);
    } catch (error) {
      errors.push(`information_schema: ${errorMessage(error)}`);
    }

    try {
      const result = (await this.db.query(`SELECT * FROM ${this.table} LIMIT 0`)) as {
        fields?: { name: string }[];
      };
      const names = (result.fields ?? []).map((field) => field.name.toLowerCase());
      if (names.length > 0) return new Set(names);
    } catch (error) {
      errors.push(`select: ${errorMessage(error)}`);
      // Do not cache a failure: try again on the next insert.
      this.columns = undefined;
    }

    this.logger.warn('metrics.columns_unknown', {
      table: this.table,
      reason: 'could not read the table columns; inserting all fields',
      errors: errors.join(' | '),
    });
    return undefined;
  }

  async insert(record: MetricsRecord): Promise<void> {
    const all = candidateColumns(record);
    const known = await this.knownColumns();
    const names = known ? Object.keys(all).filter((column) => known.has(column)) : Object.keys(all);

    if (known && !this.warnedMissing) {
      const missing = Object.keys(all).filter((column) => !known.has(column));
      if (missing.length > 0) {
        this.warnedMissing = true;
        this.logger.warn('metrics.columns_missing', { table: this.table, missing: missing.join(',') });
      }
    }
    if (names.length === 0) throw new Error(`Table ${this.table} has none of the expected metrics columns`);

    const columns = names.map((column) => `"${column}"`).join(', ');
    const placeholders = names.map((_, i) => `$${i + 1}`).join(', ');
    await this.db.query(
      `INSERT INTO ${this.table} (${columns}) VALUES (${placeholders})`,
      names.map((column) => all[column]),
    );
  }

  async ping(): Promise<void> {
    await this.db.query('SELECT 1');
  }

  close(): Promise<void> {
    return this.db.end();
  }
}

/** Used when POSTGRES_ENABLED=false (local runs); drops records. */
export class NoopMetricsStore implements MetricsStore {
  async insert(): Promise<void> {}
  async ping(): Promise<void> {}
  async close(): Promise<void> {}
}

    subject: string,

  ): Promise<void> {

    if (!url) {
      this.logger.debug('email.skipped', { reason: 'NOTIFICATION_MAIL_URL not set', subject });
      return;

export class DeploymentNamespaceService {
  constructor(
    private readonly kube: KubeGateway,
    private readonly recorder: MetricsRecorder,
    private readonly notifier: Notifier,
    private readonly requester: string,
    private readonly logger: Logger = silentLogger,
  ) {}

  async list(soeid: string): Promise<string[]> {
    const pattern = new RegExp(`^${soeid}-devspaces-deploy-\\d+$`);
    const all = await this.kube.listNamespaces();
    return all.map((ns) => ns.metadata?.name ?? '').filter((name) => pattern.test(name));
  }

  /** Returns the existing deployment project for this CSI id, or creates and provisions a new one. */
  async ensure(soeid: string, csiid: string): Promise<DeploymentEnsureResult> {
    const desired = deploymentNamespace(soeid, csiid);
    if (await this.kube.getNamespace(desired)) {
      await this.notifier.namespaceAlreadyExists({
        soeid,
        newNamespace: desired,
        existingNamespace: desired,
      });
      return { exists: true, name: desired };
    }

    const actual = await this.recorder.track(
      { soeid, csiid, eventtype: 'create', resourcetype: 'deployment_namespace', resourcename: desired },
      () => this.createAndProvision(soeid, csiid, desired),
    );
    await this.notifier.namespaceCreated({ soeid, namespace: actual });
    return { exists: false, name: actual };
  }

  private async createAndProvision(soeid: string, csiid: string, desired: string): Promise<string> {
    const project = await this.kube.createProject({
      metadata: {
        name: desired,
        labels: {
          [LABEL_COMPONENT]: LABEL_DEPLOYMENT_NAMESPACE,
          'app.kubernetes.io/managed-by': 'devspaces-support-team',
          'devspaces.citi.com/purpose': 'deployment-resource-management',
          [LABEL_CSIID]: csiid,
        },
        annotations: {
          [ANNOTATION_CHE_USERNAME]: soeid,
          'devspaces.citi.com/creator': 'workspace-manager-automation',
          'openshift.io/requester': this.requester,
          'openshift.io/display-name': `DevSpaces Deployment Project for User ${soeid} [CSIID: ${csiid}]`,
          'openshift.io/description': `Temporary deployment testing project for user ${soeid} [CSIID: ${csiid}], removable by DevSpaces support`,
        },
      },
    });
    const name = project.metadata?.name ?? desired;

    await this.reconcile(soeid, name);
    this.logger.success('deployment_namespace.created', { soeid, namespace: name });
    return name;
  }

  private async grantAccess(soeid: string, namespace: string): Promise<void> {
    for (const role of [BUILDER_ROLE_CONFIG, DEPLOYER_ROLE_CONFIG]) {
      const roleName = role.metadata?.name ?? '';
      await this.kube.apply('Role', namespace, role);
      await this.kube.apply('RoleBinding', namespace, this.binding(soeid, namespace, roleName));
    }
  }

  async reconcile(soeid: string, namespace: string): Promise<void> {
    await this.kube.apply('ResourceQuota', namespace, DEPLOYMENT_RESOURCE_QUOTA_COMPUTE_CONFIG);
    await this.kube.apply('LimitRange', namespace, DEPLOYMENT_LIMIT_RANGE_DEFAULT_CONFIG);
    await this.kube.apply('ResourceQuota', namespace, DEPLOYMENT_RESOURCE_QUOTA_STORAGE_CONFIG);
    await this.grantAccess(soeid, namespace);
  }

  private binding(soeid: string, namespace: string, roleName: string): KubeObject {
    return {
      apiVersion: 'rbac.authorization.k8s.io/v1',
      kind: 'RoleBinding',
      metadata: { name: `${roleName}-${soeid}-binding` },
      subjects: [
        { kind: 'User', name: soeid, apiGroup: 'rbac.authorization.k8s.io' },
        { kind: 'ServiceAccount', name: 'default', namespace },
      ],
      roleRef: { apiGroup: 'rbac.authorization.k8s.io', kind: 'Role', name: roleName },
    };
  }

  async delete(soeid: string): Promise<DeploymentDeleteResult> {
    const names = await this.list(soeid);
    if (names.length === 0) {
      return { exists: false, deleted: [], failed: [], message: 'No deployment namespaces found for user.' };
    }

    const deleted: string[] = [];
    const failed: string[] = [];
    for (const name of names) {
      try {
        await this.recorder.track(
          {
            soeid,
            csiid: csiidFromDeploymentNamespace(name) ?? '',
            eventtype: 'delete',
            resourcetype: 'deployment_namespace',
            resourcename: name,
          },
          () => this.kube.deleteNamespace(name),
        );
        deleted.push(name);
      } catch (error) {
        this.logger.error('deployment_namespace.delete_failed', {
          soeid,
          namespace: name,
          error: error,
        });
        failed.push(name);
      }
    }

    if (deleted.length > 0) await this.notifier.namespacesDeleted({ soeid, namespaces: deleted });

    const parts: string[] = [];
    if (deleted.length > 0)
      parts.push(`Deleted ${deleted.length} deployment namespace(s): ${deleted.join(', ')}`);
    if (failed.length > 0) parts.push(`Failed to delete ${failed.length}: ${failed.join(', ')}`);
    return { exists: deleted.length > 0, deleted, failed, message: parts.join('. ') };
  }

/src/services/MetricsRecorder.ts
import { buildLogRecord, type MetricsInput } from '../factories/log-factory.js';
import type { MetricsRecord } from '../types.js';
import { systemClock, type Clock, type MetricsStore } from '../infra/ports.js';
import { errorMessage } from '../utils/errors.js';
import { silentLogger, type Logger } from '../utils/logger.js';

export type MetricBase = MetricsInput;

/**
 * Writes one metrics row per user action. Recording is best-effort: a slow or broken database is logged
 * and never fails the user's action.
 */
export class MetricsRecorder {
  constructor(
    private readonly store: MetricsStore,
    private readonly clock: Clock = systemClock,
    private readonly logger: Logger = silentLogger,
    private readonly timeoutMs = 2000,
  ) {}

  async record(input: MetricsInput): Promise<void> {
    const record = buildLogRecord(input, this.clock.now());
    let timer: NodeJS.Timeout | undefined;
    try {
      await Promise.race([
        this.store.insert(record),
        new Promise<never>((_, reject) => {
          timer = setTimeout(
            () => reject(new Error(`metrics insert timed out after ${this.timeoutMs}ms`)),
            this.timeoutMs,
          );
        }),
      ]);
    } catch (error) {
      this.logger.error('metrics.insert_failed', {
        soeid: record.soeid,
        eventtype: record.eventtype,
        resourcetype: record.resourcetype,
        error: error,
      });
    } finally {
      if (timer) clearTimeout(timer);
    }
  }

  /** Run `fn`, record success (with optional extra fields from the result) or failure, and pass the outcome through. */
  async track<T>(
    base: MetricBase,
    fn: () => Promise<T>,
    onSuccess?: (result: T) => Partial<MetricsRecord>,
  ): Promise<T> {
    let result: T;
    try {
      result = await fn();
    } catch (error) {
      await this.record({ ...base, status: { failed: true, error: errorMessage(error), message: '' } });
      throw error;
    }
    await this.record({ ...base, ...(onSuccess?.(result) ?? {}) });
    return result;
  }
}

    return name;
  }

  async ensure(soeid: string, csiid: string): Promise<EnsuredNamespace> {
    const name = workspaceNamespace(soeid, csiid);
    const existing = await this.kube.getNamespace(name);
    if (existing) {
      this.assertOwner(existing, soeid);
      return { name, created: false };
    }

    this.logger.info('namespace.creating', { soeid, namespace: name });
    const created = await this.recorder.track(
      { soeid, csiid, eventtype: 'create', resourcetype: 'project', resourcename: name },
      () => this.createAndProvision(soeid, csiid, name),
    );
    return { name, created };
  }

  private async createAndProvision(soeid: string, csiid: string, name: string): Promise<boolean> {
    try {
      await this.kube.createNamespace({
        apiVersion: 'v1',
        kind: 'Namespace',
        metadata: {
          name,
          labels: {
            [LABEL_COMPONENT]: LABEL_WORKSPACES_NAMESPACE,
            'app.kubernetes.io/part-of': 'che.eclipse.org',
            'app.kubernetes.io/managed-by': 'workspace-mgr',
            [LABEL_CSIID]: csiid,
          },
          annotations: { [ANNOTATION_CHE_USERNAME]: soeid },
        },
      });

        // Another request created it between our read and write; use theirs.
        const raced = await this.kube.getNamespace(name);
        if (raced) {
          this.assertOwner(raced, soeid);
          return false;

      throw error;
    }

    try {
      await this.reconcile(soeid, name);
    } catch (error) {
      this.logger.error('namespace.provision_failed', { soeid, namespace: name, error });
      await this.kube.deleteNamespace(name).catch(() => false);
      throw error;
    }
    return true;
  }

        apiGroup: 'rbac.authorization.k8s.io',
      },
    });

    await this.kube.apply('LimitRange', namespace, ORION_LIMIT_RANGE_CONFIG);
    for (const policy of NETWORK_POLICIES_DEFAULT_CONFIG) {
      await this.kube.apply('NetworkPolicy', namespace, policy);
    }
    await this.applyProxyConfig(soeid, namespace);
  }

  private async applyProxyConfig(soeid: string, namespace: string): Promise<void> {

    if (!proxy) return;
    const noProxy = 'localhost,127.0.0.1,*.svc,*.svc.cluster.local';

    await this.kube.apply('ConfigMap', namespace, {
      apiVersion: 'v1',
      kind: 'ConfigMap',
      metadata: {
        name: 'proxy-env-vars-ws-mgr',
        labels: {
          'controller.devfile.io/mount-to-devworkspace': 'true',
          'controller.devfile.io/watch-configmap': 'true',
        },
        annotations: { 'controller.devfile.io/mount-as': 'env' },
      },
      data: {
        HTTP_PROXY: proxy,
        HTTPS_PROXY: proxy,
        http_proxy: proxy,
        https_proxy: proxy,
        NO_PROXY: noProxy,
        no_proxy: noProxy,
      },
    });

    await this.kube.apply('ConfigMap', namespace, {
      apiVersion: 'v1',
      kind: 'ConfigMap',
      metadata: {
        name: 'workspace-userdata-gitconfig-configmap-ws-mgr',
        labels: {
          'controller.devfile.io/mount-to-devworkspace': 'true',
          'controller.devfile.io/watch-configmap': 'true',
        },
        annotations: {
          'controller.devfile.io/mount-as': 'subpath',
          'controller.devfile.io/mount-path': '/etc/',
        },

  }

  }

/** Readable terminal logs with timestamps and source locations. */

export type LogKind = 'debug' | 'info' | 'success' | 'warn' | 'error';

const ESC = '\u001b[';
export const RESET = `${ESC}0m`;
export const COLORS: Record<LogKind, string> = {
  error: `${ESC}31m`, // red
  warn: `${ESC}38;5;208m`, // orange
  success: `${ESC}32m`, // green
  info: `${ESC}97m`, // white
  debug: `${ESC}97m`, // white
};

const BADGE: Record<LogKind, string> = {
  error: 'ERROR',
  warn: 'WARN ',
  success: 'OK   ',
  info: 'INFO ',
  debug: 'DEBUG',
};

const EVENT_WIDTH = 30;
const BLOCK_INDENT = '    ';
const MAX_INLINE_FIELDS = 6;
const MAX_INLINE_VALUE = 80;
const MAX_INLINE_TOTAL = 120;

export interface LogEntry {
  time: Date;
  kind: LogKind;
  event: string;
  fields: Record<string, unknown>;
}

const pad2 = (n: number): string => String(n).padStart(2, '0');

/** Local time `2026-10-24 03:12:45`. */
export function formatLocalTime(d: Date): string {
  return (
    `${d.getFullYear()}-${pad2(d.getMonth() + 1)}-${pad2(d.getDate())} ` +
    `${pad2(d.getHours())}:${pad2(d.getMinutes())}:${pad2(d.getSeconds())}`
  );
}

type Primitive = string | number | boolean | null | undefined;
const isPrimitive = (v: unknown): v is Primitive => v === null || v === undefined || typeof v !== 'object';
const isPlainObject = (v: unknown): v is Record<string, unknown> =>
  typeof v === 'object' && v !== null && !Array.isArray(v);

const oneLine = (s: string): string => s.replace(/\r?\n/g, '\\n');

/** Inline value: bare when simple, quoted when it contains spaces or `=`. */
function inlineValue(v: Primitive): string {
  if (typeof v !== 'string') return String(v);
  const s = oneLine(v);
  return /^[^\s"=]+$/.test(s) ? s : JSON.stringify(s);
}

/** Value on its own line: strings as they are, arrays as compact JSON. */
function blockValue(v: unknown): string {
  if (typeof v === 'string') return oneLine(v);
  if (Array.isArray(v)) return JSON.stringify(v);
  return String(v);
}

function renderBlock(obj: Record<string, unknown>, indent: string): string[] {
  const entries = Object.entries(obj).filter(([, v]) => v !== undefined);
  const width = Math.max(
    0,
    ...entries.filter(([, v]) => !isPlainObject(v) || Object.keys(v).length === 0).map(([k]) => k.length),
  );
  const lines: string[] = [];
  for (const [key, value] of entries) {
    if (isPlainObject(value) && Object.keys(value).length > 0) {
      lines.push(`${indent}${key}:`);
      lines.push(...renderBlock(value, `${indent}  `));
    } else {
      const text = isPlainObject(value) ? '{}' : blockValue(value);
      lines.push(`${indent}${key.padEnd(width)} : ${text}`);
    }
  }
  return lines;
}

function canInline(fields: [string, unknown][]): boolean {
  if (fields.length > MAX_INLINE_FIELDS) return false;
  let total = 0;
  for (const [k, v] of fields) {
    if (!isPrimitive(v)) return false;
    const text = inlineValue(v);
    if (text.length > MAX_INLINE_VALUE) return false;
    total += k.length + text.length + 3;
  }
  return total <= MAX_INLINE_TOTAL;
}

/** `GET    /api/v1/x -> 200 (12 ms)` for the per-request log line, plus the fields that are not part of it. */
function requestMessage(
  fields: Record<string, unknown>,
): { message: string; rest: Record<string, unknown> } | undefined {
  const { method, path, status, ms, ...rest } = fields;
  if (typeof method !== 'string' || typeof path !== 'string' || typeof status !== 'number') return undefined;
  const took = typeof ms === 'number' ? ` (${ms} ms)` : '';
  return { message: `${method.padEnd(6)} ${path} -> ${status}${took}`, rest };
}

/** One log entry as text. Multi-line entries end with a blank line so that entries stay visually separate. */
export function formatPretty(entry: LogEntry, color: boolean): string {
  const { file = 'unknown', function: functionName = 'module', line, ...data } = entry.fields;
  const location = line === undefined ? String(file) : `${String(file)}:${String(line)}`;
  const prefix = `[${formatLocalTime(entry.time)}] [${oneLine(location)}] [${oneLine(String(functionName))}]`;
  const head = `${prefix} | ${BADGE[entry.kind]} | `;
  const request = entry.event === 'request' ? requestMessage(data) : undefined;
  const fields = Object.entries(request ? request.rest : data).filter(([, v]) => v !== undefined);
  const lines: string[] = [];

  if (fields.length === 0 && !request) {
    lines.push(`${head}${entry.event}`);
  } else if (canInline(fields)) {
    const inline = fields.map(([k, v]) => `${k}=${inlineValue(v as Primitive)}`).join('  ');
    const text = [request?.message, inline].filter(Boolean).join('  ');
    lines.push(`${head}${entry.event.padEnd(EVENT_WIDTH)} | ${text}`);
  } else {
    lines.push(
      request ? `${head}${entry.event.padEnd(EVENT_WIDTH)} | ${request.message}` : `${head}${entry.event}`,
    );
    lines.push(...renderBlock(Object.fromEntries(fields), BLOCK_INDENT).map((line) => `${prefix} ${line}`));
    lines.push(''); // blank line after a multi-line entry
  }

  const paint = (line: string): string =>
    color && line !== '' ? `${COLORS[entry.kind]}${line}${RESET}` : line;
  return lines.map(paint).join('\n');
}

import { formatPretty, formatLocalTime, type LogKind } from './log-format.js';
import { appendDailyLog } from '../config/daily-logs.js';

export type LogLevel = 'debug' | 'info' | 'warn' | 'error' | 'silent';
export type LogFormat = 'json' | 'pretty';

const ORDER: Record<LogLevel, number> = { debug: 10, info: 20, warn: 30, error: 40, silent: 100 };
const SENSITIVE = /token|password|authorization|secret|pat$|credential|cookie/i;

export type LogFields = Record<string, unknown>;

export interface Logger {

  info(event: string, fields?: LogFields): void;
  /** Something finished successfully (a call, a created resource): shown green in the terminal. */
  success(event: string, fields?: LogFields): void;
  warn(event: string, fields?: LogFields): void;
  error(event: string, fields?: LogFields): void;
  child(bindings: LogFields): Logger;
}

export type LogSink = (line: string) => void;

export interface LoggerOptions {

  dailyFiles?: boolean;
  /** `json` (one JSON object per line, for log collectors; the default here) or `pretty` (terminal). */
  format?: LogFormat;

  color?: boolean;

function logSource(error?: Error): { file: string; function: string; line?: number } {
  let fallback: { file: string; function: string; line?: number } | undefined;
  for (const frame of (error?.stack ?? new Error().stack ?? '').split('\n').slice(1)) {
    const match = /^\s*at (?:(.*?) \()?(.+?):(\d+):\d+\)?$/.exec(frame);
    if (!match) continue;
    const path = match[2]?.replaceAll('\\', '/') ?? '';
    if (
      /\/utils\/(?:logger|errors|k8s-errors)\.(?:ts|js)$/.test(path) ||
      path.startsWith('node:') ||
      path.includes('/node_modules/')
    )
      continue;
    const source = {
      file: path.split('/').at(-1) || 'unknown',
      function: match[1] || 'module',
      line: Number(match[3]),
    };
    if (!match[1] || /anonymous/.test(match[1])) {
      fallback ??= { ...source, function: 'module' };
      continue;
    }
    return source;
  }
  return fallback ?? { file: 'unknown', function: 'module' };
}

export function redact(value: unknown, depth = 0): unknown {
  if (depth > 5 || value === null || typeof value !== 'object') return value;
  if (value instanceof Error) return { name: value.name, message: value.message };
  if (Array.isArray(value)) return value.map((v) => redact(v, depth + 1));
  return Object.fromEntries(
    Object.entries(value as Record<string, unknown>).map(([k, v]) => [
      k,
      SENSITIVE.test(k) ? '[redacted]' : redact(v, depth + 1),
    ]),
  );
}

export function createLogger(
  level: LogLevel = 'info',
  sink: LogSink = (line) => process.stdout.write(`${line}\n`),
  bindings: LogFields = {},
  options: LoggerOptions = {},
): Logger {
  const format = options.format ?? 'json';
  const now = options.now ?? (() => new Date());

  const write = (kind: LogKind, event: string, fields?: LogFields): void => {
    // `success` is an info-level message that is shown in green
    const severity: Exclude<LogLevel, 'silent'> = kind === 'success' ? 'info' : kind;
    if (ORDER[severity] < ORDER[level]) return;
    let source = options.source ?? logSource(fields?.error instanceof Error ? fields.error : undefined);
    if (source.file === 'unknown') source = logSource();
    const merged = {
      ...(redact(bindings) as LogFields),
      ...(redact(
        fields?.error instanceof Error ? { ...fields, error: fields.error.message } : (fields ?? {}),
      ) as LogFields),
      ...source,
    };
    const time = now();
    const timestamp = formatLocalTime(time);
    if (options.dailyFiles)
      appendDailyLog(
        JSON.stringify({ ...merged, time: time.toISOString(), timestamp, level: severity, event }),
        time,
      );
    if (format === 'pretty') {
      sink(formatPretty({ time, kind, event, fields: merged }, options.color === true));
      return;
    }
    sink(
      JSON.stringify({
        time: time.toISOString(),
        timestamp,
        level: severity,
        ...(kind === 'success' ? { outcome: 'success' } : {}),
        event,
        ...merged,
      }),
    );
  };

  return {
    debug: (e, f) => write('debug', e, f),
    info: (e, f) => write('info', e, f),
    success: (e, f) => write('success', e, f),
    warn: (e, f) => write('warn', e, f),
    error: (e, f) => write('error', e, f),
    child: (b) => createLogger(level, sink, { ...bindings, ...b }, options),
  };
}

export const silentLogger: Logger = createLogger('silent');

import { describe, expect, it } from 'vitest';
import { createLogger, redact } from '../../../src/utils/logger.js';

function capture(level: Parameters<typeof createLogger>[0] = 'info') {
  const lines: Record<string, unknown>[] = [];
  return { lines, logger: createLogger(level, (l) => lines.push(JSON.parse(l))) };
}

describe('logger', () => {
  it('records the calling file and function with a seconds-resolution timestamp', () => {
    const { lines, logger } = capture();
    function recordEvent() {
      logger.info('source.test');
    }
    recordEvent();
    expect(lines[0]).toMatchObject({ file: 'logger.test.ts', function: 'recordEvent' });
    expect(lines[0]?.timestamp).toMatch(/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$/);
  });
  it('uses an error stack to identify its original file and function', () => {
    const { lines, logger } = capture();
    const error = new Error('creation failed');
    error.stack =
      'Error: creation failed\n    at NamespaceService.ensure (C:\\app\\src\\services\\NamespaceService.ts:42:10)';
    logger.error('namespace.failed', { error });
    expect(lines[0]).toMatchObject({
      file: 'NamespaceService.ts',
      function: 'NamespaceService.ensure',
      error: 'creation failed',
    });
    expect(JSON.stringify(lines[0])).not.toContain('C:\\app');
  });

    const { lines, logger } = capture();

    expect(typeof lines[0]?.time).toBe('string');
  });
