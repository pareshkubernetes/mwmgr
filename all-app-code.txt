# Workspace Mgr

Middleware between the **Orion** dashboard and **Red Hat OpenShift Dev Spaces**. On demand of a user it
creates, lists, starts, stops and deletes DevWorkspaces, creates the user's project (namespace) when it does not
exist, manages per-user Git credentials, and records every action to Postgres for the Dev Spaces dashboard.

Node 20+, TypeScript (strict, ESM), Express 4, `@kubernetes/client-node`, `pg`, `zod`.
Project rules: [docs/PROJECT_RULES.md](docs/PROJECT_RULES.md) · Checklist: [docs/CHECKLIST.md](docs/CHECKLIST.md)

## Quick start

```bash
npm install
cp .env.example .env        # edit; SECRET_KEY, ADMIN_*, DEVREG_URL are required
npm run dev                 # tsx watch (loads env from your shell; use `node --env-file=.env` if you prefer)
npm run build && npm start  # production
```

| Script                                                | What it does                               |
| ----------------------------------------------------- | ------------------------------------------ |
| `npm run typecheck` / `lint` / `format`               | tsc, eslint (0 warnings allowed), prettier |
| `npm test`                                            | unit + integration + e2e                   |
| `npm run test:unit` / `test:integration` / `test:e2e` | one layer                                  |
| `npm run test:coverage`                               | all layers with a coverage gate            |

## Postgres: the existing database

Metrics go into the **existing** Orion database. workspace-mgr creates nothing (no tables, schemas or migrations);
it only inserts rows into the table named by `POSTGRES_DATABASE_TABLENAME`.

Same variables as the original service:

```bash
export POSTGRES_DATABASE=orion_dev_metadata
export POSTGRES_HOSTNAME=NAORI01DPS_INSTANCE1.pgaas.dyn.nsroot.net
export POSTGRES_PASSWORD=...
export POSTGRES_PORT='1524'
export POSTGRES_USER=app_orion_pgsql_dev
export POSTGRES_DATABASE_TABLENAME='metrics."devspaces-metrics-dev"'
export NODE_ENV=development
```

- **TLS** is always on and the server certificate is verified, as before. `NODE_ENV` picks the CA file:
  `development` → `./certs/dev.pem` (hostname check relaxed), `uat` → `/app/backend/cert/uat.pem`,
  `production` → `/app/backend/cert/prod.pem`. Override with `POSTGRES_CERT_DIR` or `POSTGRES_CA_FILE`.
  The app refuses to start, naming the missing file, if the CA cannot be read.
- **Columns:** the service reads the table's column list once and writes only the columns that exist (it knows
  `timestamp, csiid, soeid, eventtype, resourcename, resourcetype, status, limitcpu, limitmemory, requestcpu,
requestmemory, duration, storage, useraction, errordetail, workspaceversion, editorname`). A table without
  `workspaceversion` / `editorname` still works; a warning names what is not stored.
- **Timestamps** are written as UTC wall-clock text, as the original did.
- A database problem never blocks a workspace action: it is logged and the action continues.

## Environment variables

Every variable the team exports is understood as-is (`.env.example` lists them with comments):

| Variable                                         | Meaning                                                                                                                    |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `PORT`                                           | HTTP port (default 3050)                                                                                                   |
| `NODE_ENV`                                       | `development` / `uat` / `production`; also picks the Postgres CA file                                                      |
| `SECRET_KEY`, `ADMIN_USERNAME`, `ADMIN_PASSWORD` | login and JWT signing; **required**, there is no fallback secret                                                           |
| `CLUSTER_API_URL`                                | Dev Spaces cluster API                                                                                                     |
| `devSpacesClusterToken001d`                      | its bearer token, found by name: the `001d` must end the cluster name (`namctigtd001d`)                                    |
| `DEPLOY_CLUSTER_API_URL`, `devOpsToken004d`      | optional separate cluster for build/deploy projects and its token; unset = same cluster (a token for another id is unused) |
| `DEVREG_URL`                                     | devfile registry                                                                                                           |
| `EDITOR_VSCODE`, `EDITOR_INTELLIJ`               | full editor ids, e.g. `che-incubator/che-code/latest`                                                                      |
| `NODE_TLS_REJECT_UNAUTHORIZED=0`                 | do not verify certificates (clusters and every HTTPS peer); a warning is logged at startup                                 |
| `POSTGRES_*`                                     | see "Postgres: the existing database"                                                                                      |

Without a token the service uses `KUBECONFIG_PATH` (or the first command-line argument), then the default kubeconfig /
pod service account. `CLUSTER_TOKEN` and `DEPLOY_CLUSTER_TOKEN` set a token explicitly. The Dev Spaces dashboard address
for the editor link is `DEV_SPACES_SERVICE_FQDN`, or `https://devspaces.apps.<cluster domain>` worked out from `CLUSTER_API_URL`.
At startup the service logs what it understood (which variable supplied each token, never the token itself).

## API (version 1)

All routes live under **`/api/v1`**. Send `Authorization: Bearer <jwt>` except for `login`.
Errors are always `{ "error": string, "message": string, "code": string }`.

| Method | Path                                    | Purpose                                                        |
| ------ | --------------------------------------- | -------------------------------------------------------------- |
| POST   | `/api/v1/login`                         | `{username,password}` → `{token}`                              |
| GET    | `/api/v1/catalog`                       | Stacks from the devfile registry                               |
| GET    | `/api/v1/:soeid/projects`               | The user's projects (namespaces)                               |
| GET    | `/api/v1/:soeid/workspaces`             | List workspaces                                                |
| POST   | `/api/v1/:soeid/workspaces`             | Create a workspace (creates the project if needed)             |
| GET    | `/api/v1/:soeid/workspaces/:id`         | Workspace details                                              |
| DELETE | `/api/v1/:soeid/workspaces/:id`         | Delete                                                         |
| POST   | `/api/v1/:soeid/workspaces/:id/start`   | Start                                                          |
| POST   | `/api/v1/:soeid/workspaces/:id/stop`    | Stop                                                           |
| GET    | `/api/v1/:soeid/pats`                   | List GitHub PAT secrets                                        |
| GET    | `/api/v1/:soeid/pats/:tokenName?csiid=` | View (token is masked)                                         |
| POST   | `/api/v1/:soeid/pats/:tokenName`        | `{csiid,token}` create (409 if it exists)                      |
| PUT    | `/api/v1/:soeid/pats/:tokenName`        | `{csiid,token}` replace                                        |
| DELETE | `/api/v1/:soeid/pats/:tokenName?csiid=` | Delete (idempotent)                                            |
| GET    | `/api/v1/:soeid/gitconfig?csiid=`       | View `~/.gitconfig`                                            |
| PUT    | `/api/v1/:soeid/gitconfig`              | `{csiid,content}` create or replace                            |
| DELETE | `/api/v1/:soeid/gitconfig?csiid=`       | Delete (idempotent)                                            |
| GET    | `/api/v1/:soeid/deployment-projects`    | List build/deploy projects                                     |
| POST   | `/api/v1/:soeid/deployment-projects`    | `{csiid}` → 201 created, or 200 if it already exists           |
| DELETE | `/api/v1/:soeid/deployment-projects`    | Delete all of the user's deployment projects                   |
| GET    | `/healthz`, `/readyz`                   | Liveness (no dependencies) / readiness (Kubernetes + Postgres) |

**Versioning.** `/api/v1` is the contract. A breaking change will ship as `/api/v2` next to it. The old unversioned
paths (`/login`, `/:soeid/...`) still work as **deprecated aliases** (`Deprecation: true`,
`Link: </api/v1/...>; rel="successor-version"`) so Orion keeps working while it migrates. Turn them off with
`LEGACY_UNVERSIONED_ROUTES=false`.

## Hand-over to another computer (`recreate-app.sh`, `all-app-code.txt`)

The app moves between computers as **one text file**, `all-app-code.txt`, and one script, `recreate-app.sh`.
The text file is made for you (by Claude, with `tools/build-all-code.sh`); you only run the script:

```bash
bash recreate-app.sh -f             # inside the app folder: writes the files of ./all-app-code.txt, overwriting
bash recreate-app.sh -f --prune     # also delete files that were removed from the app
bash recreate-app.sh -n             # dry run: show what would happen
bash recreate-app.sh p.txt ./out    # another input file / another folder (existing files are kept without -f)
```

- **First hand-over:** the entire application. **Every later one:** only the new and changed files, plus a list of
  files that were removed (`/_REMOVED.txt`). It ends with what to run next (`npm install`, `npm run build`, ...) when
  something relevant changed.
- **New empty folder:** put `recreate-app.sh` and `all-app-code.txt` in it and run `bash recreate-app.sh -f`, then
  `npm ci && npm test && npm run build && npm start`.
- **Format:** `/path/to/file`, the file's content, a blank line, next file. Files that cannot be shown as exact plain
  text (CRLF line endings, no final newline, odd names) are stored as base64 after `@@BINARY-SECTION`; the plain files
  are LF, so an editor, e-mail or git changing line endings cannot damage anything.
- **Safe:** the text file ends with a SHA-256 for every file; they are all checked in a temp folder before your files are
  touched. Existing files that differ are kept unless you pass `-f`. Paths that could escape the folder are rejected.
  `recreate-app.sh` never replaces itself while running; a newer version is saved as `recreate-app.sh.new`.
- **Never in a hand-over:** `node_modules`, `dist`, `coverage`, `.git`, `legacy`, `tools`, `.env*` (secrets), private keys.
- **For the maintainer:** `bash tools/build-all-code.sh` builds the next hand-over (entire app the first time, then
  only changes; `--full`, `--list`, `--redo` and `--keep-state` exist). What the other computer has is remembered in
  `.handover-state` (not committed). Before saving, the file is recreated in a temp folder and compared byte for byte.

/** `'1524'` → `1524`, `"a b"` → `a b`; anything not wrapped in one matching pair of quotes is untouched. */
export function unquote(value: string): string {
  const match = /^(['"])(.*)\1$/s.exec(value);
  return match?.[2] ?? value;
}

/** `che-code` → `che-incubator/che-code/latest`; `che-incubator/che-code/latest` is kept as it is. */
export function normalizeEditorId(value: string): string {
  const v = value.trim();
  return v.includes('/') ? v : `che-incubator/${v}/latest`;
}

/** `https://api.namctigtd001d.ecs.dyn.example.net:6443` → `namctigtd001d`. */
export function clusterNameOf(apiUrl: string): string | undefined {
  try {
    const host = new URL(apiUrl).hostname;
    return host.startsWith('api.') ? host.split('.')[1] : undefined;
  } catch {
    return undefined;
  }
}

/** `https://api.<rest>:6443` → `https://devspaces.apps.<rest>` (the usual Dev Spaces dashboard host). */
export function deriveDevSpacesFqdn(apiUrl: string): string {
  try {
    const host = new URL(apiUrl).hostname;
    return host.startsWith('api.') ? `https://devspaces.apps.${host.slice('api.'.length)}` : '';
  } catch {
    return '';
  }
}

export interface FoundToken {
  /** The environment variable the token came from (never the token itself). */
  name: string;
  value: string;
}

/**
 * Finds the bearer token for a cluster by variable name: `<prefix><id>`, e.g. devSpacesClusterToken001d for the cluster
 * `namctigtd001d` (the id must be the end of the cluster name). A variable without an id (`<prefix>`) fits any cluster.
 * Tokens that belong to another cluster are ignored, so a leftover `devOpsToken004d` is never sent to cluster 001d.
 */
export function findClusterToken(
  env: Record<string, string | undefined>,
  prefix: string,
  apiUrl: string,
): FoundToken | undefined {
  const cluster = (clusterNameOf(apiUrl) ?? '').toLowerCase();
  const fits = Object.keys(env)
    .filter((k) => k.toLowerCase().startsWith(prefix.toLowerCase()) && env[k])
    .filter((k) => {
      const id = k.slice(prefix.length).toLowerCase();
      return id === '' || (cluster !== '' && cluster.endsWith(id));
    });
  if (fits.length > 1) {
    throw new Error(
      `Invalid configuration:\n  - several variables fit one cluster token: ${fits.join(', ')}`,
    );
  }
  const name = fits[0];
  return name ? { name, value: env[name] as string } : undefined;
}

    table: string;
  };

    url?: string;
    username: string;

  };

/** What the service understood from its environment, for the startup log. Contains no secret values. */
export function startupSummary(c: AppConfig): Record<string, unknown> {
  const auth = (tokenVar: string | undefined, kubeconfig: string | undefined): string =>
    tokenVar
      ? `bearer token from ${tokenVar}`
      : kubeconfig
        ? 'kubeconfig file'
        : 'default kubeconfig / pod service account';
  return {
    port: c.port,
    nodeEnv: c.nodeEnv,
    cluster: c.cluster.apiUrl,
    clusterAuth: auth(c.cluster.tokenVar, c.cluster.kubeconfigPath),
    deployCluster: c.cluster.deployApiUrl,
    deployClusterAuth:
      c.cluster.deployApiUrl === c.cluster.apiUrl
        ? 'same cluster'
        : auth(c.cluster.deployTokenVar, c.cluster.kubeconfigPath),
    devSpacesFqdn: c.cluster.devSpacesServiceFqdn,
    devfileRegistry: c.devreg.url,
    editors: c.devreg.editors,
    clusterTls: c.cluster.tlsRejectUnauthorized
      ? 'certificates verified'
      : 'NOT verified (NODE_TLS_REJECT_UNAUTHORIZED=0)',
    postgres: c.postgres.enabled
      ? {
          host: c.postgres.host,
          port: c.postgres.port,
          database: c.postgres.database,
          table: c.postgres.table,
        }
      : 'disabled',
  };
}

/** Parse and validate the environment once, at startup. Throws a readable error listing every problem. */
export function loadConfig(env: NodeJS.ProcessEnv = process.env): AppConfig {
  // An exported-but-empty variable (`FOO=`) is treated as unset. Values that still carry their shell quotes
  // (`'1524'`, `'metrics."devspaces-metrics-dev"'` from a .env file or a pasted export line) are unwrapped.
  const cleaned = Object.fromEntries(
    Object.entries(env)
      .filter(([, v]) => v !== undefined && v !== '')
      .map(([k, v]) => [k, unquote(v as string)]),
  );
  const parsed = schema.safeParse(cleaned);
  if (!parsed.success) {
    const problems = parsed.error.issues.map((i) => `${i.path.join('.') || '(root)'}: ${i.message}`);
    throw new Error(`Invalid configuration:\n  - ${problems.join('\n  - ')}`);
  }
  const e = parsed.data;
  if (e.POSTGRES_ENABLED && (!e.POSTGRES_DATABASE || !e.POSTGRES_USER)) {
    throw new Error(
      'Invalid configuration:\n  - POSTGRES_DATABASE and POSTGRES_USER are required when POSTGRES_ENABLED=true',
    );
  }

  const deployApiUrl = e.DEPLOY_CLUSTER_API_URL ?? e.CLUSTER_API_URL;
  const separateDeployCluster = deployApiUrl !== e.CLUSTER_API_URL;
  const main = e.CLUSTER_TOKEN
    ? { name: 'CLUSTER_TOKEN', value: e.CLUSTER_TOKEN }
    : findClusterToken(cleaned, 'devSpacesClusterToken', e.CLUSTER_API_URL);
  const deploy = !separateDeployCluster
    ? undefined
    : e.DEPLOY_CLUSTER_TOKEN
      ? { name: 'DEPLOY_CLUSTER_TOKEN', value: e.DEPLOY_CLUSTER_TOKEN }
      : findClusterToken(cleaned, 'devOpsToken', deployApiUrl);
  if (separateDeployCluster && !deploy && !e.KUBECONFIG_PATH) {
    throw new Error(
      `Invalid configuration:\n  - DEPLOY_CLUSTER_API_URL is set to a different cluster but no token was found for it ` +
        `(set DEPLOY_CLUSTER_TOKEN, or devOpsToken<id> where <id> ends the cluster name)`,
    );
  }

  return {
    port: e.PORT,
    nodeEnv: e.NODE_ENV,
    logLevel: e.LOG_LEVEL,
    legacyRoutes: e.LEGACY_UNVERSIONED_ROUTES,
    auth: {
      secretKey: e.SECRET_KEY,
      adminUsername: e.ADMIN_USERNAME,
      adminPassword: e.ADMIN_PASSWORD,
      expiresIn: e.JWT_EXPIRES_IN,
    },
    cluster: {
      apiUrl: e.CLUSTER_API_URL,
      token: main?.value,
      tokenVar: main?.name,
      deployApiUrl,
      deployToken: deploy?.value,
      deployTokenVar: deploy?.name,
      tlsRejectUnauthorized: cleaned.NODE_TLS_REJECT_UNAUTHORIZED !== '0',
      kubeconfigPath: e.KUBECONFIG_PATH,
      deployProjectRequester: e.DEPLOY_PROJECT_REQUESTER,
      devSpacesServiceFqdn: e.DEV_SPACES_SERVICE_FQDN ?? deriveDevSpacesFqdn(e.CLUSTER_API_URL),
    },
    devreg: {
      url: e.DEVREG_URL,
      editors: {
        vscode: normalizeEditorId(e.EDITOR_VSCODE),
        intellij: normalizeEditorId(e.EDITOR_INTELLIJ),
        goland: normalizeEditorId(e.EDITOR_GOLAND),
      },
      workspaceProxyUrl: e.WORKSPACE_PROXY_URL,
    },
    limits: { maxRunning: e.MAX_RUNNING_WORKSPACES, maxTotal: e.MAX_TOTAL_WORKSPACES },
    postgres: {
      enabled: e.POSTGRES_ENABLED,
      host: e.POSTGRES_HOSTNAME,
      port: e.POSTGRES_PORT,
      database: e.POSTGRES_DATABASE,
      user: e.POSTGRES_USER,
      password: e.POSTGRES_PASSWORD,
      ssl: e.POSTGRES_SSL,
      caFile: e.POSTGRES_CA_FILE,
      certDir: e.POSTGRES_CERT_DIR,
      env: e.NODE_ENV,
      table: e.POSTGRES_DATABASE_TABLENAME,
    },
    notification: {
      url: e.NOTIFICATION_MAIL_URL,
      username: e.NOTIFICATION_EMAIL_USERNAME,
      password: e.NOTIFICATION_EMAIL_PASSWORD,
      sender: e.NOTIFICATION_SENDER,
      cc: e.NOTIFICATION_CC,
      emailDomain: e.EMAIL_DOMAIN,
      userDirectoryUrl: e.USER_DIRECTORY_GRAPHQL_URL,
    },
    github: { url: e.GITHUB_URL.replace(/\/$/, ''), userSuffix: e.GITHUB_USER_SUFFIX },
  };
}

/** The single place where adapters are wired into services. Tests call this with fakes. */
export function buildContainer(config: AppConfig, logger: Logger, deps: Dependencies): Container {
  const clock = deps.clock ?? systemClock;
  const recorder = new MetricsRecorder(deps.metrics, clock, logger);
  const namespaces = new NamespaceService(
    deps.kube,
    recorder,
    { workspaceProxyUrl: config.devreg.workspaceProxyUrl, emailDomain: config.notification.emailDomain },
    logger,
  );
  return {
    config,
    logger,
    kube: deps.kube,
    deployKube: deps.deployKube ?? deps.kube,
    metrics: deps.metrics,
    registry: deps.registry,
    recorder,
    namespaces,
    workspaces: new WorkspaceService(
      deps.kube,
      namespaces,
      deps.registry,
      recorder,
      {
        limits: config.limits,
        editors: config.devreg.editors,
        devSpacesServiceFqdn: config.cluster.devSpacesServiceFqdn,
      },
      clock,
      logger,
    ),
    pats: new PatService(deps.kube, namespaces, recorder, config.github),
    gitConfig: new GitConfigService(deps.kube, namespaces, recorder),
    deployments: new DeploymentNamespaceService(
      deps.deployKube ?? deps.kube,
      recorder,
      deps.notifier,
      config.cluster.deployProjectRequester,
      logger,
    ),
  };

/** Real adapters for a running pod. */
export function createProductionDependencies(config: AppConfig, logger: Logger): Dependencies {
  const directory = config.notification.userDirectoryUrl
    ? new GraphqlUserDirectory(config.notification.userDirectoryUrl, logger)
    : new NullUserDirectory();
  const { cluster } = config;
  const skipTlsVerify = !cluster.tlsRejectUnauthorized;
  const separateDeploy = cluster.deployApiUrl !== cluster.apiUrl;
  return {
    kube: new KubeClient(
      createKubeConfig({
        apiUrl: cluster.apiUrl,
        token: cluster.token,
        kubeconfigPath: cluster.kubeconfigPath,
        skipTlsVerify,
      }),
    ),
    deployKube: separateDeploy
      ? new KubeClient(
          createKubeConfig({
            apiUrl: cluster.deployApiUrl,
            token: cluster.deployToken,
            kubeconfigPath: cluster.kubeconfigPath,
            skipTlsVerify,
          }),
        )
      : undefined,
    metrics: config.postgres.enabled
      ? new MetricsRepository(createPgPool(config.postgres, logger), config.postgres.table, logger)
      : new NoopMetricsStore(),
    registry: new DevfileRegistryClient(createRegistryHttp(config.devreg.url)),
    notifier: config.notification.url
      ? new EmailNotifier(config.notification, config.cluster.deployApiUrl, directory, logger)
      : new NoopNotifier(),
  };
}

export interface BuildWorkspaceArgs {

  stack: string;

  devfile: Devfile;
  editor: EditorKey;
  /** Full editor id as the Dev Spaces dashboard knows it, e.g. `che-incubator/che-code/latest`. */
  editorId: string;

  repositoryBranch?: string;

const EDITOR_DISPLAY: Record<EditorKey, string> = {
  vscode: 'Visual Studio Code',
  intellij: 'IntelliJ IDEA',
  goland: 'GoLand',
};

function repoName(url: string): string {
  const last = url
    .replace(/\.git$/, '')
    .split('/')
    .filter(Boolean)
    .pop();
  return (last ?? 'project').toLowerCase().replace(/[^a-z0-9-]/g, '-');
}

export function buildDevWorkspaceObject(a: BuildWorkspaceArgs): DevWorkspaceResource {
  const projects = [...((a.devfile.projects as unknown[] | undefined) ?? [])];
  if (a.repositoryUrl) {
    projects.push({
      name: repoName(a.repositoryUrl),
      git: {
        remotes: { origin: a.repositoryUrl },
        ...(a.repositoryBranch ? { checkoutFrom: { revision: a.repositoryBranch } } : {}),
      },
    });
  }

  const template: NonNullable<NonNullable<DevWorkspaceResource['spec']>['template']> = {
    attributes: {
      'controller.devfile.io/devworkspace-config': {
        name: 'devworkspace-config',
        namespace: 'openshift-devspaces',
      },
      'controller.devfile.io/scc': 'container-build',
      'controller.devfile.io/storage-type': 'per-workspace',
    },
    components: a.devfile.components ?? [],
  };
  if (projects.length > 0) template.projects = projects;
  if (Array.isArray(a.devfile.commands)) template.commands = a.devfile.commands;
  if (a.devfile.events) template.events = a.devfile.events;

  return {
    apiVersion: 'workspace.devfile.io/v1alpha2',
    kind: 'DevWorkspace',
    metadata: {
      name: a.name,
      namespace: a.namespace,
      annotations: {
        dw: a.name,
        workspaceVersion: a.stackVersion,
        workspaceDisplayName: a.devfile.metadata?.displayName ?? a.devfile.metadata?.name ?? a.stack,
        workspaceDescription: a.devfile.metadata?.description ?? '',
        editorDisplayName: EDITOR_DISPLAY[a.editor],
      },
      labels: {
        [WORKSPACE_LABELS.csiid]: a.csiid,
        [WORKSPACE_LABELS.stack]: a.stack,
        [WORKSPACE_LABELS.managedBy]: 'workspace-mgr',

    },
    spec: {
      started: true,
      routingClass: 'che',

          name: 'ide',
          uri: `${a.devSpacesServiceFqdn}/dashboard/api/editors/devfile?che-editor=${a.editorId}`,

import { randomUUID } from 'node:crypto';
import express, { Router, type Express, type Request, type RequestHandler, type Response } from 'express';
import type { Container } from '../container.js';
import { parseCsiid, parseTokenName } from '../utils/names.js';
import { UnauthorizedError } from '../utils/errors.js';
import { authenticate, authorizeSoeid, checkAdminCredentials, getSoeid, signToken } from './auth.js';
import { asyncHandler, createErrorHandler, errorBody, notFoundHandler } from './errors.js';
import {
  createWorkspaceSchema,
  csiidBodySchema,
  csiidQuerySchema,
  gitConfigBodySchema,
  loginSchema,
  parse,
  patBodySchema,
} from './schemas.js';

export const API_PREFIX = '/api/v1';

const param = (req: Request, name: string): string => req.params[name] ?? '';

/** RFC 8594-style signalling that an unversioned path is going away. */
const deprecatedAlias: RequestHandler = (req, res, next) => {
  res.setHeader('Deprecation', 'true');
  res.setHeader('Link', `<${API_PREFIX}${req.path}>; rel="successor-version"`);
  next();
};

export function createApp(c: Container): Express {
  const app = express();
  app.disable('x-powered-by');
  app.use(express.json({ limit: '256kb' }));

  app.use((req, res, next) => {
    const incoming = req.header('x-request-id');
    const requestId = incoming && /^[A-Za-z0-9-]{8,64}$/.test(incoming) ? incoming : randomUUID();
    res.locals.requestId = requestId;
    res.setHeader('x-request-id', requestId);
    const started = Date.now();
    res.on('finish', () =>
      c.logger.info('request', {
        requestId,
        method: req.method,
        path: req.path,
        status: res.statusCode,
        ms: Date.now() - started,
        soeid: res.locals.soeid as string | undefined,
      }),
    );
    next();
  });

  // ---- operations ---------------------------------------------------------------------------
  app.get('/healthz', (_req, res) => {
    res.send('OK');
  });

  app.get(
    '/readyz',
    asyncHandler(async (_req, res) => {
      const checks: Record<string, string> = {};
      await Promise.all([
        c.kube.ping().then(
          () => (checks.kubernetes = 'ok'),
          () => (checks.kubernetes = 'unavailable'),
        ),
        c.metrics.ping().then(
          () => (checks.postgres = 'ok'),
          () => (checks.postgres = 'unavailable'),
        ),
        // only when build/deploy projects live on a different cluster
        ...(c.deployKube !== c.kube
          ? [
              c.deployKube.ping().then(
                () => (checks.deployCluster = 'ok'),
                () => (checks.deployCluster = 'unavailable'),
              ),
            ]
          : []),
      ]);
      const ready = Object.values(checks).every((v) => v === 'ok');
      res.status(ready ? 200 : 503).json({ status: ready ? 'ready' : 'not-ready', checks });
    }),
  );

  // ---- versioned API (mounted at /api/v1, and optionally at / as a deprecated alias) --------
  const api = Router();

  api.post('/login', (req, res, next) => {
    try {
      const { username, password } = parse(loginSchema, req.body);
      if (!checkAdminCredentials(c.config.auth, username, password)) {
        throw new UnauthorizedError('Username or password is incorrect');
      }
      res.json({ token: signToken(c.config.auth, { soeid: username, role: 'admin' }) });
    } catch (error) {
      next(error);
    }
  });

  const auth = authenticate(c.config.auth);

  api.get(
    '/catalog',
    auth,
    asyncHandler(async (_req, res) => {
      res.json(await c.registry.getCatalog());
    }),
  );

  // ---- per-user routes ----------------------------------------------------------------------
  const user = Router({ mergeParams: true });

  user.get(
    '/projects',
    asyncHandler(async (_req, res) => {
      res.json(await c.namespaces.listProjects(getSoeid(res)));
    }),
  );

  user.get(
    '/workspaces',
    asyncHandler(async (_req, res) => {
      res.json(await c.workspaces.list(getSoeid(res)));
    }),
  );

  user.get(
    '/workspaces/:id',
    asyncHandler(async (req, res) => {
      res.json(await c.workspaces.get(getSoeid(res), param(req, 'id')));
    }),
  );

  user.post(
    '/workspaces',
    asyncHandler(async (req, res) => {
      const body = parse(createWorkspaceSchema, req.body);
      const workspace = await c.workspaces.create({
        soeid: getSoeid(res),
        csiid: parseCsiid(body.csiid),
        devworkspaceValue: body.devworkspaceValue,
        editor: body.editor,
        stackVersion: body.stackVersion,
        repositoryUrl: body.repositoryUrl,
        repositoryBranch: body.repositoryBranch,
      });
      res.status(200).json(workspace);
    }),
  );

  user.delete(
    '/workspaces/:id',
    asyncHandler(async (req, res) => {
      const id = param(req, 'id');
      await c.workspaces.delete(getSoeid(res), id);
      res.json({ message: `Workspace with id ${id} is terminating.` });
    }),
  );

  user.post(
    '/workspaces/:id/start',
    asyncHandler(async (req, res) => {
      const id = param(req, 'id');
      await c.workspaces.start(getSoeid(res), id);
      res.json({ message: `Workspace with id ${id} is starting.` });
    }),
  );

  user.post(
    '/workspaces/:id/stop',
    asyncHandler(async (req, res) => {
      const id = param(req, 'id');
      await c.workspaces.stop(getSoeid(res), id);
      res.json({ message: `Workspace with id ${id} is stopping.` });
    }),
  );

  // Personal access tokens
  user.get(
    '/pats',
    asyncHandler(async (_req, res) => {
      res.json(await c.pats.list(getSoeid(res)));
    }),
  );
  user.get(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      res.json(await c.pats.view(getSoeid(res), parseCsiid(csiid), parseTokenName(param(req, 'tokenName'))));
    }),
  );
  user.post(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const body = parse(patBodySchema, req.body);
      const created = await c.pats.create(
        getSoeid(res),
        parseCsiid(body.csiid),
        parseTokenName(param(req, 'tokenName')),
        body.token,
      );
      res.status(201).json(created);
    }),
  );
  user.put(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const body = parse(patBodySchema, req.body);
      res.json(
        await c.pats.update(
          getSoeid(res),
          parseCsiid(body.csiid),
          parseTokenName(param(req, 'tokenName')),
          body.token,
        ),
      );
    }),
  );
  user.delete(
    '/pats/:tokenName',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      const tokenName = parseTokenName(param(req, 'tokenName'));
      const removed = await c.pats.delete(getSoeid(res), parseCsiid(csiid), tokenName);
      res.json({
        message: removed ? `PAT '${tokenName}' deleted.` : `PAT '${tokenName}' not found; nothing to delete.`,
      });
    }),
  );

  // Git config
  user.get(
    '/gitconfig',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      res.json(await c.gitConfig.view(getSoeid(res), parseCsiid(csiid)));
    }),
  );
  user.put(
    '/gitconfig',
    asyncHandler(async (req, res) => {
      const body = parse(gitConfigBodySchema, req.body);
      res.json(await c.gitConfig.upsert(getSoeid(res), parseCsiid(body.csiid), body.content));
    }),
  );
  user.delete(
    '/gitconfig',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidQuerySchema, req.query);
      const removed = await c.gitConfig.delete(getSoeid(res), parseCsiid(csiid));
      res.json({ message: removed ? 'Git config deleted.' : 'Git config not found; nothing to delete.' });
    }),
  );

  // Deployment (build/deploy) projects
  user.get(
    '/deployment-projects',
    asyncHandler(async (_req, res) => {
      res.json(await c.deployments.list(getSoeid(res)));
    }),
  );
  user.post(
    '/deployment-projects',
    asyncHandler(async (req, res) => {
      const { csiid } = parse(csiidBodySchema, req.body);
      const result = await c.deployments.ensure(getSoeid(res), parseCsiid(csiid));
      res.status(result.exists ? 200 : 201).json(result);
    }),
  );
  user.delete(
    '/deployment-projects',
    asyncHandler(async (_req: Request, res: Response) => {
      res.json(await c.deployments.delete(getSoeid(res)));
    }),
  );

  api.use('/:soeid', auth, authorizeSoeid(), user);

  app.use(API_PREFIX, api);
  if (c.config.legacyRoutes) {
    // Pre-versioning paths kept so existing Orion builds keep working while they migrate to /api/v1.
    const legacy = Router();
    // Unknown /api/... paths (e.g. a future /api/v2) must 404, not be read as `/:soeid` = "api".
    legacy.use((req, _res, next) =>
      req.path === '/api' || req.path.startsWith('/api/') ? next('router') : next(),
    );
    legacy.use(deprecatedAlias, api);
    app.use('/', legacy);
  }

  app.use(notFoundHandler);
  app.use(createErrorHandler(c.logger));
  return app;
}

  }
  const container = buildContainer(config, logger, createProductionDependencies(config, logger));
  const server: Server = createApp(container).listen(config.port, () =>
    logger.info('server.listening', startupSummary(config)),
  );

  let shuttingDown = false;
  const shutdown = (signal: string): void => {
    if (shuttingDown) return;
    shuttingDown = true;
    logger.info('server.shutdown', { signal });
    server.close(() => {
      container.metrics.close().finally(() => process.exit(0));
    });
    setTimeout(() => process.exit(1), 10_000).unref();
  };
  process.on('SIGTERM', () => shutdown('SIGTERM'));
  process.on('SIGINT', () => shutdown('SIGINT'));
}

main().catch((error: unknown) => {
  process.stderr.write(`Fatal: ${errorMessage(error)}\n`);
  process.exit(1);
});

import {
  CoreV1Api,
  KubeConfig,
  KubernetesObjectApi,
  PatchStrategy,
  type KubernetesObject,
} from '@kubernetes/client-node';
import type { DevWorkspaceResource, KubeObject } from '../../domain/types.js';
import { isK8sStatus, toAppError } from '../../utils/k8s-errors.js';
import type { KubeGateway, NamespacedKind } from '../ports.js';

const API_VERSION: Record<NamespacedKind, string> = {
  Secret: 'v1',
  ConfigMap: 'v1',
  ResourceQuota: 'v1',
  LimitRange: 'v1',
  Role: 'rbac.authorization.k8s.io/v1',
  RoleBinding: 'rbac.authorization.k8s.io/v1',
  NetworkPolicy: 'networking.k8s.io/v1',
  DevWorkspace: 'workspace.devfile.io/v1alpha2',
  DevWorkspaceTemplate: 'workspace.devfile.io/v1alpha2',
};

const asK8s = (o: unknown): KubernetesObject => o as KubernetesObject;
const asKube = <T>(o: unknown): T => o as T;

export function loadKubeConfig(kubeconfigPath?: string): KubeConfig {
  const kc = new KubeConfig();
  if (kubeconfigPath) kc.loadFromFile(kubeconfigPath);
  else kc.loadFromDefault();
  return kc;
}

export interface ClusterConnection {
  apiUrl: string;
  /** Bearer token (e.g. from devSpacesClusterToken001d). Wins over a kubeconfig. */
  token?: string;
  kubeconfigPath?: string;
  /** Do not verify the cluster's certificate (NODE_TLS_REJECT_UNAUTHORIZED=0). */
  skipTlsVerify?: boolean;
}

/** Token + API URL when a token is given, else the kubeconfig file, else the pod's service account / default config. */
export function createKubeConfig(connection: ClusterConnection): KubeConfig {
  if (!connection.token || !connection.apiUrl) return loadKubeConfig(connection.kubeconfigPath);
  const kc = new KubeConfig();
  kc.loadFromOptions({
    clusters: [
      { name: 'cluster', server: connection.apiUrl, skipTLSVerify: connection.skipTlsVerify === true },
    ],
    users: [{ name: 'service-account', token: connection.token }],
    contexts: [{ name: 'default', cluster: 'cluster', user: 'service-account' }],
    currentContext: 'default',
  });
  return kc;
}

/** Kubernetes/OpenShift access through the pod's service account (or a kubeconfig for local runs). */
export class KubeClient implements KubeGateway {
  private readonly core: CoreV1Api;
  private readonly objects: KubernetesObjectApi;

  constructor(kubeConfig: KubeConfig) {
    this.core = kubeConfig.makeApiClient(CoreV1Api);
    this.objects = KubernetesObjectApi.makeApiClient(kubeConfig);
  }

  private async call<T>(context: string, fn: () => Promise<T>): Promise<T> {
    try {
      return await fn();
    } catch (error) {
      throw toAppError(context, error);
    }
  }

  private async orNull<T>(context: string, fn: () => Promise<T>): Promise<T | null> {
    try {
      return await fn();
    } catch (error) {
      if (isK8sStatus(error, 404)) return null;
      throw toAppError(context, error);
    }
  }

  private header(kind: NamespacedKind, namespace: string, name: string) {
    return { apiVersion: API_VERSION[kind], kind, metadata: { name, namespace } };
  }

  private body<T extends KubeObject>(kind: NamespacedKind, namespace: string, body: T): KubernetesObject {
    return asK8s({
      ...body,
      apiVersion: API_VERSION[kind],
      kind,
      metadata: { ...body.metadata, namespace },
    });
  }

  async listNamespaces(labelSelector?: string): Promise<KubeObject[]> {
    const res = await this.call('List namespaces', () => this.core.listNamespace({ labelSelector }));
    return asKube<KubeObject[]>(res.items);
  }

  getNamespace(name: string): Promise<KubeObject | null> {
    return this.orNull(`Read namespace '${name}'`, async () =>
      asKube<KubeObject>(await this.core.readNamespace({ name })),
    );
  }

  async createNamespace(body: KubeObject): Promise<KubeObject> {
    const created = await this.call(`Create namespace '${body.metadata?.name}'`, () =>
      this.core.createNamespace({ body: asKube(body) }),
    );
    return asKube<KubeObject>(created);
  }

  async deleteNamespace(name: string): Promise<boolean> {
    const result = await this.orNull(`Delete namespace '${name}'`, () => this.core.deleteNamespace({ name }));
    return result !== null;
  }

  async createProject(body: KubeObject): Promise<KubeObject> {
    const name = body.metadata?.name ?? '';
    const request = asK8s({ ...body, apiVersion: 'project.openshift.io/v1', kind: 'ProjectRequest' });
    const created = await this.call(`Create project '${name}'`, () => this.objects.create(request));
    const result = asKube<KubeObject>(created);
    return result.metadata?.name ? result : { ...result, metadata: { ...result.metadata, name } };
  }

  get<T extends KubeObject>(kind: NamespacedKind, namespace: string, name: string): Promise<T | null> {
    return this.orNull(`Read ${kind} '${name}'`, async () =>
      asKube<T>(await this.objects.read(this.header(kind, namespace, name))),
    );
  }

  async list<T extends KubeObject>(
    kind: NamespacedKind,
    namespace: string,
    labelSelector?: string,
  ): Promise<T[]> {
    const res = await this.call(`List ${kind} in '${namespace}'`, () =>
      this.objects.list(
        API_VERSION[kind],
        kind,
        namespace,
        undefined,
        undefined,
        undefined,
        undefined,
        labelSelector,
      ),
    );
    return asKube<T[]>(res.items);
  }

  async create<T extends KubeObject>(kind: NamespacedKind, namespace: string, body: T): Promise<T> {
    const created = await this.call(`Create ${kind} '${body.metadata?.name}'`, () =>
      this.objects.create(this.body(kind, namespace, body)),
    );
    return asKube<T>(created);
  }

  async apply<T extends KubeObject>(kind: NamespacedKind, namespace: string, body: T): Promise<T> {
    const name = body.metadata?.name ?? '';
    const context = `Apply ${kind} '${name}'`;
    const replaceExisting = async (): Promise<T | null> => {
      const existing = await this.get<T>(kind, namespace, name);
      if (!existing) return null;
      const spec = this.body(kind, namespace, {
        ...body,
        metadata: { ...body.metadata, resourceVersion: existing.metadata?.resourceVersion },
      });
      return asKube<T>(await this.call(context, () => this.objects.replace(spec)));
    };

    const replaced = await replaceExisting();
    if (replaced) return replaced;
    try {
      return asKube<T>(await this.objects.create(this.body(kind, namespace, body)));
    } catch (error) {
      if (isK8sStatus(error, 409)) {
        // Lost a creation race with another request; replace what the winner created.
        const retried = await replaceExisting();
        if (retried) return retried;
      }
      throw toAppError(context, error);
    }
  }

  async delete(kind: NamespacedKind, namespace: string, name: string): Promise<boolean> {
    const result = await this.orNull(`Delete ${kind} '${name}'`, () =>
      this.objects.delete(asK8s(this.header(kind, namespace, name))),
    );
    return result !== null;
  }

  async setWorkspaceStarted(
    namespace: string,
    name: string,
    started: boolean,
  ): Promise<DevWorkspaceResource> {
    const patch = asK8s({ ...this.header('DevWorkspace', namespace, name), spec: { started } });
    const patched = await this.call(`${started ? 'Start' : 'Stop'} DevWorkspace '${name}'`, () =>
      this.objects.patch(patch, undefined, undefined, undefined, undefined, PatchStrategy.MergePatch),
    );
    return asKube<DevWorkspaceResource>(patched);
  }

  async ping(): Promise<void> {
    await this.call('Kubernetes API ping', () => this.core.getAPIResources());
  }
}

import type { Express } from 'express';

export interface Integration {
  app: Express;
  container: Container;
  fakes: Fakes;
  registry: RegistryServer;
  token: string;
  /** Run SQL against the in-memory metrics database. */
  sql: (query: string) => Promise<Record<string, unknown>[]>;

  close(): Promise<void>;

/**
 * Real routes, services, SQL (pg-mem) and HTTP devfile registry; only the cluster is in memory.
 */
export async function startIntegration(
  env: Record<string, string> = {},
  options: { deployKube?: InMemoryKube } = {},
): Promise<Integration> {
