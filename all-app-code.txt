# Workspace Mgr

Middleware between the **Orion** dashboard and **Red Hat OpenShift Dev Spaces**. On demand of a user it
creates, lists, starts, stops and deletes DevWorkspaces, creates the user's project (namespace) when it does not
exist, manages per-user Git credentials, and records every action to Postgres for the Dev Spaces dashboard.

Node 20+, TypeScript (strict, ESM), Express 4, `@kubernetes/client-node`, `pg`, `zod`.
Project rules: [docs/PROJECT_RULES.md](docs/PROJECT_RULES.md) · Checklist: [docs/CHECKLIST.md](docs/CHECKLIST.md)

## Postgres: the existing database

Metrics go into the **existing** Orion database. workspace-mgr creates nothing (no tables, schemas or migrations);
it only inserts rows into the table named by `POSTGRES_DATABASE_TABLENAME`.

Same variables as the original service:

```bash
export POSTGRES_DATABASE=orion_dev_metadata
export POSTGRES_HOSTNAME=NAORI01DPS_INSTANCE1.pgaas.dyn.nsroot.net
export POSTGRES_PASSWORD=...
export POSTGRES_PORT='1524'
export POSTGRES_USER=app_orion_pgsql_dev
export POSTGRES_DATABASE_TABLENAME='metrics."devspaces-metrics-dev"'
export NODE_ENV=development
```

- **TLS** is always on and the server certificate is verified, as before. `NODE_ENV` picks the CA file:
  `development` → `./certs/dev.pem` (hostname check relaxed), `uat` → `/app/backend/cert/uat.pem`,
  `production` → `/app/backend/cert/prod.pem`. Override with `POSTGRES_CERT_DIR` or `POSTGRES_CA_FILE`.
  The app refuses to start, naming the missing file, if the CA cannot be read.
- **Columns:** the service reads the table's column list once and writes only the columns that exist (it knows
  `timestamp, csiid, soeid, eventtype, resourcename, resourcetype, status, limitcpu, limitmemory, requestcpu,
requestmemory, duration, storage, useraction, errordetail, workspaceversion, editorname`). A table without
  `workspaceversion` / `editorname` still works; a warning names what is not stored.
- **Timestamps** are written as UTC wall-clock text, as the original did.
- A database problem never blocks a workspace action: it is logged and the action continues.

## Hand-over to another computer (`recreate-app.sh`, `all-app-code.txt`)

The app moves between computers as **one text file**, `all-app-code.txt`, and one script, `recreate-app.sh`.
Build the text file with `tools/build-all-code.sh`; on the destination computer, run:

```bash
bash recreate-app.sh -f             # inside the app folder: writes the files of ./all-app-code.txt, overwriting
bash recreate-app.sh -f --prune     # also delete files that were removed from the app
bash recreate-app.sh -n             # dry run: show what would happen
bash recreate-app.sh p.txt ./out    # another input file / another folder (existing files are kept without -f)
```

- **First hand-over:** the entire application. **Every later one:** only the new and changed files, plus a list of
  files that were removed (`/_REMOVED.txt`). It ends with what to run next (`npm install`, `npm run build`, ...) when
  something relevant changed.
- **New empty folder:** put `recreate-app.sh` and `all-app-code.txt` in it and run `bash recreate-app.sh -f`, then
  `npm ci && npm test && npm run build && npm start`.
- **Format:** `/path/to/file`, the file's content, a blank line, next file. Files that cannot be shown as exact plain
  text (CRLF line endings, no final newline, odd names) are stored as base64 after `@@BINARY-SECTION`; the plain files
  are LF, so an editor, e-mail or git changing line endings cannot damage anything.
- **Safe:** the text file ends with a SHA-256 for every file; they are all checked in a temp folder before your files are
  touched. Existing files that differ are kept unless you pass `-f`. Paths that could escape the folder are rejected.
  `recreate-app.sh` never replaces itself while running; a newer version is saved as `recreate-app.sh.new`.
- **Never in a hand-over:** `node_modules`, `dist`, `coverage`, `.git`, `tools`, `.env*` (secrets), private keys.
- **For the maintainer:** `bash tools/build-all-code.sh` builds the next hand-over (entire app the first time, then
  only changes; `--full`, `--list`, `--redo` and `--keep-state` exist). What the other computer has is remembered in
  `.handover-state` (not committed). Before saving, the file is recreated in a temp folder and compared byte for byte.

## Creating a workspace

`POST /api/v1/:soeid/workspaces` accepts the existing dashboard payload:

```json
{
  "devworkspaceValue": "citi-optimus",
  "csiid": "177398",
  "editorType": "che-code",
  "stackVersion": "8.1.1",
  "repositoryUrl": "https://github.com/acme/project.git",
  "repositoryCheckoutBranch": "optimus"
}
```

The first four fields are required. `editorType` accepts `che-code`, `che-idea`, or
`che-goland`. The previously documented `editor` and `repositoryBranch` names also
remain accepted; conflicting aliases are rejected. Invalid nonempty values produce
400 with a `details` array naming the offending fields.

Repository URL and checkout branch are optional. Omitted, empty or null values do
not prevent workspace creation. Without a URL, no request-supplied project is added
and Git setup is skipped. Stack-provided projects remain intact. With a URL, the
request-supplied project is named `default-project`, cloned by Dev Spaces under
`/projects/default-project`. Branch selection happens in a post-start command so
an unavailable branch does not fail that command. It tries the requested branch,
then its remote tracking branch, then creates a local branch if no remote exists.
With no branch supplied, it tries `main`, then `master`, retaining the current
checkout if neither is available. Git failures are logged and the setup script
returns success. Actual project cloning still depends on Dev Spaces and repository
access; the API response confirms resource creation, not completed cloning.

The post-start setup runs in the stack's `tools` container, or its first container
when `tools` is absent. Existing commands and lifecycle events are preserved. For
`citi-optimus`, it also makes `/home/user/mta-analyzer-rpc-linux-amd64/mta-analyzer-rpc`
executable and updates `mta-core.analyzerPath` in
`/checode/remote/data/Machine/settings.json` using `jq`. Missing files, missing `jq`,
or configuration errors are logged without stopping setup. Other stacks skip MTA
configuration. Request values are safely passed as environment variables to the
workspace command; the API server needs no repository environment variables.

Inspect `/tmp/workspace-setup-debug.log` inside the workspace for Git and MTA setup
details. These operations execute in the workspace pod, so their runtime output is
separate from the API server's logs.

Failed API requests have a `request.failed` log containing the error's source and
message. Their `request` summary uses that same source, rather than the response
listener in `app.ts`. Successful request summaries identify the access-log function.

## Repairing or updating Kubernetes resources

Restore existing defaults on a user's workspace project:

```http
PUT /api/v1/support/resources
Authorization: Bearer <admin-jwt>
Content-Type: application/json

{ "soeid": "pp58386", "csiid": "177398", "target": "workspace" }
```

Use `"target": "deployment"` for the deployment cluster/project. The project must
exist and its owner annotation must match the requested SOEID. Omitting `resources`
reapplies the existing provisioning defaults, including network/proxy resources for
workspace projects. This repairs missing resources without recreating a project.

To create or replace selected resources, supply their manifests:

```json
{
  "soeid": "pp58386",
  "csiid": "177398",
  "target": "workspace",
  "resources": [
    {
      "kind": "ResourceQuota",
      "metadata": { "name": "custom-compute-quota" },
      "spec": { "hard": { "requests.cpu": "4", "requests.memory": "8Gi" } }
    }
  ]
}
```

Allowed kinds: `Role`, `RoleBinding`, `ResourceQuota`, `LimitRange`, `ClusterRole`,
`ClusterRoleBinding`. `metadata` accepts only `name`: the server sets namespace and
API version. Cluster roles/bindings are cluster-scoped and apply to the selected
workspace or deployment cluster. Kubernetes has no cluster-scoped LimitRange or
ResourceQuota; those apply to the selected user's namespace on that cluster.
Kubernetes validates manifest rules, subjects, role references and specs.

Operations run sequentially. If one fails, earlier successful updates remain;
correct the error and retry. Existing Kubernetes permissions still apply. The
service account needs explicit cluster-RBAC write privileges for cluster-scoped
operations; this change does not automatically expand deployment privileges.

## Runtime settings

`GET /api/v1/configuration` returns settings with passwords and tokens redacted.
`PATCH /api/v1/configuration` accepts any nonempty subset of:

```json
{
  "DEVREG_URL": "https://registry.example.com",
  "NOTIFICATION_MAIL_URL": "https://mail.example.com",
  "NOTIFICATION_EMAIL_USERNAME": "workspace-mailer",
  "NOTIFICATION_EMAIL_PASSWORD": "replacement-password",
  "MAX_RUNNING_WORKSPACES": 3,
  "MAX_TOTAL_WORKSPACES": 5,
  "CLUSTER_API_URL": "https://api.cluster.example.com:6443",
  "CLUSTER_TOKEN": "replacement-token",
  "DEPLOY_CLUSTER_API_URL": "https://api.deploy.example.com:6443",
  "DEPLOY_CLUSTER_TOKEN": "replacement-deployment-token"
}
```

Changes take effect for subsequent requests in this process. Production adapters
are rebuilt so updated URLs and credentials are used; the database pool remains
open. In-flight operations can finish using their original services. Updates are
validated before replacement. Running limits cannot exceed total limits; changing
a cluster URL requires its token in the same request.

**Persistence is process-lifetime:** this API does not rewrite deployment environment
variables, Kubernetes Secrets or `.env` files. Set the same values in deployment
configuration to retain them after restart and across replicas. Responses explicitly
report `"persistence": "process-lifetime"`. No arbitrary environment-variable writes
are supported. Stored secret values are never returned by this API.

## Troubleshooting with daily logs

Production writes one redacted JSON entry per line to `logs/app-YYYY-MM-DD.log`.
Each entry includes `timestamp` (`YYYY-MM-DD HH:MM:SS` in the process's local timezone),
`file`, and `function`. The ISO `time` field remains available for precise filtering.
Readable console and log-search output uses
`[timestamp] [filename:line] [functionName]`. Continuation lines carry the
same prefix. Source details come from the log call, or the original error stack when
an Error object is provided. Application callbacks have descriptive function names;
top-level execution without a named function is identified as `module`.
Client failures (400/401/403/404/409) are logged as warnings with status, error code,
message, request ID, and source location. Server failures are logged as errors.
JWT errors distinguish expired, not-yet-valid, invalid-signature, and malformed tokens.
Use the Workspace Manager token from `/api/v1/login` for these APIs; cluster tokens
authenticate the server's Kubernetes requests and are separate credentials.
Dates are UTC and files switch automatically at midnight. Console formatting is
independent. `LOG_DIRECTORY` selects the directory. Mount a writable volume there
when using a read-only filesystem, and persistent storage if logs must survive pod
replacement. Log files are not committed. Retention is managed by the deployment.

```http
GET /api/v1/logs?days=2&level=error&search=namespace&limit=100&format=text
Authorization: Bearer <admin-jwt>
```

Supported query parameters:

| Parameter   | Meaning                                           |
| ----------- | ------------------------------------------------- |
| `days`      | Rolling last 1–31 days; default 1                 |
| `limit`     | Maximum 1–1000 results; default 200               |
| `level`     | `debug`, `info`, `warn`, or `error`               |
| `search`    | Case-insensitive text match, up to 200 characters |
| `requestId` | Exact request correlation ID                      |
| `soeid`     | Exact user match                                  |
| `format`    | `json` (default) or readable `text`               |

Results are newest first and include the queried range and a `truncated` indicator.
Search scans at most 100,000 lines per request. Missing files and malformed lines are
ignored. Search uses literal text filtering. The API searches this
instance's files; aggregate logs externally when running multiple replicas.

import express, { type Express } from 'express';
import { randomUUID } from 'node:crypto';
import type { Container } from './container.js';
import baseRouter from './routers/index.js';
import { createErrorHandler, notFoundHandler } from './http/errors.js';

export const API_PREFIX = '/api/v1';

export function createApp(c: Container): Express {
  const app = express();
  app.disable('x-powered-by');

  app.use(function requestContext(req, res, next) {
    const incoming = req.header('x-request-id');
    const requestId = incoming && /^[A-Za-z0-9-]{8,64}$/.test(incoming) ? incoming : randomUUID();
    res.locals.requestId = requestId;
    res.setHeader('x-request-id', requestId);
    const started = Date.now();
    res.on('finish', function logRequest() {
      const failure = res.locals.failure as { error: Error; code: string } | undefined;
      // Match request severity to the HTTP status.
      const outcome = res.statusCode >= 500 ? 'error' : res.statusCode >= 400 ? 'warn' : 'success';
      c.logger[outcome]('request', {
        method: req.method,
        // Preserve the full path when logging requests handled by nested routers.
        path: req.originalUrl.split('?')[0],
        status: res.statusCode,
        ms: Date.now() - started,
        requestId,
        soeid: res.locals.soeid as string | undefined,
        ...(failure ?? {}),
      });
    });
    next();
  });
  app.use(express.json({ limit: '256kb' }));

  const api = baseRouter(c);
  app.use(API_PREFIX, api);

  app.use(notFoundHandler);
  app.use(createErrorHandler(c.logger));
  return app;
}

  /** Full editor id as the Dev Spaces dashboard knows it, e.g. `che-incubator/che-code/latest`. */

const EDITOR_DISPLAY: Record<EditorKey, string> = {

  intellij: 'IntelliJ IDEA',

export function buildDevWorkspaceObject(a: BuildWorkspaceArgs): DevWorkspaceResource {
  const projects = [...((a.devfile.projects as unknown[] | undefined) ?? [])];
  if (a.repositoryUrl) {
    const requestedProject = {
      name: 'default-project',
      git: {
        remotes: { origin: a.repositoryUrl },
      },
    };
    const existing = projects.findIndex(
      (project) => (project as { name?: string })?.name === 'default-project',
    );
    if (existing >= 0) projects[existing] = requestedProject;
    else projects.push(requestedProject);
  }

  const template: NonNullable<NonNullable<DevWorkspaceResource['spec']>['template']> = {
    attributes: {
      'controller.devfile.io/devworkspace-config': {
        name: 'devworkspace-config',
        namespace: 'openshift-devspaces',
      },
      'controller.devfile.io/scc': 'container-build',
      'controller.devfile.io/storage-type': 'per-workspace',
    },
    components: a.devfile.components ?? [],
  };
  if (projects.length > 0) template.projects = projects;
  if (Array.isArray(a.devfile.commands)) template.commands = a.devfile.commands;
  if (a.devfile.events) template.events = a.devfile.events;
  const tools = a.devfile.components?.find((component) => component.name === 'tools' && component.container);
  const container = tools ?? a.devfile.components?.find((component) => component.container);
  if (container) {
    const commands = [...(a.devfile.commands ?? [])];
    let setupId = 'workspace-manager-setup';
    while (commands.some((command) => (command as { id?: string })?.id === setupId)) setupId += '-post-start';
    commands.push({
      id: setupId,
      exec: {
        component: container.name,
        commandLine: buildWorkspaceSetupCommand({
          stack: a.stack,
          repositoryUrl: a.repositoryUrl,
          repositoryBranch: a.repositoryBranch,
        }),
        workingDir: '/projects',
      },
    });
    const events = (
      a.devfile.events && typeof a.devfile.events === 'object' ? a.devfile.events : {}
    ) as Record<string, unknown>;
    template.commands = commands;
    template.events = {
      ...events,
      postStart: [...(Array.isArray(events.postStart) ? events.postStart : []), setupId],
    };
  }

  return {
    apiVersion: 'workspace.devfile.io/v1alpha2',
    kind: 'DevWorkspace',
    metadata: {
      name: a.name,
      namespace: a.namespace,
      annotations: {
        dw: a.name,
        workspaceVersion: a.stackVersion,
        workspaceDisplayName: a.devfile.metadata?.displayName ?? a.devfile.metadata?.name ?? a.stack,
        workspaceDescription: a.devfile.metadata?.description ?? '',
        editorDisplayName: EDITOR_DISPLAY[a.editor],
      },
      labels: {
        [WORKSPACE_LABELS.csiid]: a.csiid,
        [WORKSPACE_LABELS.stack]: a.stack,
        [WORKSPACE_LABELS.managedBy]: 'workspace-mgr',
      },
    },
    spec: {
      started: true,
      routingClass: 'che',
      template,
      contributions: [
        {
          name: 'ide',
          uri: `${a.devSpacesServiceFqdn}/dashboard/api/editors/devfile?che-editor=${a.editorId}`,
        },
      ],
    },
  };
}

const shellQuote = (value: string): string => `'${value.replaceAll("'", "'\\''")}'`;

/** Runs inside the workspace container after the Dev Spaces project clone. */
export function workspaceSetupScript(): string {
  return [
    'set +e',
    'set +u',
    'REPO_DIR="${WORKSPACE_REPOSITORY_DIR:-/projects/default-project}"',
    'MTA_DIR="${WORKSPACE_MTA_DIR:-/home/user/mta-analyzer-rpc-linux-amd64}"',
    'SETTINGS_PATH="${WORKSPACE_SETTINGS_PATH:-/checode/remote/data/Machine/settings.json}"',
    'LOG_FILE="${WORKSPACE_SETUP_LOG:-/tmp/workspace-setup-debug.log}"',
    'exec >> "$LOG_FILE" 2>&1',
    'log_setup() { printf "[%s] [workspace-setup] [%s] %s\\n" "$(date +"%Y-%m-%d %H:%M:%S")" "$1" "$2"; }',
    'log_setup setup "Starting workspace post-start setup."',
    'if [ "$WORKSPACE_STACK" = "citi-optimus" ]; then',
    '  ANALYZER="$MTA_DIR/mta-analyzer-rpc"',
    '  if [ -f "$ANALYZER" ]; then',
    '    chmod +x "$ANALYZER" || log_setup configureAnalyzer "Could not set executable permission; continuing."',
    '  else log_setup configureAnalyzer "MTA analyzer binary not found; continuing."; fi',
    '  if [ -f "$SETTINGS_PATH" ] && command -v jq >/dev/null 2>&1; then',
    '    UPDATED=$(jq --arg analyzer_path "$ANALYZER" \'. + {"mta-core.analyzerPath": $analyzer_path}\' "$SETTINGS_PATH")',
    '    if [ "$?" -eq 0 ]; then',
    '      printf "%s\\n" "$UPDATED" > "$SETTINGS_PATH" || log_setup configureAnalyzer "Could not write settings; continuing."',
    '    else log_setup configureAnalyzer "Could not parse analyzer settings; continuing."; fi',
    '  else log_setup configureAnalyzer "Settings file or jq unavailable; skipping settings update."; fi',
    'fi',
    'if [ "$REPOSITORY_URL_PROVIDED" != "true" ]; then',
    '  log_setup checkoutRepository "No repositoryUrl supplied; skipping Git setup."',
    '  exit 0',
    'fi',
    'if ! cd "$REPO_DIR" || ! git rev-parse --git-dir >/dev/null 2>&1; then',
    '  log_setup checkoutRepository "Cloned repository directory unavailable; skipping Git setup."',
    '  exit 0',
    'fi',
    'git fetch --all --prune || log_setup checkoutRepository "Git fetch failed; continuing with available local refs."',
    'git branch -a || true',
    'if [ -z "$TARGET_BRANCH" ]; then',
    '  git checkout main || git checkout master || log_setup checkoutRepository "Default branches unavailable; retaining the current branch."',
    'elif git checkout "$TARGET_BRANCH"; then',
    '  log_setup checkoutRepository "Requested branch checked out."',
    'elif git show-ref --verify --quiet "refs/remotes/origin/$TARGET_BRANCH"; then',
    '  git checkout -b "$TARGET_BRANCH" --track "origin/$TARGET_BRANCH" || git checkout --detach "origin/$TARGET_BRANCH" || log_setup checkoutRepository "Could not check out the remote branch; retaining the current branch."',
    'else',
    '  git checkout -b "$TARGET_BRANCH" || log_setup checkoutRepository "Could not create the requested local branch; retaining the current branch."',
    'fi',
    'git branch -a || true',
    'git status --short || true',
    'log_setup setup "Workspace setup completed."',
    'exit 0',
  ].join('\n');
}

export function buildWorkspaceSetupCommand(input: WorkspaceSetup): string {
  return `env WORKSPACE_STACK=${shellQuote(input.stack)} REPOSITORY_URL_PROVIDED=${shellQuote(input.repositoryUrl ? 'true' : 'false')} TARGET_BRANCH=${shellQuote(input.repositoryBranch ?? '')} bash -c ${shellQuote(workspaceSetupScript())}`;
}

import type { ErrorRequestHandler, NextFunction, Request, RequestHandler, Response } from 'express';
import { AppError, NotFoundError, ValidationError, errorMessage } from '../utils/errors.js';
import type { Logger } from '../utils/logger.js';

export interface ErrorBody {
  error: string;
  message: string;
  code: string;
}

export const errorBody = (message: string, code: string): ErrorBody => ({ error: message, message, code });

/** Express 4 does not catch rejected promises; this forwards them to the error handler. */
export const asyncHandler =
  (fn: (req: Request, res: Response) => Promise<void>): RequestHandler =>
  (req, res, next: NextFunction) => {
    fn(req, res).catch(next);
  };

export const notFoundHandler: RequestHandler = function routeNotFound(req, _res, next) {
  next(new NotFoundError(`Route not found: ${req.method} ${req.path}`, 'ROUTE_NOT_FOUND'));
};

export function createErrorHandler(logger: Logger): ErrorRequestHandler {
  return function handleRequestError(err: unknown, req, res, next) {
    if (res.headersSent) return next(err);
    const requestId = res.locals.requestId as string | undefined;

    if (err instanceof AppError) {
      res.locals.failure = { error: err, code: err.code };
      logger[err.status >= 500 ? 'error' : 'warn']('request.failed', {
        requestId,
        method: req.method,
        path: req.originalUrl?.split('?')[0] ?? req.path,
        status: err.status,
        code: err.code,
        error: err,
        ...(err instanceof ValidationError ? { details: err.details } : {}),
      });
      res.status(err.status).json({
        ...errorBody(err.message, err.code),
        ...(err instanceof ValidationError ? { details: err.details } : {}),
      });
      return;
    }
    // body-parser errors carry a status and a type
    const parserError = err as { status?: number; type?: string };
    if (parserError.type === 'entity.parse.failed') {
      res.locals.failure = { error: new Error('Request body is not valid JSON'), code: 'INVALID_JSON' };
      logger.warn('request.failed', {
        requestId,
        method: req.method,
        path: req.path,
        status: 400,
        code: 'INVALID_JSON',
        error: 'Request body is not valid JSON',
      });
      res.status(400).json(errorBody('Request body is not valid JSON', 'INVALID_JSON'));
      return;
    }
    if (parserError.type === 'entity.too.large') {
      res.locals.failure = { error: new Error('Request body is too large'), code: 'PAYLOAD_TOO_LARGE' };
      logger.warn('request.failed', {
        requestId,
        method: req.method,
        path: req.path,
        status: 413,
        code: 'PAYLOAD_TOO_LARGE',
        error: 'Request body is too large',
      });
      res.status(413).json(errorBody('Request body is too large', 'PAYLOAD_TOO_LARGE'));
      return;
    }
    // Never leak internals for unexpected errors.
    res.locals.failure = {
      error: err instanceof Error ? err : new Error(errorMessage(err)),
      code: 'INTERNAL_ERROR',
    };
    logger.error('request.crashed', {
      requestId,
      path: req.path,
      error: err instanceof Error ? err : errorMessage(err),
    });
    res.status(500).json(errorBody('Internal server error', 'INTERNAL_ERROR'));
  };
}

import { z } from 'zod';

const identifier = /^[A-Za-z0-9._-]+$/;

const csiid = z

export const loginSchema = z.strictObject({ username: z.string().min(1), password: z.string().min(1) });

const editorKeys: Record<string, EditorKey> = {
  'che-code': 'vscode',
  'che-idea': 'intellij',
  'che-goland': 'goland',
  vscode: 'vscode',
  intellij: 'intellij',
  goland: 'goland',

const editorType = z.enum(['che-code', 'che-idea', 'che-goland', 'vscode', 'intellij', 'goland']);
const optionalText = <T extends z.ZodType>(schema: T) =>
  z.preprocess(
    (value) => (value === null || (typeof value === 'string' && value.trim() === '') ? undefined : value),
    schema.optional(),
  );
const branch = z
  .string()
  .max(200)
  .regex(/^[A-Za-z0-9._/-]+$/, 'invalid branch name');

export const createWorkspaceSchema = z
  .strictObject({
    devworkspaceValue: z
      .string({ error: 'devworkspaceValue is required and must name a stack' })
      .min(1)
      .max(100)
      .regex(identifier, 'invalid stack name'),
    csiid,
    editorType: editorType.optional(),
    editor: z.enum(['vscode', 'intellij', 'goland']).optional(),
    stackVersion: z
      .string({ error: 'stackVersion is required and must be a string' })
      .min(1, 'stackVersion is required')
      .max(50)
      .regex(identifier, 'invalid stack version'),
    repositoryUrl: optionalText(z.url({ protocol: /^https$/ }).max(500)),
    repositoryCheckoutBranch: optionalText(branch),
    repositoryBranch: optionalText(branch),
  })
  .superRefine((body, context) => {
    if (!body.editorType && !body.editor)
      context.addIssue({
        code: 'custom',
        path: ['editorType'],
        message: 'editorType is required (che-code, che-idea, or che-goland)',
      });
    if (body.editorType && body.editor && editorKeys[body.editorType] !== body.editor)
      context.addIssue({
        code: 'custom',
        path: ['editorType'],
        message: 'editorType and editor must identify the same editor',
      });
    if (
      body.repositoryCheckoutBranch &&
      body.repositoryBranch &&
      body.repositoryCheckoutBranch !== body.repositoryBranch
    )
      context.addIssue({
        code: 'custom',
        path: ['repositoryCheckoutBranch'],
        message: 'Conflicting repository branch values',
      });
  })
  .transform(({ editorType, editor, repositoryCheckoutBranch, repositoryBranch, ...body }) => ({
    ...body,
    editor: editorKeys[editorType ?? editor ?? ''] as EditorKey,
    repositoryBranch: repositoryCheckoutBranch ?? repositoryBranch,
  }));

export const csiidQuerySchema = z.object({ csiid });
export const csiidBodySchema = z.strictObject({ csiid });
export const patBodySchema = z.strictObject({ csiid, token: z.string().min(1).max(200) });
export const gitConfigBodySchema = z.strictObject({ csiid, content: z.string().min(1) });

export function parse<T extends z.ZodType>(schema: T, data: unknown): z.output<T> {
  const result = schema.safeParse(data ?? {});
  if (!result.success) {
    const message = result.error.issues.map((i) => `${i.path.join('.') || 'body'}: ${i.message}`).join('; ');
    throw new ValidationError(
      message,
      result.error.issues.map((issue) => ({
        field: issue.path.join('.') || 'body',
        message: issue.message,
      })),
    );
  }
  return result.data;
}

import type { AppConfig } from '../config/env.js';
import type { CreateWorkspaceInput, DevWorkspaceResource, EditorKey, Workspace } from '../types.js';
import { applyEditorProfile, parseDevfile } from '../factories/devfile-updater.js';
import { buildDevWorkspaceObject, WORKSPACE_LABELS } from '../factories/workspace-factory.js';
import { systemClock, type Clock, type DevfileRegistry, type KubeGateway } from '../infra/ports.js';
import {
  NotFoundError,
  WorkspaceCountExceededError,
  WorkspaceRunCountExceededError,
} from '../utils/errors.js';
import { silentLogger, type Logger } from '../utils/logger.js';
import { cleanWorkspaceName, csiidFromWorkspaceNamespace } from '../utils/names.js';
import { summarizeComponents } from '../utils/resources.js';
import { durationSince } from '../utils/timestamp.js';
import type { MetricsRecorder } from './MetricsRecorder.js';
import type { NamespaceService } from './NamespaceService.js';

export interface WorkspaceServiceOptions {
  limits: AppConfig['limits'];
  editors: AppConfig['devreg']['editors'];
  devSpacesServiceFqdn: string;
}

const ACTIVE_PHASES = new Set(['Running', 'Starting', 'Stopping']);

/** Running, starting, stopping — or not yet reporting a phase — all still hold cluster resources. */
export const isActive = (dw: DevWorkspaceResource): boolean =>
  !dw.status?.phase || ACTIVE_PHASES.has(dw.status.phase);

export function toWorkspace(dw: DevWorkspaceResource): Workspace {
  const meta = dw.metadata ?? {};
  const annotations = meta.annotations ?? {};
  const namespace = meta.namespace ?? '';
  const resources = summarizeComponents(dw.spec?.template?.components);
  return {
    id: meta.name ?? '',
    name: meta.name ?? '',
    displayName: annotations.workspaceDisplayName ?? meta.name ?? '',
    description: annotations.workspaceDescription ?? '',
    namespace,
    csiid: meta.labels?.[WORKSPACE_LABELS.csiid] ?? csiidFromWorkspaceNamespace(namespace) ?? '',
    phase: dw.status?.phase ?? 'Starting',
    mainUrl: dw.status?.mainUrl ?? '',
    editor: annotations.editorDisplayName ?? '',
    version: annotations.workspaceVersion ?? '',
    stack: meta.labels?.[WORKSPACE_LABELS.stack] ?? '',
    created: meta.creationTimestamp ? new Date(meta.creationTimestamp).toISOString() : '',
    limitcpu: resources.limitcpu,
    limitmemory: resources.limitmemory,
    storage: resources.storage,
  };
}

/** When the workspace last became ready; falls back to creation time. */
function runningSince(dw: DevWorkspaceResource): Date | string | undefined {
  const ready = dw.status?.conditions?.find(
    (c) => (c.type === 'Started' || c.type === 'Ready') && c.status === 'True',
  );
  return ready?.lastTransitionTime ?? dw.metadata?.creationTimestamp;
}

export class WorkspaceService {
  constructor(
    private readonly kube: KubeGateway,
    private readonly namespaces: NamespaceService,
    private readonly registry: DevfileRegistry,
    private readonly recorder: MetricsRecorder,
    private readonly options: WorkspaceServiceOptions,
    private readonly clock: Clock = systemClock,
    private readonly logger: Logger = silentLogger,
  ) {}

  private async listResources(soeid: string): Promise<DevWorkspaceResource[]> {
    const namespaces = await this.namespaces.listForUser(soeid);
    const lists = await Promise.all(
      namespaces.map((ns) => this.kube.list<DevWorkspaceResource>('DevWorkspace', ns.metadata?.name ?? '')),
    );
    return lists.flat();
  }

  async list(soeid: string): Promise<Workspace[]> {
    return (await this.listResources(soeid)).map(toWorkspace);
  }

  private async find(soeid: string, id: string): Promise<DevWorkspaceResource> {
    const found = (await this.listResources(soeid)).find((dw) => dw.metadata?.name === id);
    if (!found) throw new NotFoundError(`Workspace '${id}' not found`, 'WORKSPACE_NOT_FOUND');
    return found;
  }

  async get(soeid: string, id: string): Promise<Workspace> {
    return toWorkspace(await this.find(soeid, id));
  }

  private assertCanRunAnother(all: DevWorkspaceResource[]): void {
    const active = all.filter(isActive).length;
    if (active >= this.options.limits.maxRunning) {
      throw new WorkspaceRunCountExceededError(
        `You already have ${active} running workspace(s); the limit is ${this.options.limits.maxRunning}. Stop one first.`,
      );
    }
  }

  private assertCanCreateAnother(all: DevWorkspaceResource[]): void {
    if (all.length >= this.options.limits.maxTotal) {
      throw new WorkspaceCountExceededError(
        `You already have ${all.length} workspace(s); the limit is ${this.options.limits.maxTotal}. Delete one first.`,
      );
    }
    this.assertCanRunAnother(all);
  }

  async create(input: CreateWorkspaceInput): Promise<Workspace> {
    const { soeid, csiid } = input;
    if (!input.repositoryUrl)
      this.logger.info('workspace.repository_skipped', {
        soeid,
        csiid,
        reason:
          'No repositoryUrl supplied; creating the workspace from the stack without adding a repository.',
      });
    else if (!input.repositoryBranch)
      this.logger.info('workspace.repository_default_branch', {
        soeid,
        csiid,
        reason: 'No repositoryCheckoutBranch supplied; using the repository default branch.',
      });
    this.assertCanCreateAnother(await this.listResources(soeid));

    const { name: namespace } = await this.namespaces.ensure(soeid, csiid);
    const { yaml, version } = await this.registry.getDevfile(input.devworkspaceValue, input.stackVersion);
    const devfile = applyEditorProfile(parseDevfile(yaml), input.editor);
    const body = buildDevWorkspaceObject({
      name: cleanWorkspaceName(input.devworkspaceValue),
      namespace,
      csiid,
      stack: input.devworkspaceValue,
      stackVersion: version,
      devfile,
      editor: input.editor,
      editorId: this.editorId(input.editor),
      devSpacesServiceFqdn: this.options.devSpacesServiceFqdn,
      repositoryUrl: input.repositoryUrl,
      repositoryBranch: input.repositoryBranch,
    });

    const created = await this.recorder.track(
      {
        soeid,
        csiid,
        eventtype: 'create',
        resourcetype: 'workspace',
        resourcename: body.metadata?.name ?? '',
        workspaceversion: version,
        editorname: input.editor,
        ...summarizeComponents(devfile.components),
      },
      () => this.kube.create<DevWorkspaceResource>('DevWorkspace', namespace, body),
    );
    this.logger.success('workspace.created', { soeid, namespace, workspace: created.metadata?.name });
    return toWorkspace(created);
  }

  async start(soeid: string, id: string): Promise<Workspace> {
    const dw = await this.find(soeid, id);
    if (dw.status?.phase === 'Running' || dw.status?.phase === 'Starting') return toWorkspace(dw);
    this.assertCanRunAnother(await this.listResources(soeid));
    return this.setStarted(soeid, dw, true);
  }

  async stop(soeid: string, id: string): Promise<Workspace> {
    const dw = await this.find(soeid, id);
    return this.setStarted(soeid, dw, false);
  }

  private async setStarted(soeid: string, dw: DevWorkspaceResource, started: boolean): Promise<Workspace> {
    const namespace = dw.metadata?.namespace ?? '';
    const name = dw.metadata?.name ?? '';
    const resources = summarizeComponents(dw.spec?.template?.components);
    const patched = await this.recorder.track(
      {
        soeid,
        csiid: toWorkspace(dw).csiid,
        eventtype: started ? 'start' : 'stop',
        resourcetype: 'workspace',
        resourcename: name,
        workspaceversion: dw.metadata?.annotations?.workspaceVersion ?? '',
        editorname: dw.metadata?.annotations?.editorDisplayName ?? '',
        duration: started ? '0 seconds' : durationSince(runningSince(dw), this.clock.now()),
        ...resources,
      },
      () => this.kube.setWorkspaceStarted(namespace, name, started),
    );
    this.logger.success(started ? 'workspace.started' : 'workspace.stopped', {
      soeid,
      namespace,
      workspace: name,
    });
    return toWorkspace({ ...dw, ...patched, metadata: { ...dw.metadata, ...patched.metadata } });
  }

  async delete(soeid: string, id: string): Promise<void> {
    const dw = await this.find(soeid, id);
    const namespace = dw.metadata?.namespace ?? '';
    const name = dw.metadata?.name ?? '';
    const resources = summarizeComponents(dw.spec?.template?.components);

    await this.recorder.track(
      {
        soeid,
        csiid: toWorkspace(dw).csiid,
        eventtype: 'delete',
        resourcetype: 'workspace',
        resourcename: name,
        workspaceversion: dw.metadata?.annotations?.workspaceVersion ?? '',
        editorname: dw.metadata?.annotations?.editorDisplayName ?? '',
        duration: durationSince(dw.metadata?.creationTimestamp, this.clock.now()),
        ...resources,
      },
      async () => {
        await this.kube.delete('DevWorkspace', namespace, name);
        // Workspaces created by the legacy flow reference a separate DevWorkspaceTemplate.
        for (const contribution of dw.spec?.contributions ?? []) {
          if (contribution.kubernetes?.name) {
            await this.kube.delete('DevWorkspaceTemplate', namespace, contribution.kubernetes.name);
          }
        }
      },
    );
    this.logger.success('workspace.deleted', { soeid, namespace, workspace: name });
  }

  private editorId(editor: EditorKey): string {
    return this.options.editors[editor];
  }
}

export class AppError extends Error {
  constructor(
    message: string,
    public readonly status: number,
    public readonly code: string,
    options?: { cause?: unknown },
  ) {
    super(message, options);
    this.name = new.target.name;
  }
}

export class BadRequestError extends AppError {
  constructor(message: string, code = 'BAD_REQUEST') {
    super(message, 400, code);
  }
}

export class ValidationError extends BadRequestError {
  constructor(
    message: string,
    public readonly details: { field: string; message: string }[],
  ) {
    super(message, 'VALIDATION_ERROR');
  }
}

export class UnauthorizedError extends AppError {
  constructor(message = 'Authentication required') {
    super(message, 401, 'UNAUTHORIZED');
  }
}

export class ForbiddenError extends AppError {
  constructor(message = 'Forbidden', options?: { cause?: unknown }) {
    super(message, 403, 'FORBIDDEN', options);
  }
}

export class NotFoundError extends AppError {
  constructor(message: string, code = 'NOT_FOUND', options?: { cause?: unknown }) {
    super(message, 404, code, options);
  }
}

export class ConflictError extends AppError {
  constructor(message: string, code = 'CONFLICT', options?: { cause?: unknown }) {
    super(message, 409, code, options);
  }
}

export class UpstreamError extends AppError {
  constructor(message: string, options?: { cause?: unknown }) {
    super(message, 502, 'UPSTREAM_ERROR', options);
  }
}

export class TimeoutError extends AppError {
  constructor(message: string) {

import type { NextFunction, Request, Response } from 'express';
import { describe, expect, it } from 'vitest';
import { asyncHandler, createErrorHandler, errorBody, notFoundHandler } from '../../../src/http/errors.js';
import {
  createWorkspaceSchema,
  gitConfigBodySchema,
  loginSchema,
  parse,
  patBodySchema,
} from '../../../src/http/schemas.js';
import { BadRequestError, ConflictError, UpstreamError } from '../../../src/utils/errors.js';
import { createLogger } from '../../../src/utils/logger.js';

function fakeRes() {
  const res = {
    locals: { requestId: 'rid' },
    headersSent: false,
    statusCode: 200,
    body: undefined as unknown,
    status(code: number) {
      this.statusCode = code;
      return this;
    },
    json(b: unknown) {
      this.body = b;
      return this;
    },
  };
  return res;
}

function handle(err: unknown) {
  const logs: Record<string, unknown>[] = [];
  const handler = createErrorHandler(createLogger('debug', (l) => logs.push(JSON.parse(l))));
  const res = fakeRes();
  let forwarded: unknown;
  handler(
    err,
    { path: '/x' } as Request,
    res as unknown as Response,
    ((e?: unknown) => (forwarded = e)) as NextFunction,
  );
  return { res, logs, forwarded };
}

describe('error handler', () => {
  it('maps AppErrors to their status and the standard body', () => {
    const { res } = handle(new ConflictError('taken', 'PAT_EXISTS'));
    expect(res.statusCode).toBe(409);
    expect(res.body).toEqual({ error: 'taken', message: 'taken', code: 'PAT_EXISTS' });
  });

  it('logs both server and client failures', () => {
    expect(handle(new UpstreamError('cluster down')).logs).toHaveLength(1);
    expect(handle(new BadRequestError('bad')).logs).toHaveLength(1);
  });

  it('maps body-parser failures', () => {
    expect(handle(Object.assign(new Error('x'), { type: 'entity.parse.failed' })).res.statusCode).toBe(400);
    expect(handle(Object.assign(new Error('x'), { type: 'entity.too.large' })).res.statusCode).toBe(413);
  });

  it('hides internals of unexpected errors', () => {
    const { res, logs } = handle(new Error('db password is hunter2'));
    expect(res.statusCode).toBe(500);
    expect(res.body).toEqual({
      error: 'Internal server error',
      message: 'Internal server error',
      code: 'INTERNAL_ERROR',
    });
    expect(JSON.stringify(res.body)).not.toContain('hunter2');
    expect(logs[0]).toMatchObject({ event: 'request.crashed', requestId: 'rid' });
  });

  it('defers to express when headers are already sent', () => {
    const logs: string[] = [];
    const handler = createErrorHandler(createLogger('debug', (l) => logs.push(l)));
    const res = { ...fakeRes(), headersSent: true };
    let forwarded: unknown;
    const err = new Error('late');
    handler(
      err,
      {} as Request,
      res as unknown as Response,
      ((e?: unknown) => (forwarded = e)) as NextFunction,
    );
    expect(forwarded).toBe(err);
  });

  it('404 handler names the route', () => {
    const res = fakeRes();
    notFoundHandler(
      { method: 'GET', path: '/nope' } as Request,
      res as unknown as Response,
      ((error: unknown) =>
        createErrorHandler(createLogger('silent'))(
          error,
          { method: 'GET', path: '/nope' } as Request,
          res as unknown as Response,
          (() => undefined) as NextFunction,
        )) as NextFunction,
    );
    expect(res.statusCode).toBe(404);
    expect(res.body).toEqual(errorBody('Route not found: GET /nope', 'ROUTE_NOT_FOUND'));
  });
});

describe('asyncHandler', () => {
  it('forwards rejections to next()', async () => {
    const boom = new Error('async boom');
    let forwarded: unknown;
    asyncHandler(async () => {
      throw boom;
    })({} as Request, {} as Response, ((e?: unknown) => (forwarded = e)) as NextFunction);
    await new Promise((r) => setImmediate(r));
    expect(forwarded).toBe(boom);
  });
});

describe('createWorkspaceSchema', () => {
  const ok = { editor: 'vscode', stackVersion: '2.0.0', devworkspaceValue: 'java-maven', csiid: '177398' };

  it('accepts required fields and numeric csiid', () => {
    expect(parse(createWorkspaceSchema, { ...ok, csiid: 177398 })).toEqual({ ...ok, editor: 'vscode' });
  });
  it('accepts all optional fields', () => {
    const body = {
      ...ok,
      editor: 'goland',
      stackVersion: '2.0.0',
      repositoryUrl: 'https://github.com/acme/app.git',
      repositoryBranch: 'feature/x-1',
    };
    expect(parse(createWorkspaceSchema, body)).toMatchObject(body);
  });
  it.each([
    ['missing stack', { csiid: '1' }],
    ['non-numeric csiid', { ...ok, csiid: 'abc' }],
    ['unknown editor', { ...ok, editor: 'emacs' }],
    ['stack with slash', { ...ok, devworkspaceValue: '../etc' }],
    ['http repo url', { ...ok, repositoryUrl: 'http://github.com/a/b' }],
    ['ssh repo url', { ...ok, repositoryUrl: 'git@github.com:a/b.git' }],
    ['bad branch', { ...ok, repositoryBranch: 'a b;rm' }],
    ['unknown property', { ...ok, admin: true }],
    ['empty body', undefined],
  ])('rejects %s with a 400 listing the problem', (_l, body) => {
    expect(() => parse(createWorkspaceSchema, body)).toThrow(BadRequestError);
  });
});

    expect(parse(loginSchema, { username: 'a', password: 'b' })).toEqual({ username: 'a', password: 'b' });
    expect(() => parse(loginSchema, { username: 'a' })).toThrow(BadRequestError);
    expect(() => parse(loginSchema, { username: 'a', password: 'b', extra: 1 })).toThrow(BadRequestError);
  });
  it('pat and gitconfig bodies', () => {
    expect(parse(patBodySchema, { csiid: 5, token: 't' })).toEqual({ csiid: '5', token: 't' });
    expect(() => parse(patBodySchema, { csiid: '5' })).toThrow(BadRequestError);
    expect(parse(gitConfigBodySchema, { csiid: '5', content: 'x' }).content).toBe('x');
    expect(() => parse(gitConfigBodySchema, { csiid: '5', content: '' })).toThrow(BadRequestError);
  });
  it('error messages name the field', () => {
    try {
      parse(createWorkspaceSchema, {
        editor: 'vscode',
        stackVersion: '2.0.0',
        devworkspaceValue: 'x',
        csiid: 'abc',
      });
      expect.unreachable();
    } catch (e) {
      expect((e as Error).message).toContain('csiid');
      expect((e as BadRequestError).code).toBe('VALIDATION_ERROR');
    }
  });
